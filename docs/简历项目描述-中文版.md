## 完整版（适合详细展示）

### 项目背景

学术研究人员完成一篇文献综述平均需要 **2-3 周**：跨 4-5 个学术平台检索（30-60 分钟/次）、人工筛选 100-200 篇论文摘要（1-2 天）、撰写初稿（1-2 周）。现有工具（Google Scholar、Zotero）各环节割裂，缺乏从检索到写作的端到端自动化能力，研究效率低下。

### 项目职责

**独立负责整个系统的设计与开发**，包括：
- 系统架构设计：基于 LangGraph 的多 Agent 协作框架
- 核心算法实现：多源搜索、智能筛选、自动写作、质量评审
- 前后端开发：FastAPI 异步后端 + React 前端
- 性能优化：异步架构、缓存策略、并发优化
- 测试部署：编写 827+ 测试用例，Docker 容器化部署

### 技术实现

**1. 多Agent工作流引擎**（基于 LangGraph StateGraph）
- 设计并实现了 **16 个功能节点、5 条工作流路径**（搜索/写作/报告/问答/修改）的统一调度系统
- 实现 Router 节点进行意图分类，准确率达 **92%**，动态路由到对应工作流
- 设�� PaperAgentState 状态类，管理 15+ 个字段（论文列表、大纲、草稿、反馈等），在节点间自动传递

**2. 多源并行学术搜索引擎**
- 集成 **4 个学术 API**（arXiv、PubMed、Semantic Scholar、OpenAlex），实现异步并行调度
- 将搜索耗时从 **30-60 分钟降至 3-5 秒**，效率提升 **360 倍**
- 实现基于标题+作者+年份的智能去重，准确率 > **95%**
- 构建统一搜索接口，支持跨平台查询和结果自动合并排序

**3. LLM 驱动的自动写作链路**（基于 GPT-4）
- 开发 **Selector 节点**：三维评分（相关性/质量/新颖性），F1 Score 达 **0.87**（优于人工基线 0.80，提升 **8.8%**）
- 实现 **Outline 节点**：基于筛选论文生成结构化大纲，耗时 < **10 秒**
- 构建 **Writer 节点**：逐章节生成内容并自动标注引用，**5000 字论文 < 2 分钟**完成
- 设计 **Reviewer → Evaluator 评审闭环**：4 维度质量评估（逻辑性/完整性/创新性/格式），支持最多 3 轮迭代

**4. 分层记忆系统**（参考 Mem0/Zep 架构）
- 架构设计 **4 层记忆系统**（短期/会话/长期/情景），支持向量语义检索和遗忘曲线衰减
- 集成 OpenAI text-embedding 和 sentence-transformers 实现语义检索，跨会话查询相关性提升 **15%**
- 实现搜索前自动召回历史记忆、筛选后自动存储结果，支持个性化用户体验

**5. 性能优化与工程实践**
- 优化异步架构（**aiohttp + asyncio**），并发处理能力提升 **3 倍**
- 实现 **Redis 缓存**策略，缓存命中率 > **60%**，响应时间降低 **70%**
- 构建完整的可观测性系统（WorkflowTracer），追踪节点级性能、Token 使用和成本估算
- 编写 **827+ 测试用例**（单元/集成/端到端），覆盖率 > **80%**，确保系统可靠性

**6. 全栈开发**
- **后端**：使用 FastAPI 构建异步 API 服务，支持论文/文献/报告/问答等 RESTful 端点
- **前端**：开发 **7 个核心页面**（首页/写作/文献/报告/问答/AI助手/设置），使用 React 18 + Vite 5 + Ant Design 5
- **状态管理**：使用 Zustand 实现实时状态同步和离线缓存

### 技术难点与解决方案

**难点 1: LangGraph 多路径条件路由**
- **挑战**: 5 条工作流路径共享部分节点（crawler、selector），需要运行时动态决定路径走向
- **解决**: 设计 `route_by_intent` 条件边函数，基于 Router 输出的意图标签动态选择下游节点；实现 `should_continue` 条件边控制写作-评审迭代终止
- **成果**: 单一 StateGraph 同时支持 5 条路径，节点间自动状态传递

**难点 2: 异步与同步混合调用**
- **挑战**: LangGraph 节点混合了同步方法（Agent.execute）和异步方法（memory_recall、report 节点）
- **解决**: 为异步节点使用 `async def` 定义，同步节点保持 `def`，LangGraph 自动处理调度；MemoryNode 内部通过 `asyncio.get_event_loop()` 桥接
- **成果**: 全链路异步执行，API 并发处理能力提升 3 倍

**难点 3: LLM 输出质量控制**
- **挑战**: GPT-4 生成的论文初稿存在结构松散、引用缺失、逻辑跳跃等问题
- **解决**: 设计 Reviewer → Evaluator 双重评审闭环，Reviewer 从 4 维度给出具体反馈，Evaluator 量化评分决定是否迭代
- **成果**: 3 轮迭代后综合评分从 6.3 提升至 7.9（+25%），格式评分从 7.0 提升至 8.5
