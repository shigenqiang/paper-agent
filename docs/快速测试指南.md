# 论文Agent快速测试指南

## 🚀 3步快速体验

### 第1步：安装依赖
```bash
pip install -r requirements.txt
```

### 第2步：启动服务
**推荐方式：一键启动**
```bash
start_all.bat
```

**或分步启动：**
```bash
# 终端1 - 启动API服务
python api.py

# 终端2 - 启动Web界面
streamlit run app.py
```

### 第3步：打开界面
浏览器访问：http://localhost:8501

## 🔧 常见问题

### Q1: 端口被占用
**解决方案：**
```bash
# 修改API端口
python api.py  # 编辑文件中的 port=8000

# 修改Web界面端口
streamlit run app.py --server.port 8502
```

### Q2: 依赖安装失败
**解决方案：**
```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q3: API未连接
**检查清单：**
1. API服务窗口是否正常运行
2. 侧边栏API地址是否正确（默认：http://localhost:8000）
3. 防火墙是否允许本地端口访问

### Q4: 查询无结果
**解决方法：**
1. 扩大年份范围（如2018-2025）
2. 简化查询关键词
3. 增加最大结果数
