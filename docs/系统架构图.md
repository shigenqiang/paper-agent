## 核心工作流

```
用户查询
    │
    ▼
┌─────────────────────────────────┐
│ 1. 查询理解与重写               │
│    - 术语标准化                 │
│    - 同义词扩展                 │
│    - 意图识别                   │
└────────────┬────────────────────┘
             │
             ▼
┌─────────────────────────────────┐
│ 2. 多源论文搜索                 │
│    - arXiv搜索                  │
│    - PubMed搜索                 │
│    - Google Scholar搜索         │
└────────────┬────────────────────┘
             │
             ▼
┌─────────────────────────────────┐
│ 3. 论文下载与解析               │
│    - PDF下载                    │
│    - 内容提取                   │
│    - 结构化解析                 │
└────────────┬────────────────────┘
             │
             ▼
┌─────────────────────────────────┐
│ 4. 知识抽取                     │
│    - 实体识别                   │

             │
             ▼

│ 5. 深度分析                     │
│    - 主题聚类                   │

             │
             ▼

             │
             ▼
         用户展示
```

## Agent职责分工

```
┌─────────────────────────────────────────────────────────────┐
│                    SearchAgent                               │
│  功能：论文搜索与筛选                                         │
│  输入：用户查询                                               │
│  输出：论文列表（包含元数据）                                 │
│  技能：                                                       │
│    - 查询澄清与重写                                          │
│    - 多源检索                                                │
│    - 结果排序与过滤                                          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                   ReadingAgent                               │
│  功能：论文阅读与信息提取                                     │
│  输入：论文列表                                               │
│  输出：结构化论文信息                                        │
│  技能：                                                       │
│    - PDF解析                                                 │
│    - 章节识别                                                │
│    - 关键信息提取                                            │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                  AnalysisAgent                               │
│  功能：深度分析与洞察生成                                     │
│  输入：结构化论文信息                                         │
│  输出：分析结果                                              │
│  技能：                                                       │
│    - 主题聚类                                                │
│    - 趋势分析                                                │
│    - 方法对比                                                │
│    - 知识图谱构建                                            │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                   WritingAgent                               │
│  功能：内容生成与整合                                         │
│  输入：分析结果                                               │
│  输出：草稿内容                                              │
│  技能：                                                       │
│    - 大纲生成                                                │
│    - 章节撰写                                                │
│    - 引用管理                                                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    ReportAgent                                │
│  功能：最终报告生成                                           │
│  输入：草稿内容                                               │
│  输出：Markdown报告                                           │
│  技能：                                                       │
│    - 格式规范化                                              │
│    - 语法检查                                                │
│    - 可读性优化                                              │
└─────────────────────────────────────────────────────────────┘
```
