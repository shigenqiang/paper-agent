## 一、快速部署

### 1.1 使用Docker部署

```bash
# 1. 克隆代码
git clone <repository_url>
cd paper-agent

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 填入 API密钥

# 3. 启动服务
docker-compose up -d

# 4. 检查状态
docker-compose ps
```

### 1.2 本地部署

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 填入 API密钥

# 3. 运行演示
python -m src.agents_v2.demo
```

## 二、环境变量配置

| 变量名 | 必填 | 说明 | 示例 |
|--------|------|------|------|
| `OPENAI_API_KEY` | 是 | API密钥 | `sk-xxx` |
| `HTTP_PROXY` | 否 | HTTP代理 | `http://127.0.0.1:7890` |
| `HTTPS_PROXY` | 否 | HTTPS代理 | `http://127.0.0.1:7890` |
| `LOG_LEVEL` | 否 | 日志级别 | `INFO` |
| `CACHE_TTL` | 否 | 缓存TTL(秒) | `3600` |
| `MAX_CONCURRENT` | 否 | 最大并发数 | `10` |

## 三、API使用

### 3.1 Python SDK方式

```python
import asyncio
from src.agents_v2.paper_agents import TopicAgent
from src.agents_v2.paper_agents.base_paper_agent import LLMConfig

async def main():
    # 配置
    llm_config = LLMConfig(
        provider="openai",
        model_name="minimax",
        temperature=0.7
    )

    # 创建Agent
    agent = TopicAgent(llm_config)

    # 执行
    result = await agent.execute({
        "user_request": "机器学习在医疗诊断中的应用"
    })

    print(f"Success: {result.success}")
    print(f"Quality: {result.quality_score}")

asyncio.run(main())
```

### 3.2 命令行方式

```bash
# 运行演示
python -m src.agents_v2.demo

# 运行测试
python -m pytest tests/ -v
```

## 四、Docker Compose 配置

### 4.1 服务配置

```yaml
services:
  paper-agent:
    build: .
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - HTTP_PROXY=${HTTP_PROXY:-}
    volumes:
      - ./data:/app/data
      - ./output:/app/output
    ports:
      - "8000:8000"
```

### 4.2 常用命令

```bash
# 启动服务
docker-compose up -d

# 停止服务
docker-compose down

# 查看日志
docker-compose logs -f

# 重启服务
docker-compose restart

# 重新构建
docker-compose up -d --build
```

## 六、故障排除

### 6.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| `OPENAI_API_KEY` 错误 | API密钥无效 | 检查 `.env` 中的密钥 |
| 连接超时 | 代理配置错误 | 检查 `HTTP_PROXY` 设置 |
| 端口占用 | 8000端口被占用 | 修改 `docker-compose.yml` 端口映射 |

### 6.2 日志查看

```bash
# 查看所有日志
docker-compose logs

# 查看最近日志
docker-compose logs --tail=100

# 实时跟踪日志
docker-compose logs -f paper-agent
```

## 七、性能调优

### 7.1 并发配置

```bash
# docker-compose.yml
environment:
  - MAX_CONCURRENT=20  # 增加并发数
```

### 7.2 缓存配置

```bash
# 启用缓存
environment:
  - ENABLE_CACHE=true
  - CACHE_TTL=7200  # 2小时缓存
```

### 7.3 资源限制

```yaml
# docker-compose.yml
deploy:
  resources:
    limits:
      cpus: '2'
      memory: 4G
```
