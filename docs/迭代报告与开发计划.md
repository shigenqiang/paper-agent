## 一、项目概述

### 1.1 核心目标

构建一个智能的学术论文调研与写作系统，实现：
- **智能路由**：自动判断问题类型，决定处理策略
- **论文搜索**：自动从arXiv/PubMed等学术平台搜索相关论文
- **专业报告**：基于真实论文给出带参考文献的专业回答
- **论文写作**：从选题到完稿的全流程辅助
- **智能改稿**：解析导师意见，自动优化文本

### 1.2 应用场景

| 场景 | 说明 |
|------|------|
| 快速调研 | 快速了解某研究领域的前沿进展 |
| 论文搜索 | 寻找特定研究方向的开创性工作 |
| 专业问答 | 获取跨学科的研究洞察 |
| 文献追踪 | 每日/每周/每月推送论文摘要报告 |
| 论文写作 | 从选题到完稿的全流程辅助 |
| 智能改稿 | 解析导师意见，自动优化文本 |

## 二、系统架构

### 2.1 核心架构

```
用户请求
    │
    ▼
┌─────────────────┐
│  IntentRouter   │ ← 意图识别
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌────────┐ ┌────────┐
│Pipeline │ │Problem │
│ Agent  │ │ Agent  │
└────┬───┘ └───┬────┘
     │         │
     ▼         ▼
┌────────┐ ┌────────┐
│Writing  │ │ 诊断   │
│ Agent  │ │ 修复   │
└────┬───┘ └───┬────┘
     │         │
     └────┬────┘
          ▼
┌─────────────────┐
│ MasterSupervisor│ ← 全局协调
└────────┬────────┘
          │
          ▼
┌─────────────────┐
│  UnifiedMemory   │
│  Manager         │
└─────────────────┘
```
