## 记录规范

遇到问题时，在 `docs/problem/` 目录创建新文件：

```
docs/problem/
├── README.md                    # 本文件 - 问题索引
├── YYYY-MM-DD_问题简述.md       # 按日期命名的问题文档
└── ...
```

**文件名格式**：`日期_问题简述.md`，如 `2026-05-09_websearch_api_error.md`
