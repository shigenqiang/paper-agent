# 快速开始指南

> 本指南帮助你在5分钟内上手论文Agent系统

---

## 一、安装

### 1.1 克隆项目

```bash
git clone <repository_url>
cd paper-agent
```

### 1.2 安装依赖

```bash
pip install -r requirements.txt
```

### 1.3 配置API密钥

创建 `.env` 文件：

```env
OPENAI_API_KEY=your_api_key_here
```

---

## 二、最快方式：运行演示

```bash
python -m src.agents_v2.demo
```

这将演示：
1. 意图路由
2. 论文搜索
3. 完整论文流程
4. 开题报告生成

---

## 三、Python代码方式

### 3.1 选题

```python
import asyncio
from src.agents_v2.paper_agents import TopicAgent

async def main():
    agent = TopicAgent()
    result = await agent.execute({
        "user_request": "机器学习在医疗诊断中的应用"
    })
    print(f"成功: {result.success}")
    print(f"质量: {result.quality_score}")
    print(f"主题: {result.result['selected_topic']['title']}")

asyncio.run(main())
```

### 3.2 文献搜索

```python
import asyncio
from src.agents_v2.paper_agents import LiteratureAgent

async def main():
    agent = LiteratureAgent()
    result = await agent.execute({
        "topic": "深度学习优化"
    })
    print(f"找到 {len(result.result['papers'])} 篇论文")

asyncio.run(main())
```

### 3.3 完整论文流程

```python
import asyncio
from src.agents_v2.unified import MasterSupervisor

async def main():
    supervisor = MasterSupervisor()
    supervisor.register_pipeline_agents()
    supervisor.register_writing_agents()

    result = await supervisor.run("full_paper", {
        "topic": "图像分割算法研究"
    })

    print(f"完成阶段: {result['phases_completed']}")
    print(f"最终质量: {result['final_quality']}")

asyncio.run(main())
```

## 四、HTTP API方式

### 4.1 启动服务器

```bash
python -m src.agents_v2.api_server
```

### 4.2 调用API

```bash
# 健康检查（无需认证）
curl http://localhost:8000/health

# 选题（需要认证）
curl -X POST http://localhost:8000/api/topic \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_api_key" \
  -d '{"user_request": "深度学习优化"}'

# 论文搜索
curl -X POST http://localhost:8000/api/search \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_api_key" \
  -d '{"query": "transformer", "source": "arxiv", "max_results": 5}'
```

**注意**: 设置环境变量 `API_KEY` 以启用认证

## 六、常见问题

### Q: API调用失败？

检查：
1. `.env` 文件是否正确配置
2. `OPENAI_API_KEY` 是否有效
3. 网络代理是否正确（如果需要）

### Q: 论文搜索返回空？

可能原因：
1. 网络连接问题
2. arXiv/PubMed服务暂时不可用
3. 搜索词不够精确

### Q: 中文显示乱码？

MiniMax模型有中文编码问题。解决方案：
1. 使用GPT-4/Claude（无此问题）
2. 使用TranslationWrapper（中英互译）
