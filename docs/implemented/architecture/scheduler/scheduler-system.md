## 二、功能描述

### 2.1 ReportScheduler 报告调度

**功能**: 定时生成学术报告（日报/周报/月报）

**调度模式**:
| 类型 | 触发时间 | 说明 |
|------|----------|------|
| 日报 | 每天 09:00 | 当日最新论文 |
| 周报 | 每周一 09:00 | 本周热点论文 |
| 月报 | 每月1日 09:00 | 本月研究趋势 |

**处理流程**:
```
定时触发
    │
    ▼
┌─────────────────────────────────────────┐
│  论文检索                                 │
│  - 按时间范围搜索                          │
│  - 按主题/关键词过滤                       │
│  - 多源数据聚合                           │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│  报告生成                                 │
│  - 论文筛选排序                            │
│  - 内容摘要生成                            │
│  - 结构化输出                             │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│  报告分发                                 │
│  - 邮件发送                              │
│  - Webhook推送                           │
│  - API存储                               │
└─────────────────────────────────────────┘
```

### 2.2 SubscriptionManager 订阅管理

**功能**: 管理用户订阅配置

**订阅类型**:
| 类型 | 说明 | 参数 |
|------|------|------|
| keyword | 关键词订阅 | 关键词列表 |
| author | 作者订阅 | 作者名/ID |
| venue | 期刊/会议订阅 | 期刊名 |
| topic | 主题订阅 | 研究领域 |

**用户配置**:
```python
Subscription:
    user_id: str
    type: SubscriptionType
    params: dict              # 类型相关参数
    frequency: str           # daily/weekly/monthly
    enabled: bool
    webhook_url: str = None   # 回调地址
```

### 2.3 DependencyScheduler 依赖调度

**功能**: 管理任务依赖关系

**使用场景**:
- 报告生成依赖多个子任务完成
- 论文分析依赖文献检索
- 大纲生成依赖选题完成

**调度策略**:
| 策略 | 说明 |
|------|------|
| sequential | 顺序执行，等上一个完成 |
| parallel | 并行执行 |
| conditional | 条件触发 |
