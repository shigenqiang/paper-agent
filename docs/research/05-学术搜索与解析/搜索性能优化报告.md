# 论文搜索性能优化报告

**日期**: 2026-05-02
**优化目标**: 缩短论文搜索时间，同时不降低论文质量

> **注**: 本报告是 [学术论文搜索开发报告](学术论文搜索开发报告.md) 第4-5节设计的实施验证，记录了具体的benchmark结果（13.17s → 8.41s，1.6x加速）。

---

## 一、优化的主要瓶颈

通过代码分析，发现以下性能瓶颈：

| 瓶颈 | 位置 | 影响 |
|------|------|------|
| ArXiv `search_batch` 串行执行 | `arxiv_searcher.py:311-314` | 批量查询时间 = O(n × 延迟) |
| `max_parallel_sources=3` 限制 | `search_orchestrator.py:48` | 多源搜索受并发数限制 |
| 无熔断机制 | `search_orchestrator.py` | 单源故障阻塞整体 |
| CrossRef 无速率控制 | `crossref_searcher.py` | 可能触发限流重试 |

## 二、具体优化内容

### 1. ArXiv Batch Search 并行化 ✅

**文件**: `src/agents_v2/search/arxiv_searcher.py`

**优化前** (串行):
```python
responses = []
for query in queries:
    response = await self.search(query, max_results_per_query)
    responses.append(response)
return responses
```

**优化后** (并行):
```python
tasks = [self.search(query, max_results_per_query) for query in queries]
return await asyncio.gather(*tasks)
```

**测试结果**:
| 指标 | 优化前 | 优化后 | 提升 |
|------|--------|--------|------|
| 4个查询耗时 | 13.17s | 8.41s | **1.6x 加速** |

---

### 2. 提高多源并发数 ✅

**文件**: `src/agents_v2/search/search_orchestrator.py`

**优化前**:
```python
@dataclass
class OrchestratorConfig:
    max_parallel_sources: int = 3
```

**优化后**:
```python
@dataclass
class OrchestratorConfig:
    max_parallel_sources: int = 5  # 提高并发数
```

**效果**:
- 并发能力提升 67% (3 → 5)
- COMPREHENSIVE 策略下更多源可并行执行

---

### 3. 添加熔断机制 ✅

**文件**: `src/agents_v2/search/search_orchestrator.py`

**新增配置**:
```python
@dataclass
class OrchestratorConfig:
    enable_circuit_breaker: bool = True
    circuit_breaker_threshold: int = 3  # 连续失败次数触发熔断
    circuit_breaker_timeout: float = 60.0  # 熔断窗口时间(秒)
```

**熔断逻辑**:
- 连续失败 3 次后，该源进入熔断状态
- 熔断期间（60秒）跳过该源搜索
- 超时不计入失败计数（避免误判）
- 熔断超时后自动恢复

**效果**: 单源故障不再阻塞整体搜索

## 五、风险评估

| 优化 | 风险 | 缓解措施 |
|------|------|----------|
| 提高并发数 | 可能触发 API 限流 | RateManager 已有速率控制保护 |
| 熔断机制 | 可能误跳过可用源 | 60秒窗口后自动恢复，超时不计入失败 |
| ArXiv 并行 | 速率限制更严格 | 已有 3s 间隔限制，不额外加速 |

## 六、后续优化建议

1. **结果合并算法优化**: 当前 O(n²) 标题相似度比较，可使用 SimHash 优化
2. **缓存预热**: 对高频查询进行主动缓存预填充
3. **语义缓存**: 支持相似查询的缓存命中（使用 Embedding 相似度）
