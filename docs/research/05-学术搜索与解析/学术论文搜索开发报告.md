## 1. 背景与目标

### 1.1 当前现状

项目已实现以下搜索器：

| 搜索器 | 状态 | 问题 |
|--------|------|------|
| OpenAlexSearcher | ✅ 已实现 | 正常 |
| SemanticScholarSearcher | ✅ 已实现 | 无API Key时受限 |

## 2. 文献平台选型

> **注**: 平台选型的算法理论依据（BM25、TF-IDF、Learning to Rank）详见 [学术文献选取机制调研报告](学术文献选取机制调研报告.md)。arXiv限流的专项解决方案详见 [arxiv_rate_limit_solutions.md](arxiv_rate_limit_solutions.md)。

### 2.1 推荐平台矩阵

根据调研结果，按使用场景分类：

#### 主平台（免费、高质量、建议优先使用）

| 平台 | 数据规模 | 费用 | 频率限制 | 适用场景 |
|------|----------|------|----------|----------|
| **OpenAlex** | 4.74亿学术作品 | 免费 | 合理使用 | 主力搜索，全学科 |
| **arXiv** | 200万+论文 | 免费 | 3秒间隔 | CS/物理/数学预印本 |
| **CrossRef** | 1.2亿+论文 | 免费 | 50次/秒 | 元数据、DOI解析 |

#### 辅助平台（需要API Key或有限制）

| 平台 | 数据规模 | 费用 | 频率限制 | 适用场景 |
|------|----------|------|----------|----------|
| **Semantic Scholar** | 2亿+论文 | 免费版 | 5次/秒 | 引用分析、论文详情 |
| **PubMed** | 3700万文献 | 免费 | 3次/秒(无Key) | 生物医学文献 |
| **bioRxiv/medRxiv** | 预印本 | 免费 | 无明确限制 | 医学/生物预印本 |

#### 商业平台（需要订阅）

| 平台 | 适用场景 |
|------|----------|
| Dimensions | 企业级研究分析 |
| Scopus | 机构订阅用户 |
| Web of Science | 高端学术检索 |
| IEEE Xplore | 工程/计算机领域 |

### 2.2 推荐组合方案

#### 方案A：免费优先（推荐用于开发/测试）

```
优先级1: OpenAlex - 主搜索引擎，无限制
优先级2: arXiv - 预印本搜索，CS/物理/数学
优先级3: Semantic Scholar - 论文详情和引用
优先级4: CrossRef - DOI和元数据
优先级5: PubMed - 生物医学领域
```

#### 方案B：完整覆盖（适合生产环境）

```
基础层: OpenAlex + arXiv + CrossRef
增强层: Semantic Scholar + PubMed（需要API Key）
专业层: bioRxiv/medRxiv（医学预印本）
```

#### 方案C：垂直领域（针对特定研究）

```
生物医学: PubMed + bioRxiv/medRxiv + OpenAlex
计算机: arXiv + OpenAlex + Semantic Scholar
综合: OpenAlex + CrossRef + Semantic Scholar
```

### 5.1 Rate Manager - 频率管理器

```python
# src/agents_v2/search/rate_manager.py

"""
Rate Manager - 智能频率限制管理器

管理多平台API的请求频率，避免触发限制。
"""
import asyncio
import time
from dataclasses import dataclass, field
from typing import Dict, Optional
from collections import deque
import logging

logger = logging.getLogger(__name__)


@dataclass
class PlatformConfig:
    """平台频率配置"""
    name: str
    min_interval: float = 1.0        # 最小请求间隔(秒)
    max_requests_per_second: float = 1.0  # 最大每秒请求数
    max_requests_per_hour: int = 3600    # 每小时最大请求数
    max_requests_per_day: int = 50000    # 每日最大请求数
    backoff_multiplier: float = 2.0      # 退避倍数
    max_backoff: float = 60.0            # 最大退避时间(秒)
    use_api_key: bool = False


class RateManager:
    """智能频率管理器"""

    # 平台默认配置
    DEFAULT_CONFIGS: Dict[str, PlatformConfig] = {
        "openalex": PlatformConfig(
            name="openalex",
            min_interval=0.5,
            max_requests_per_second=2,
        ),
        "arxiv": PlatformConfig(
            name="arxiv",
            min_interval=3.0,
            max_requests_per_hour=1000,
        ),
        "semantic_scholar": PlatformConfig(
            name="semantic_scholar",
            min_interval=0.2,
            max_requests_per_second=5,
            use_api_key=True,
        ),
        "pubmed": PlatformConfig(
            name="pubmed",
            min_interval=0.33,
            max_requests_per_second=3,
            use_api_key=True,
        ),
        "crossref": PlatformConfig(
            name="crossref",
            min_interval=0.02,
            max_requests_per_second=50,
        ),
        "biorxiv": PlatformConfig(
            name="biorxiv",
            min_interval=1.0,
        ),
    }

    def __init__(self):
        self._last_request_time: Dict[str, float] = {}
        self._request_counts_hour: Dict[str, deque] = {}
        self._request_counts_day: Dict[str, deque] = {}
        self._backoff_until: Dict[str, float] = {}

    def get_config(self, platform: str, **overrides) -> PlatformConfig:
        """获取平台配置，支持覆盖"""
        config = self.DEFAULT_CONFIGS.get(platform)
        if not config:
            config = PlatformConfig(name=platform)
        if overrides:
            config = PlatformConfig(
                name=config.name,
                **{**config.__dict__, **overrides}
            )
        return config

    async def acquire(self, platform: str, config: Optional[PlatformConfig] = None):
        """获取请求许可，必要时等待"""
        config = config or self.get_config(platform)

        # 检查是否在退避期
        if platform in self._backoff_until:
            backoff_end = self._backoff_until[platform]
            if time.time() < backoff_end:
                wait_time = backoff_end - time.time()
                logger.debug(f"{platform} in backoff, waiting {wait_time:.2f}s")
                await asyncio.sleep(wait_time)

        # 检查最小间隔
        if platform in self._last_request_time:
            elapsed = time.time() - self._last_request_time[platform]
            if elapsed < config.min_interval:
                wait_time = config.min_interval - elapsed
                await asyncio.sleep(wait_time)

        # 检查小时配额
        self._clean_old_counts(platform, window=3600)
        if config.max_requests_per_hour:
            hour_counts = self._request_counts_hour.setdefault(platform, deque())
            if len(hour_counts) >= config.max_requests_per_hour:
                oldest = hour_counts[0]
                wait_time = 3600 - (time.time() - oldest)
                if wait_time > 0:
                    logger.warning(f"{platform} hourly limit reached, waiting {wait_time:.2f}s")
                    await asyncio.sleep(wait_time)

        # 检查每日配额
        self._clean_old_counts(platform, window=86400, key="day")
        if config.max_requests_per_day:
            day_counts = self._request_counts_day.setdefault(platform, deque())
            if len(day_counts) >= config.max_requests_per_day:
                oldest = day_counts[0]
                wait_time = 86400 - (time.time() - oldest)
                if wait_time > 0:
                    logger.warning(f"{platform} daily limit reached, waiting {wait_time:.2f}s")
                    await asyncio.sleep(wait_time)

        # 记录请求
        current_time = time.time()
        self._last_request_time[platform] = current_time

        hour_counts = self._request_counts_hour.setdefault(platform, deque())
        hour_counts.append(current_time)

        day_counts = self._request_counts_day.setdefault(platform, deque())
        day_counts.append(current_time)

    def record_error(self, platform: str, config: Optional[PlatformConfig] = None):
        """记录错误，触发退避"""
        config = config or self.get_config(platform)
        backoff_time = min(
            config.max_backoff,
            (self._backoff_until.get(platform, 0) - time.time()) * config.backoff_multiplier
            or config.min_interval * config.backoff_multiplier
        )
        self._backoff_until[platform] = time.time() + backoff_time
        logger.warning(f"{platform} error recorded, backoff until {backoff_time:.2f}s")

    def _clean_old_counts(self, platform: str, window: int, key: str = "hour"):
        """清理过期计数"""
        current = time.time()
        if key == "hour":
            counts = self._request_counts_hour.get(platform, deque())
        else:
            counts = self._request_counts_day.get(platform, deque())

        while counts and current - counts[0] > window:
            counts.popleft()

    def get_stats(self, platform: str) -> Dict:
        """获取平台统计信息"""
        hour_counts = self._request_counts_hour.get(platform, deque())
        day_counts = self._request_counts_day.get(platform, deque())
        self._clean_old_counts(platform, 3600)
        self._clean_old_counts(platform, 86400, key="day")

        return {
            "platform": platform,
            "requests_last_hour": len(self._request_counts_hour.get(platform, [])),
            "requests_last_day": len(self._request_counts_day.get(platform, [])),
            "in_backoff": platform in self._backoff_until and time.time() < self._backoff_until[platform],
            "last_request": self._last_request_time.get(platform)
        }
```

### 5.2 增强型Searcher基类

```python
# src/agents_v2/search/enhanced_base_searcher.py

"""
Enhanced Base Searcher - 增强型搜索器基类

包含重试逻辑、速率控制、错误处理等功能。
"""
import asyncio
import logging
from abc import abstractmethod
from dataclasses import dataclass
from typing import List, Optional, Dict, Any

from .base_searcher import BaseSearcher, SearchResult, SearchResponse
from .rate_manager import RateManager, PlatformConfig

logger = logging.getLogger(__name__)


@dataclass
class RetryConfig:
    """重试配置"""
    max_retries: int = 3
    base_delay: float = 1.0
    max_delay: float = 30.0
    exponential_base: float = 2.0
    jitter: bool = True


class EnhancedBaseSearcher(BaseSearcher):
    """增强型搜索器基类"""

    def __init__(
        self,
        name: str,
        rate_manager: Optional[RateManager] = None,
        retry_config: Optional[RetryConfig] = None,
        platform_config: Optional[PlatformConfig] = None
    ):
        super().__init__(name)
        self.rate_manager = rate_manager or RateManager()
        self.retry_config = retry_config or RetryConfig()
        self.platform_config = platform_config or PlatformConfig(name=name)
        self._session = None

    async def _get_session(self):
        """获取或创建HTTP会话"""
        if self._session is None or self._session.closed:
            import aiohttp
            timeout = aiohttp.ClientTimeout(total=30)
            self._session = aiohttp.ClientSession(timeout=timeout)
        return self._session

    async def _make_request(
        self,
        url: str,
        params: dict = None,
        headers: dict = None
    ) -> Dict[str, Any]:
        """发送HTTP请求，带速率控制和重试"""
        import aiohttp

        for attempt in range(self.retry_config.max_retries):
            try:
                # 获取请求许可（速率控制）
                await self.rate_manager.acquire(self.name, self.platform_config)

                session = await self._get_session()
                async with session.get(url, params=params, headers=headers) as resp:
                    return await self._handle_response(resp)

            except aiohttp.ClientError as e:
                logger.warning(f"{self.name} request failed (attempt {attempt + 1}): {e}")
                if attempt < self.retry_config.max_retries - 1:
                    delay = self._calculate_delay(attempt)
                    await asyncio.sleep(delay)
                    continue
                self.rate_manager.record_error(self.name, self.platform_config)
                return {"error": str(e)}

            except asyncio.TimeoutError:
                logger.warning(f"{self.name} request timeout (attempt {attempt + 1})")
                if attempt < self.retry_config.max_retries - 1:
                    delay = self._calculate_delay(attempt)
                    await asyncio.sleep(delay)
                    continue
                return {"error": "Request timeout"}

        return {"error": "Max retries exceeded"}

    async def _handle_response(self, resp: aiohttp.ClientResponse) -> Dict[str, Any]:
        """处理HTTP响应"""
        if resp.status == 429:
            self.rate_manager.record_error(self.name, self.platform_config)
            return {"error": "Rate limit exceeded"}
        if resp.status == 404:
            return {"data": [], "not_found": True}
        if resp.status != 200:
            text = await resp.text()
            logger.error(f"{self.name} API error: {resp.status} - {text}")
            return {"error": f"HTTP {resp.status}"}

        return await resp.json()

    def _calculate_delay(self, attempt: int) -> float:
        """计算重试延迟"""
        delay = self.retry_config.base_delay * (self.retry_config.exponential_base ** attempt)
        delay = min(delay, self.retry_config.max_delay)

        if self.retry_config.jitter:
            import random
            delay *= (0.5 + random.random())

        return delay

    async def close(self):
        """关闭HTTP会话"""
        if self._session and not self._session.closed:
            await self._session.close()

    @abstractmethod
    async def search(self, query: str, max_results: int = 10) -> SearchResponse:
        """执行搜索 - 子类必须实现"""
        pass
```

### 5.3 搜索编排器

```python
# src/agents_v2/search/search_orchestrator.py

"""
Search Orchestrator - 搜索编排器

协调多个搜索器，实现智能搜索策略。
"""
import asyncio
import logging
from dataclasses import dataclass, field
from enum import Enum
from typing import List, Optional, Dict, Callable

from .base_searcher import SearchResult, SearchResponse
from .search_result_merger import SearchResultMerger, MergeConfig, MergedSearchResult
from .rate_manager import RateManager

logger = logging.getLogger(__name__)


class SearchStrategy(Enum):
    """搜索策略"""
    FAST = "fast"                    # 快速 - 只用最快
    BALANCED = "balanced"           # 平衡 - 覆盖与速度兼顾
    COMPREHENSIVE = "comprehensive" # 全面 - 多源聚合
    PRECISE = "precise"             # 精准 - 多重验证


@dataclass
class SearchConfig:
    """搜索配置"""
    strategy: SearchStrategy = SearchStrategy.BALANCED
    max_results_per_source: int = 10
    max_total_results: int = 50
    timeout_per_source: float = 10.0
    enable_cache: bool = True
    merge_config: Optional[MergeConfig] = None


@dataclass
class OrchestratorConfig:
    """编排器配置"""
    enable_parallel: bool = True
    max_parallel_sources: int = 3
    fail_fast: bool = False  # 一个失败立即返回
    partial_results_on_error: bool = True  # 部分失败仍返回已有结果


class SearchOrchestrator:
    """搜索编排器"""

    def __init__(
        self,
        searchers: Dict[str, Callable],
        config: Optional[OrchestratorConfig] = None,
        rate_manager: Optional[RateManager] = None
    ):
        self.searchers = searchers  # name -> searcher instance
        self.config = config or OrchestratorConfig()
        self.rate_manager = rate_manager or RateManager()
        self.merger = SearchResultMerger()

    async def search(
        self,
        query: str,
        config: Optional[SearchConfig] = None
    ) -> List[MergedSearchResult]:
        """执行搜索

        Args:
            query: 搜索查询
            config: 搜索配置

        Returns:
            合并排序后的搜索结果
        """
        config = config or SearchConfig()
        sources = self._select_sources(config.strategy)

        logger.info(f"Searching with strategy {config.strategy.value}: {sources}")

        # 并行执行多个搜索
        responses = await self._search_parallel(sources, query, config)

        # 合并结果
        merged = await self._merge_results(responses, config)

        return merged[:config.max_total_results]

    def _select_sources(self, strategy: SearchStrategy) -> List[str]:
        """根据策略选择搜索源"""
        all_sources = list(self.searchers.keys())

        if strategy == SearchStrategy.FAST:
            # 只用最快最可靠的源
            return ["openalex", "arxiv"]

        elif strategy == SearchStrategy.BALANCED:
            # 平衡策略：核心源 + 1-2个扩展源
            return ["openalex", "arxiv", "semantic_scholar"]

        elif strategy == SearchStrategy.COMPREHENSIVE:
            # 全面策略：所有源
            return all_sources

        elif strategy == SearchStrategy.PRECISE:
            # 精准策略：先去重，再扩展
            return ["openalex", "crossref", "semantic_scholar"]

        return all_sources

    async def _search_parallel(
        self,
        sources: List[str],
        query: str,
        config: SearchConfig
    ) -> List[SearchResponse]:
        """并行执行多个搜索"""
        tasks = []
        semaphore = asyncio.Semaphore(self.config.max_parallel_sources)

        async def search_with_semaphore(source: str):
            async with semaphore:
                searcher = self.searchers.get(source)
                if not searcher:
                    logger.warning(f"Searcher {source} not found")
                    return None

                try:
                    # 带超时的搜索
                    result = await asyncio.wait_for(
                        searcher.search(query, config.max_results_per_source),
                        timeout=config.timeout_per_source
                    )
                    return result
                except asyncio.TimeoutError:
                    logger.warning(f"{source} search timeout")
                    return None
                except Exception as e:
                    logger.error(f"{source} search failed: {e}")
                    if self.config.fail_fast:
                        raise
                    return None

        # 创建所有搜索任务
        for source in sources:
            tasks.append(search_with_semaphore(source))

        # 并行执行
        results = await asyncio.gather(*tasks, return_exceptions=True)

        # 过滤失败的结果
        responses = []
        for result in results:
            if isinstance(result, SearchResponse):
                responses.append(result)
            elif isinstance(result, Exception) and not self.config.fail_fast:
                logger.error(f"Search exception: {result}")

        return responses

    async def _merge_results(
        self,
        responses: List[SearchResponse],
        config: SearchConfig
    ) -> List[MergedSearchResult]:
        """合并搜索结果"""
        if not responses:
            return []

        merge_config = config.merge_config or MergeConfig()
        return self.merger.merge(responses)
```

### 7.1 错误分类与处理策略

```python
# src/agents_v2/search/error_handling.py

"""
Error Handling - 错误处理与降级策略
"""
import asyncio
from dataclasses import dataclass
from enum import Enum
from typing import Optional
import logging

logger = logging.getLogger(__name__)


class ErrorCategory(Enum):
    """错误类别"""
    RATE_LIMIT = "rate_limit"           # 限流
    TIMEOUT = "timeout"                   # 超时
    NETWORK_ERROR = "network_error"       # 网络错误
    API_ERROR = "api_error"               # API错误
    PARSE_ERROR = "parse_error"           # 解析错误
    AUTH_ERROR = "auth_error"             # 认证错误
    UNKNOWN = "unknown"                   # 未知错误


@dataclass
class ErrorContext:
    """错误上下文"""
    category: ErrorCategory
    platform: str
    message: str
    retry_count: int
    is_retryable: bool
    fallback_available: bool


class ErrorHandler:
    """错误处理器"""

    # 错误类别对应的重试策略
    RETRY_STRATEGIES = {
        ErrorCategory.RATE_LIMIT: {"should_retry": True, "delay": 30, "max_retries": 3},
        ErrorCategory.TIMEOUT: {"should_retry": True, "delay": 5, "max_retries": 3},
        ErrorCategory.NETWORK_ERROR: {"should_retry": True, "delay": 2, "max_retries": 2},
        ErrorCategory.API_ERROR: {"should_retry": True, "delay": 5, "max_retries": 2},
        ErrorCategory.AUTH_ERROR: {"should_retry": False, "delay": 0, "max_retries": 0},
        ErrorCategory.PARSE_ERROR: {"should_retry": False, "delay": 0, "max_retries": 0},
    }

    def __init__(self):
        self.fallback_sources: Dict[str, List[str]] = {
            "semantic_scholar": ["openalex", "crossref"],
            "pubmed": ["openalex", "crossref"],
            "arxiv": ["openalex"],
        }

    def categorize_error(self, error: Exception, platform: str) -> ErrorContext:
        """将错误分类"""
        error_str = str(error).lower()

        if "429" in error_str or "rate limit" in error_str:
            category = ErrorCategory.RATE_LIMIT
        elif "timeout" in error_str:
            category = ErrorCategory.TIMEOUT
        elif "connection" in error_str or "network" in error_str:
            category = ErrorCategory.NETWORK_ERROR
        elif "401" in error_str or "403" in error_str or "auth" in error_str:
            category = ErrorCategory.AUTH_ERROR
        elif "parse" in error_str or "json" in error_str:
            category = ErrorCategory.PARSE_ERROR
        else:
            category = ErrorCategory.UNKNOWN

        strategy = self.RETRY_STRATEGIES.get(category, {})

        return ErrorContext(
            category=category,
            platform=platform,
            message=str(error),
            retry_count=0,
            is_retryable=strategy.get("should_retry", False),
            fallback_available=platform in self.fallback_sources
        )

    def get_fallback_sources(self, platform: str) -> list:
        """获取降级源"""
        return self.fallback_sources.get(platform, [])

    async def handle_error(self, error: Exception, platform: str) -> Optional[SearchResponse]:
        """处理错误，返回降级结果（如果有）"""
        context = self.categorize_error(error, platform)

        logger.warning(f"{platform} error: {context.category.value} - {context.message}")

        if context.is_retryable:
            strategy = self.RETRY_STRATEGIES[context.category]
            for i in range(strategy["max_retries"]):
                await asyncio.sleep(strategy["delay"] * (i + 1))
                try:
                    # 重试逻辑
                    pass
                except Exception as e:
                    continue

        # 触发降级
        if context.fallback_available:
            logger.info(f"Falling back from {platform} to alternatives")
            return None  # 让编排器使用降级源

        return None
```

## 10. 技术难点与解决方案

### 10.1 频率限制处理

基于调研发现，主要学术API平台的限制特点如下：

| 平台 | 频率限制 | 配额限制 | 认证要求 | 解决方案 |
|-----|---------|---------|---------|---------|
| OpenAlex | 未明确声明 | 未明确声明 | 无 | 合理使用，建议0.5-1秒间隔 |
| Semantic Scholar | 5次/秒(免费) | 可申请提高 | API Key可选 | 令牌桶算法 + 多密钥轮换 |
| CrossRef | 50次/秒 | 高 | 可选 | 标准限流，缓存策略 |
| PubMed | 基于IP | 需API Key提升 | 必须API Key | 必须配置API Key |
| arXiv | 建议3秒/次 | 无 | 无 | 每小时1000次限制 |
| Dimensions | 未公开 | 高 | 必须 | 商业级API配额 |

**核心解决方案：**

1. **令牌桶算法(Token Bucket)** - 平滑突发流量，适用于高并发控制场景
2. **漏桶算法(Leaky Bucket)** - 严格匀速输出，适用于下游服务保护
3. **指数退避重试** - 处理429错误，自动恢复
4. **多密钥轮换** - 扩展可用配额，适用于企业级应用
5. **本地缓存策略** - 减少重复请求，降低API调用次数
