## 1. 技术栈

```
React 18 + Vite + React Router v6 + Zustand + CSS Modules + D3.js
```

## 3. 实施步骤

### Step 1: 项目初始化
- `npm create vite@latest frontend -- --template react`
- 安装依赖：react-router-dom, zustand, d3, lucide-react
- 配置CSS变量和全局样式
- 配置Vite代理到后端API

### Step 2: 全局布局
- Layout组件（侧边栏 + 顶栏 + 内容区 + Scope栏）
- 路由配置（4个页面）
- 响应式布局

### Step 3: 论文库页面
- 论文卡片组件
- 搜索/筛选/排序
- 上传PDF交互
- 论文详情抽屉

### Step 4: 知识图谱页面
- D3力导向图
- 节点/边样式
- 交互（点击、拖拽、缩放）
- 节点详情面板

### Step 5: QA页面
- 对话界面
- 证据面板
- 引用标记交互
- Scope选择器

### Step 6: 报告页面
- 报告列表
- 报告预览（Markdown渲染）
- 创新点卡片
- 导出功能

### Step 7: 全局组件
- 命令面板
- 快捷键系统
- 加载/空状态

## 4. API对接

后端API前缀：`/api/rw/`

| 页面 | 主要API |
|------|---------|
| 论文库 | GET/POST projects, papers, upload |
| 图谱 | POST kg/build, GET kg |
| QA | POST qa |
| 报告 | POST reports/*, GET reports |

- [ ] 4个页面可切换

- [ ] 知识图谱可交互
- [ ] QA对话可用
