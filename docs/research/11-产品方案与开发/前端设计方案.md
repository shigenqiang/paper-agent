# 前端界面设计方案

> 设计时间：2026-06-01
> 产品：论文知识库分析 Agent
> 设计方向：学术研究工作站（Research Studio）

---

## 1. 设计理念

### 1.1 核心概念：数字研究工作室

不是普通的SaaS面板，而是一个**学者的工作台**。界面应该让人联想到：
- 深夜实验室的灯光
- 铺满论文的桌面
- 满墙的关系图谱
- 一本翻到一半的笔记本

**视觉基调**：深色背景 + 暖光高亮 + 纸张质感 + 手绘线条感

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **证据优先** | 每个信息都有来源，点击可追溯 |
| **范围可见** | 当前选择的QA范围始终可见 |
| **渐进披露** | 默认简洁，高级功能按需展开 |
| **键盘优先** | 命令面板 + 快捷键 |
| **非模态** | 侧边抽屉 > 弹窗，不打断工作流 |

### 1.3 参考产品分析

| 产品 | 借鉴点 | 应用位置 |
|------|--------|---------|
| **Elicit** | 证据表工作流、sentence-level引用 | QA页面 |
| **Connected Papers** | 力导向图谱、节点大小=引用数 | 知识图谱 |
| **NotebookLM** | Sources面板 + Chat + Artifact三栏 | 整体布局 |
| **Semantic Scholar** | 论文卡片、AI高亮 | 论文库 |
| **Readwise** | 键盘快捷键、命令面板 | 全局交互 |
| **Consensus** | 共识度量表 | 证据表 |

## 3. 页面结构

### 3.1 全局布局

```
┌─────────────────────────────────────────────────────────────┐
│  顶部导航栏（项目名 + 全局搜索 + 命令面板入口）               │
├────┬────────────────────────────────────────────────────────┤
│    │                                                        │
│ 侧 │                                                        │
│ 边 │              主内容区域                                 │
│ 导 │         （根据当前页面切换）                              │
│ 航 │                                                        │
│ 栏 │                                                        │
│    │                                                        │
├────┴────────────────────────────────────────────────────────┤
│  底部状态栏（当前Scope摘要 + 快捷操作）                       │
└─────────────────────────────────────────────────────────────┘
```

**侧边导航**：60px图标栏，hover展开标签
- 论文库 (Library)
- 知识图谱 (Graph)
- 研究QA (Research)
- 成果报告 (Reports)
- 设置 (Settings)

**底部Scope栏**：始终可见，显示当前选择的范围
- "全项目 · 23篇论文" 或 "主题: LLM反馈 · 5篇论文"
- 点击可修改范围

**论文卡片设计**：
- 深色卡片 + 左侧彩色条（状态色）
- 标题（衬线字体，2行截断）
- 作者（小字，逗号分隔）
- 年份 + 期刊/会议（标签样式）
- 状态徽标：已解析(绿) / 解析中(琥珀) / 已排除(红)
- 底部操作：查看卡片 | QA | 排除

**交互**：
- 点击卡片 → 右侧抽屉展开论文详情
- 多选模式 → 批量操作栏
- 拖拽上传PDF

### 3.3 知识图谱页面

```

│     节点颜色 = 类型         │  │ 相关论文:               │   │
│     边粗细 = 关系强度       │  │  · Attention Is All...  │   │
│                           │  │  · BERT: Pre-training... │   │
│                           │  │                         │   │

│                           │  └─────────────────────────┘   │
├───────────────────────────┴─────────────────────────────────┤

└─────────────────────────────────────────────────────────────┘
```

**图谱视觉**：
- 节点：圆形，大小按连接数缩放
- 节点颜色：Paper(蓝), Method(琥珀), Topic(绿), Finding(紫), Gap(红), Limitation(橙)
- 边：曲线，粗细按关系强度
- 选中节点：发光效果 + 扩展环
- hover：高亮相邻节点和边

**交互**：
- 点击节点 → 右侧面板显示详情
- 框选多个节点 → 加入子图
- 双击节点 → 以该节点为中心展开
- 滚轮缩放 + 拖拽平移

## 4. 组件设计

### 4.1 命令面板 (Command Palette)

`Ctrl+K` 唤起，支持：
- 搜索论文
- 跳转页面
- 执行操作（构建图谱、生成报告）
- 查看快捷键

### 4.2 论文详情抽屉

从右侧滑出，包含：
- 元数据（标题、作者、年份、DOI）
- 论文卡片（结构化摘要）
- 证据记录列表
- 图谱关联节点
- 操作按钮（纳入/排除、查看PDF、加入QA范围）

### 4.3 Scope选择器

底部常驻栏，支持：
- 全项目
- 选中论文列表
- 主题/方法/年份筛选
- 图谱子图
- 点击切换，实时更新

### 4.4 证据引用组件

```
[1] Vaswani et al. (2017) - "Attention Is All You Need"
    "缺乏长期依赖建模能力" (p.3, §2.1)
    [查看原文] [查看证据记录]
```

## 5. 动效设计

### 5.1 页面切换

- 侧边导航点击 → 内容区域淡入淡出（200ms）
- 当前页面图标有琥珀色指示条

### 5.2 卡片交互

- hover → 微微上浮 + 阴影增强
- 点击 → 抽屉滑入（300ms ease-out）
- 选中 → 左侧琥珀色条 + 背景微亮

### 5.3 图谱动画

- 节点出现 → 从小到大弹入（stagger 50ms）
- 边绘制 → 渐进出现
- 选中节点 → 呼吸发光效果

### 5.4 QA回答

- 打字机效果逐字显示
- 引用标记 [1] 高亮闪烁后常驻
- 证据面板同步滑入

## 8. 技术选型

| 组件 | 选择 | 理由 |
|------|------|------|
| 框架 | React 18 + Vite | 生态成熟，构建快 |
| 路由 | React Router v6 | 标准选择 |
| 状态 | Zustand | 轻量，适合中等复杂度 |
| 样式 | CSS Modules + CSS Variables | 无额外依赖，主题可控 |
| 图谱 | D3.js force-directed | 学术图谱标准方案 |
| 图标 | Lucide React | 轻量现代 |
| 字体 | Google Fonts | 免费，覆盖中英文 |
| HTTP | 原生 fetch | 简单场景够用 |
