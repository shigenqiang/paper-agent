```
                    ┌─────────────────────┐
                    │     论文来源         │

                              │
            ┌─────────────────┼─────────────────┐
            v                 v                 v
      ┌──────────┐    ┌──────────┐    ┌──────────┐
      │ 上传 PDF  │    │ 关键词   │    │ DOI/     │
      │          │    │ 检索     │    │ BibTeX   │
      └────┬─────┘    └────┬─────┘    └────┬─────┘
           │               │               │
           v               v               v
      ┌─────────────────────────────────────────┐
      │            Paper (IMPORTED)              │
      │  paper_id, title, abstract, authors,     │

      ┌─────────────────────────────────────────┐

      │  │ (L2 章节)    │──>│ (L3 文本块) │      │
      │  │ section_type │   │ parent_id   │      │
      │  │ claims       │   │ context_    │      │
      │  │ entities     │   │  summary    │      │
      │  └─────────────┘   └─────────────┘      │
      │                                          │

      │  └─────────────┘   └─────────────┘      │

```

**数据流说明：**

| 步骤 | 输入 | 输出 | 服务 |
|------|------|------|------|
| 入库 | 搜索结果/上传文件/DOI 列表 | Paper (IMPORTED) | PaperLibraryService |
| 下载 | Paper.open_access.pdf_url | 本地 PDF 文件 | ParserService.download_pdf() |
| 解析 | 本地 PDF 文件 | PaperSection + PaperChunk + Reference | ParserService.parse_paper() |
| 后处理 | 原始文本块 | 清洁文本块（上下文摘要） | TextPostProcessor + ChunkCleaner |

**数据流说明：**

| 步骤 | 输入 | 输出 | 服务 |
|------|------|------|------|
| 生成卡片 | PaperChunk + Paper | PaperCard | PaperCardGenerator |
| 生成证据 | PaperCard | EvidenceRecord | EvidenceTableService |
| 构建图谱 | EvidenceRecord + PaperCard | KnowledgeGraph | GraphService |
| Gap 检测 | KnowledgeGraph | GapAnalysisResult | GraphService.find_gaps() |
| GhostPaper | Reference.is_ghost=True | GhostPaperNode | GraphService |

|------|------|------|------|

| 反证检测 | InnovationPoint | counter_evidence + verification_status | CriticAgent |
| 幻觉检测 | Report | hv_ratio | LettuceDetect |
| 版本管理 | Report | ReportVersion | ReportService |

## 7. 质量控制贯穿路径

```
                    检索层                    生成层                检测层
                    ────                     ────                 ────
Phase 4 QA:
  ┌─────────────────────┐   ┌─────────────────────┐   ┌─────────────────────┐
  │ Contextual Retrieval│──>│ Scope 限制           │──>│ LettuceDetect       │
  │ + BM25 混合检索     │   │ + 范围声明           │   │ token-level 幻觉    │
  │ -67% 失败检索       │   │ + 不引用 Scope 外    │   │ H/V ratio < 0.1    │
  └─────────────────────┘   └─────────────────────┘   └─────────────────────┘

Phase 5 综述:
  ┌─────────────────────┐   ┌─────────────────────┐   ┌─────────────────────┐
  │ EvidenceRecord      │──>│ Review-Revise        │──>│ hv_ratio            │
  │ + PaperCard         │   │ Writer→Reviewer      │   │ evidence_coverage   │
```

```
│       │   └── {report_id}.json  ← Report + ReportVersion[]
│       └── files/
│           └── {paper_id}.pdf    ← PDF 文件

├── papers_pool/                  ← 全局论文池（跨项目共享）

│
├── search_cache.json             ← 搜索缓存
```
