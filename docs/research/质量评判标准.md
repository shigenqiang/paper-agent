# 论文生成质量评判标准

## 分数计算公式

```
final_score = avg_score × success_rate
```

- **avg_score**：所有 agent 的质量分数的算术平均值（无分数时默认 5.0）
- **success_rate**：成功 agent 数量 / 总 agent 数量

## 等级划分

| 等级 | 分数范围 |
|------|----------|
| excellent | ≥ 9.0 |
| good | ≥ 7.0 |
| acceptable | ≥ 5.0 |
| poor | < 5.0 |

## 问题类型（ProblemType）

### 选题相关
| 问题类型 | 描述 |
|----------|------|
| `topic_vague` | 选题模糊 |
| `topic_too_broad` | 选题太宽 |
| `topic_lack_novelty` | 缺乏创新 |

### 文献相关
| 问题类型 | 描述 |
|----------|------|
| `literature_insufficient` | 文献不足 |
| `literature_one_sided` | 综述片面 |
| `gap_not_identified` | 空白未识别 |

### 方法相关
| 问题类型 | 描述 |
|----------|------|
| `method_inappropriate` | 方法不当 |
| `method_not_rigorous` | 严谨性不足 |

### 论证相关
| 问题类型 | 描述 |
|----------|------|
| `argument_weak` | 论证薄弱 |
| `logic_incoherent` | 逻辑不连贯 |

### 内容相关
| 问题类型 | 描述 |
|----------|------|
| `abstract_repeats_conclusion` | 摘要重复结论 |
| `discussion_shallow` | 讨论浅薄 |

### 格式相关
| 问题类型 | 描述 |
|----------|------|
| `chart_poor` | 图表粗糙 |
| `language_poor` | 语言表达差 |
| `plagiarism_risk` | 查重风险 |

## 严重问题判定

severity（严重程度）≥ 0.7 的问题会被标记为严重问题（`critical_problems`）。

## 迭代重试机制

当 phase 的 `quality_score < 7.0` 且 `iteration < max_iterations` 时，会触发该 phase 的重试。

- **max_iterations**：默认 3 次

## 最终报告字段

Pipeline 执行完成后，`_compile_final_result()` 会输出以下字段：

| 字段 | 描述 |
|------|------|
| `quality_history` | 所有 phase 的质量分数演变列表 |
| `final_quality` | 最后一个质量分数 |
| `quality_level` | 根据分数计算的质量等级 |
| `problems_identified` | 发现的问题类型列表 |
| `iterations` | 当前迭代次数 |
