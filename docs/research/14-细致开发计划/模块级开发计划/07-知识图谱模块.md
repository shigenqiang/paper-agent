## 1. 模块定位

知识图谱处在证据表之后、Scope 和生成模块之前。它的核心价值是把分散的 EvidenceRecord 组织成图结构，使系统能够回答：

```text
哪些论文属于同一主题？
哪些论文使用相似方法？
哪些发现支持同一结论？
哪些局限共同指向同一个研究空白？
某个 gap 背后有哪些论文和证据？
两个主题、方法或论文之间通过什么路径相关？
当前选择的图谱子图能限定哪些 paper_ids 和 evidence_ids？
```

产品主线：

```text
研究项目
  -> 论文库
  -> PDF 解析与分块
  -> 论文卡片
  -> 证据表
  -> 知识图谱          <-- 本模块
  -> Retrieval Scope
  -> Scope-based QA
  -> 文献综述
  -> 创新点报告
```

## 3. 数据提取方案

### 3.1 输入数据结构

当前可直接用于构图的数据源：

```text

  evidence_id, paper_id, topic, research_question, method,
  data_or_sample, finding, limitation, future_work,
  evidence_strength, citation_context, source_chunk_id, source_quote

PaperCard（模型中定义）：
  paper_id, title, authors, year, topics, method,
  key_findings, limitations, possible_gaps, future_work,
  data_or_sample, research_question, abstract...

Paper（模型中定义）：
  paper_id, title, authors, year, doi, venue,
  abstract, references...

paper_sections（JSONB 字段，GraphExtractor 写入）：
  section_id, paper_id, section_type, section_title, text,
  entities[{name, type, description}],
  relations[{source_name, target_name, type, evidence_quote}],
  key_claims[{claim, evidence_quote}],
  methods_used[], datasets_used[], key_results[],
  limitations[], future_work[],
  extraction_status: "pending" | "done"
```

```python
def _add_task_node(self, nodes, edges, paper_node_id, research_question, ev):
    """从 EvidenceRecord.research_question 构建 Task 节点"""
    if not research_question or research_question.strip().lower() in ("", "unknown", "n/a"):
        return
    for rq in self._split_multi(research_question):
        normalized = normalize_label(rq)
        if not normalized:
            continue
        canonical = resolve_alias(normalized)
        task_id = f"task:{stable_hash(canonical)}"
        existing = next((n for n in nodes if n.node_id == task_id), None)
        if existing:
            self._merge_provenance(existing, ev)
        else:
            nodes.append(GraphNode(
                node_id=task_id,
                node_type=NodeType.TASK,
                label=rq.strip(),
                properties={
                    "normalized_label": canonical,
                    "paper_ids": [ev.paper_id],
                    "evidence_ids": [ev.evidence_id],
                    "source_chunk_ids": [ev.source_chunk_id] if ev.source_chunk_id else [],
                    "source_quotes": [ev.source_quote] if ev.source_quote else [],
                }
            ))
        edge_id = f"edge:STUDIES_TASK:{stable_hash(paper_node_id)}:{stable_hash(task_id)}"
        existing_edge = next((e for e in edges if e.edge_id == edge_id), None)
        if existing_edge:
            self._merge_edge_provenance(existing_edge, ev)
        else:
            edges.append(GraphEdge(
                edge_id=edge_id,
                source_id=paper_node_id,
                target_id=task_id,
                edge_type=EdgeType.STUDIES_TASK,
                properties={
                    "paper_ids": [ev.paper_id],
                    "evidence_ids": [ev.evidence_id],
                    "source_chunk_ids": [ev.source_chunk_id] if ev.source_chunk_id else [],
                }
            ))
```

#### G4.2 resolve_graph_scope 实现

**修改文件**：`src/agents_v3/research_workspace/graph_service.py`

**新增方法**：

```python
def resolve_graph_scope(
    self,
    project_id: str,
    graph_node_ids: list[str],
    graph_edge_ids: list[str] | None = None,
    hops: int = 1,
) -> dict:
    """
    将用户选择的图谱节点/边解析为 paper_ids + evidence_ids。
    供 RetrievalScopeService 使用。
    """
    graph = self.get_graph(project_id)
    if not graph:
        return {"paper_ids": [], "evidence_ids": [], "warnings": ["graph_not_found"]}

    # 从选中节点出发，获取子图
    subgraph = self.get_subgraph(project_id, graph_node_ids, hops=hops)

    # 收集所有 paper_ids 和 evidence_ids
    paper_ids = list(set(subgraph.get("related_paper_ids", [])))
    evidence_ids = list(set(subgraph.get("related_evidence_ids", [])))

    # 如果选中的是 Gap 节点，额外包含 supporting evidence
    for node_id in graph_node_ids:
        node = self.get_node(project_id, node_id)
        if node and node.node_type == NodeType.GAP:
            supporting = node.properties.get("supporting_evidence_ids", [])
            evidence_ids.extend(supporting)
            supporting_papers = node.properties.get("supporting_paper_ids", [])
            paper_ids.extend(supporting_papers)

    paper_ids = list(set(paper_ids))
    evidence_ids = list(set(evidence_ids))

    # 生成 scope summary
    node_map = {n.node_id: n for n in graph.nodes}
    selected_labels = [node_map[nid].label for nid in graph_node_ids if nid in node_map]
    summary = f"图谱子图范围：{', '.join(selected_labels[:5])}，包含 {len(paper_ids)} 篇论文、{len(evidence_ids)} 条证据"

    warnings = []
    if not paper_ids:
        warnings.append("scope_no_papers")
    if not evidence_ids:
        warnings.append("scope_no_evidence")
    if hops > 2:
        warnings.append("hops_truncated")

    return {
        "paper_ids": paper_ids,
        "evidence_ids": evidence_ids,
        "graph_node_ids": subgraph.get("selected_node_ids", graph_node_ids),
        "graph_edge_ids": [e.edge_id for e in subgraph.get("edges", [])],
        "scope_summary": summary,
        "warnings": warnings,
    }
```

**验收**：
- 选择 Topic 节点 → 解析出相关 paper_ids + evidence_ids
- 选择 Gap 节点 → 解析出 supporting_paper_ids + supporting_evidence_ids
- hops=2 时返回 warning
- 空 scope 返回 warnings

```python
def search_nodes(
    self,
    project_id: str,
    query: str,
    node_types: list[str] | None = None,
    top_k: int = 10,
) -> list[dict]:
    """简单 label 包含匹配搜索节点。P1 可接入 embedding/BM25。"""
    graph = self.get_graph(project_id)
    if not graph:
        return []
    query_lower = query.lower().strip()
    results = []
    for node in graph.nodes:
        if node_types and node.node_type.value not in node_types:
            continue
        label = node.label.lower()
        normalized = node.properties.get("normalized_label", "").lower()
        if query_lower in label or query_lower in normalized:
            results.append({
                "node_id": node.node_id,
                "node_type": node.node_type.value,
                "label": node.label,
                "paper_count": len(node.properties.get("paper_ids", [])),
                "evidence_count": len(node.properties.get("evidence_ids", [])),
            })
    return results[:top_k]
```

#### G5.2 build_graph_context 构建 GraphRAG 上下文

```python
def build_graph_context(
    self,
    project_id: str,
    graph_node_ids: list[str],
    hops: int = 1,
    token_budget: int = 4000,
) -> dict:
    """
    为 QA 构建紧凑的 GraphRAG 上下文。
    输出格式：
    [Graph Scope]
    Selected nodes: ...
    Related papers: p1, p2, p3

    [Key relations]
    Paper A --USES_METHOD--> Method X (ev1)
    Paper B --HAS_LIMITATION--> Limitation Y (ev2)

    [Evidence]
    ev1 | Paper A | method | quote...
    """
    scope = self.resolve_graph_scope(project_id, graph_node_ids, hops=hops)
    graph = self.get_graph(project_id)
    node_map = {n.node_id: n for n in graph.nodes}

    # 构建关系描述
    relations = []
    subgraph = self.get_subgraph(project_id, graph_node_ids, hops=hops)
    for edge in subgraph.get("edges", []):
        src = node_map.get(edge.source_id)
        tgt = node_map.get(edge.target_id)
        if src and tgt:
            ev_ids = edge.properties.get("evidence_ids", [])[:2]
            relations.append(
                f"{src.label} --{edge.edge_type.value}--> {tgt.label}"
                + (f" ({', '.join(ev_ids)})" if ev_ids else "")
            )

    # 构建上下文文本
    context_parts = [
        "[Graph Scope]",
        f"Selected: {', '.join(node_map[nid].label for nid in graph_node_ids if nid in node_map)}",
        f"Hops: {hops}",
        f"Related papers: {', '.join(scope['paper_ids'][:10])}",
        f"Related evidence: {len(scope['evidence_ids'])} records",
        "",
        "[Key Relations]",
        *relations[:20],
    ]

    text = "\n".join(context_parts)
    estimated_tokens = len(text) // 2  # 粗估

    return {
        "context_text": text,
        "paper_ids": scope["paper_ids"],
        "evidence_ids": scope["evidence_ids"],
        "estimated_tokens": estimated_tokens,
        "warnings": scope.get("warnings", []),
    }
```


#### G6.2 Method-Dataset 矩阵 Gap

```python
def _method_dataset_gaps(self, graph: KnowledgeGraph) -> list[dict]:
    """
    如果某 Method 从未在某 Dataset 上使用，可能是 gap。
    借鉴 Consensus 的 Research Gap Matrix。
    """
    # 构建 Method->Paper 和 Dataset->Paper 映射
    method_papers = {}
    dataset_papers = {}
    for edge in graph.edges:
        if edge.edge_type == EdgeType.USES_METHOD:
            method_papers.setdefault(edge.target_id, set()).add(edge.source_id)
        elif edge.edge_type == EdgeType.USES_DATASET:
            dataset_papers.setdefault(edge.target_id, set()).add(edge.source_id)

    gaps = []
    for method_id, mpapers in method_papers.items():
        for dataset_id, dpapers in dataset_papers.items():
            overlap = mpapers & dpapers
            if not overlap and len(mpapers) >= 2 and len(dpapers) >= 2:
                gaps.append({
                    "method_id": method_id,
                    "dataset_id": dataset_id,
                    "method_paper_count": len(mpapers),
                    "dataset_paper_count": len(dpapers),
                    "type": "method_dataset_gap",
                })
    return gaps
```

```python
def _build_ghost_papers(self, nodes, edges, papers):
    """
    GhostPaper: 被库中论文引用但本身不在库中的论文。
    借鉴 Literature Mapper。
    """
    # 收集所有 references
    all_refs = {}  # normalized_title -> cited_by_paper_ids
    paper_ids_in_project = {p.paper_id for p in papers}

    for paper in papers:
        if not hasattr(paper, "references") or not paper.references:

    # 找出被引用 >= 2 次且不在库中的
    for ref_key, info in all_refs.items():
        if len(info["cited_by"]) >= 2:
```

#### G9.1 Embedding 相似度合并

```python
def _merge_similar_entities(self, nodes: dict, edges: dict, threshold: float = 0.85) -> None:
    """
    对同类型节点，用 embedding 余弦相似度合并语义相同的实体。
    例如 "GPT-3" / "GPT3" / "GPT 3" → 同一节点。
    """
    from src.agents_v3.research_workspace.storage.embedding_provider import get_embedding_provider
    provider = get_embedding_provider()

    # 按 node_type 分组
    by_type: dict[str, list[str]] = {}
    for nid, node in nodes.items():
        if node.node_type != NodeType.PAPER:
            by_type.setdefault(node.node_type.value, []).append(nid)

    for ntype, nids in by_type.items():
        if len(nids) < 2:
            continue
        labels = [nodes[nid].label for nid in nids]
        embeddings = provider.embed_texts(labels)

        # 计算相似度矩阵，合并超过阈值的对
        merged: set[str] = set()
        for i, nid_i in enumerate(nids):
            if nid_i in merged:
                continue
            for j, nid_j in enumerate(nids):
                if j <= i or nid_j in merged:
                    continue
                sim = _cosine_similarity(embeddings[i], embeddings[j])
                if sim >= threshold:
                    self._merge_node(nodes, edges, nid_i, nid_j)
                    merged.add(nid_j)
```

### 5.2 normalize_label 增强

当前实现：lowercase + strip + compress whitespace + 去末尾 "s"。

需要增强：

```python
def normalize_label(text: str) -> str:
    if not text:
        return ""
    # 1. strip
    text = text.strip()
    # 2. lowercase
    text = text.lower()
    # 3. 全角转半角
    text = unicodedata.normalize("NFKC", text)
    # 4. 去除多余空白
    text = re.sub(r"\s+", " ", text)
    # 5. 去除末尾标点
    text = text.rstrip(".,;:。，；：")
    # 6. 中文标点归一
    text = text.replace("，", ",").replace("。", ".").replace("；", ";")
    # 7. hyphen/underscore 统一
    text = text.replace("_", " ").replace("-", " ")
    # 8. 常见复数归一（仅英文）
    if text.endswith("es") and len(text) > 4:
        text = text[:-2]
    elif text.endswith("s") and not text.endswith("ss") and len(text) > 3:
        text = text[:-1]
    # 9. alias 替换
    text = resolve_alias(text)
    return text
```

## 11. 技术调研结论（2026-06-04）

基于 5 项技术方法的深度调研，形成以下具体实现方案：

### 11.1 实体消歧（G9）— 调研结论

**推荐方案**：分层策略（非单一模型）

| 层级 | 方法 | 适用场景 | 精度 |
|------|------|---------|------|
| L1 | 精确匹配（normalize_label + alias 表） | 完全一致/大小写差异 | 100% |
| L2 | 编辑距离（Levenshtein ≤ 2） | 拼写变体（GPT-3/GPT3） | ~95% |
| L3 | SPECTER2 余弦相似度（≥0.85） | 语义相同但表述不同 | ~88% |
| L4 | LLM 辅助判断 | 边界情况 | ~90% |

**关键参数**：
- SPECTER2：768 维，~440MB，需 GPU 推荐
- all-MiniLM-L6-v2：384 维，~80MB，CPU 可用
- 阈值：同类型节点 embedding 余弦相似度 ≥ 0.85 合并

**实现要点**：先按 node_type 分组，组内两两计算相似度，合并时迁移边的 provenance。

### 11.2 社区检测 + Global Search（G11）— 调研结论

**关键发现**：Microsoft GraphRAG 使用 `graspologic-native` 库（非 `leidenalg`）做层次化 Leiden。

**推荐方案**：

```text
1. 安装 graspologic-native（pip install graspologic-native）
2. 调用 hierarchical_leiden(graph, max_cluster_size=10)
   → 产出多层次社区结构（level 0 → level N）
3. 为每个社区生成 LLM 摘要（title + summary + rating + findings）
4. Global Search: Map-Reduce 两阶段
   - Map: 每个社区批次 → LLM → {points: [{description, score}]}
   - Reduce: 所有 map 响应按 score 排序 → LLM → 最终回答
```

**社区报告 Prompt 结构**：
- 输出 JSON：`{title, summary, rating(0-10), findings: [{summary, explanation, data_source}]}`
- 每个 finding 必须引用数据来源（node_id 或 edge_id）

**Dynamic Community Selection**：从根社区开始，逐层评估相关性，只处理评分 >= threshold 的社区。

### 11.3 引用网络（G8）— 调研结论

**推荐工具链**：

| 步骤 | 工具 | 说明 |
|------|------|------|
| PDF reference extraction | **GROBID**（~13k Stars） | Docker 部署，输出 TEI XML，内置 CrossRef DOI 解析 |
| 引用关系获取 | **Semantic Scholar API** | 200M+ papers，免费 100 req/5min |
| 元数据补充 | **OpenAlex API** | 200M+ works，完全免费 CC0 |
| 作者消歧 | **ORCID + OpenAlex** | ORCID 作为锚点，OpenAlex MAG 算法辅助 |

**GROBID 输出格式**：
```xml
<TEI>
  <biblStruct xml:id="b0">
    <analytic><title>...</title><author>...</author></analytic>
    <monogr><imprint><date>...</date></imprint></monogr>
    <idno type="DOI">10.xxx/yyy</idno>
  </biblStruct>
</TEI>
```

**实现流程**：
1. PDF → GROBID → TEI XML → 解析 reference list
2. 每个 reference 用 DOI/title 查询 Semantic Scholar API → 获取 cited_paper_id
3. 构建 CITES 边：paper → cited_paper
4. 未匹配的 references → GhostPaper 节点
5. Paper.authors → Author 节点 + AUTHORED_BY 边

### 11.4 引用立场分类 — 调研结论

**推荐三阶段方案**：

| 阶段 | 方法 | 精度 | 适用场景 |
|------|------|------|---------|
| 阶段一 | DeBERTa-MNLI 零样本 | 80-85% F1 | 冷启动，无需训练数据 |
| 阶段二 | SciBERT 微调（SciCite 数据集） | 83-85% F1 | 生产环境 |
| 阶段三 | SPECTER2 微调 | 86-88% F1 | 最高精度 |

**训练数据**：SciCite 数据集（github.com/allenai/scicite），三分类：Supporting / Contrasting / Mentioning。

**集成方式**：分类结果写入边的 `properties.stance` 字段，替代当前的 `evidence_strength`。

### 11.5 Consensus Meter — 调研结论

**推荐三阶段实现**：

| 阶段 | 方法 | 说明 |
|------|------|------|
| MVP | LLM Zero-shot 判断 | 每篇论文的 finding → LLM 判断 {supports, contradicts, neutral} |
| 质量加权 | 加入 evidence_strength 权重 | high=1.0, medium=0.6, low=0.3 |
| 高级版本 | NLI Fine-tuned 模型 | 用 SciFact 数据集训练分类器 |

**Claim 归一化方案**：先用 normalize_label 做精确匹配，再用 embedding 相似度（≥0.85）做语义合并，最后 LLM 确认是否指向同一 claim。

**Prompt 模板（MVP）**：
```text
Given a research claim: "{claim}"
And a finding from a paper: "{finding}"
判断该 finding 对 claim 的立场：
- supports: 支持/证实该 claim
- contradicts: 反对/反驳该 claim  
- neutral: 仅提及但不表态
输出 JSON: {"stance": "supports|contradicts|neutral", "confidence": 0.0-1.0}
```
