### 数据关联路径（paper_id 三表联动）

```text
┌──────────────────────────────────────────────────────────────────┐
│  PostgreSQL papers 表                                            │
│  paper_id（主键）← 所有下游引用的锚点                            │
│  title / abstract / authors / year / venue / doi / source_platform│
└──────────────┬───────────────────────────────────────────────────┘
│ paper_id
       ┌───────┼───────┐
       ▼       ▼       ▼
┌──────────┐ ┌──────────┐ ┌──────────┐
│ Qdrant   │ │ Qdrant   │ │ Qdrant   │
│ L0       │ │ L1       │ │ L2       │
│paper_prof│ │paper_sec │ │paper_chk │
│iles      │ │tions     │ │unks      │
│          │ │          │ │          │
│dense+sp  │ │dense+sp  │ │dense+sp  │
│论文级向量 │ │章节级向量 │ │chunk级向量│
│title+abs │ │summary   │ │child only│
│          │ │          │ │          │
│metadata: │ │metadata: │ │metadata: │
│ paper_id │ │ paper_id │ │ paper_id │
│ project_id│ │ section_ │ │ section_id│
│ title    │ │ type     │ │ section_ │
│          │ │ section_ │ │ type     │
│          │ │ title    │ │ chunk_   │
│          │ │ project_id│ │ type     │
│          │ │          │ │ parent_id│
│          │ │          │ │ page_*   │
│          │ │          │ │ token_   │
│          │ │          │ │ count    │
└──────────┘ └──────────┘ └──────────┘

embed_paper() 三写：
  ① paper_chunks：每个 child chunk 一个向量点（L2）
  ② paper_profiles：每篇论文一个向量点 title+abstract（L0）
  ③ paper_sections：每个有 summary 的章节一个向量点（L1）

HierarchicalRetriever 渐进式检索：
  L0(project_id filter) → L1(paper_id filter) → L2(section_id filter)
  回退：L0 为空 → flat L2；L1 为空 → L2 with paper_ids

云端推理：Qdrant 自动生成 dense + sparse 向量
本地模式：EmbeddingService 预计算 dense + TF-IDF sparse
```

## 09b-HierarchicalRetriever 渐进式检索

### 在系统中的角色

HierarchicalRetriever 是三层渐进式向量检索服务，利用 Qdrant 的 L0/L1/L2 三层集合实现从论文→章节→chunk 的逐层精筛。它为 ScopeQA 提供向量检索能力，替代纯元数据过滤。

### 模块架构

```text
┌────────────────────────────────────────────────────────────────────────┐
│        HierarchicalRetriever（~300 行 / 10 方法）                      │
│                                                                        │
│  retrieve(query_text, project_id, top_k_*) ──▶ 渐进式检索              │
│       │                                                                │
│       ▼                                                                │
│  ① _embed_query(text) → (dense_emb, sparse_emb)                       │
│       │   云端推理：返回空占位（search_hybrid_by_text 自动处理）        │
│       │   本地模式：EmbeddingService.embed_query + embed_sparse        │
│       │                                                                │
│       ▼                                                                │
│  ② L0: _search_l0 → paper_profiles（project_id 过滤）                  │
│       │   → top_k_papers 个 paper_id                                  │
│       │   若 L0 为空 → 直接回退到 flat L2 检索                         │
│       │                                                                │
│       ▼                                                                │
│  ③ L1: _search_l1 → paper_sections（L0 的 paper_ids 过滤）            │
│       │   → top_k_sections 个 section_id                              │
│       │   若 L1 为空 → 用 paper_ids 直接搜 L2                         │
│       │                                                                │
│       ▼                                                                │
│  ④ L2: _search_l2 → paper_chunks（L1 的 section_ids 过滤）            │
│       │   → top_k_chunks 个 chunk                                     │
│       │   若结果太少（< top_k//3）→ 用 paper_ids 重搜                  │
│       │                                                                │
│       ▼                                                                │
│  ⑤ _enrich_with_context(l2, l1, l0) → list[RetrievalResult]           │
│       │   合并 paper_title / section_title / section_type              │
│       │   layer_scores: {"l0": 0.9, "l1": 0.85, "l2": 0.78}          │
│       │                                                                │
│       ▼                                                                │
│  RetrievalResult + RetrievalDiagnostics                                │
│                                                                        │
│  ──────────────── 回退策略 ────────────────                            │
│  L0 为空 → retrieve_flat_fallback（L2 + project_id where 过滤）        │
│  L1 为空 → L2 + paper_ids 过滤                                        │
│  L2 section_id 过滤太少 → L2 + paper_ids 重搜                         │
│  fallback_used / fallback_reason 记录在 diagnostics 中                 │
│                                                                        │
│  ──────────────── 依赖 ────────────────                                │
│  storage.vector.VectorStorage（search_hybrid 含 where 过滤）           │
│  storage.embedding.EmbeddingService（本地模式）                        │
│  storage.json_storage.JSONStorage（paper/section 上下文补充）          │
└────────────────────────────────────────────────────────────────────────┘
```

### 已实现能力

| 方法 | 功能 |
| --- | --- |
| retrieve | 渐进式 L0→L1→L2 检索，自动回退，返回 (results, diagnostics) |
| retrieve_flat_fallback | L0/L1 为空时的 L2 直搜回退（project_id where 过滤） |

## 10-综述生成
