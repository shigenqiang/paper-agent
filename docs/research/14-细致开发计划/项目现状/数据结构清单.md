## 存储架构：PostgreSQL vs Qdrant 职责划分

### 核心原则

**PostgreSQL 管"存什么"，Qdrant 管"怎么找"。**

PostgreSQL 是系统的事实源（source of truth），存储全部结构化业务数据。Qdrant 是检索加速器，只存储需要被向量搜索的文本子集及其向量。

### 存储内容对比

| 维度 | PostgreSQL（17 张表） | Qdrant（2 个集合） |
|------|----------------------|-------------------|
| papers | 完整记录：title/abstract/authors/year/venue/doi/identifiers/classify/status/source_platform 等 30+ 字段 | paper_profiles 仅存 title+abstract 文本 + 向量，metadata 仅 paper_id/project_id/title |
| paper_chunks | 解析结果、chunk 元数据（完整字段见 2.1） | chunk 文本 + 向量，metadata 仅 7 字段（paper_id/section_type/chunk_type/parent_id/page_start/page_end/token_count） |
| paper_cards | 完整卡片：research_question/method/findings/limitations/future_work/source_spans/quality_score | 不存储 |
| evidence_records | 完整证据：topic/finding/limitation/method/evidence_strength/source_chunk_id/source_quote | 不存储 |
| graphs | 节点/边/关系/GAP | 不存储 |
| reports | 综述/创新点报告全文 + 版本历史 | 不存储 |
| search_sessions | 搜索会话、候选列表、提交状态 | 不存储 |
| 其他 | qa_history/tasks/report_versions/topic_scores/search_cache 等 | 不存储 |

### Qdrant 集合详情

#### paper_chunks（chunk 级向量）

```text
向量：dense（sentence-transformers/all-MiniLM-L6-v2）+ sparse（Qdrant/bm25）
用途：ScopeQA 精细检索，按 chunk 返回最相关文本片段
写入时机：embed_paper() 解析后双写
过滤维度：paper_id / section_type / chunk_type
```

#### paper_profiles（论文级向量）

```text
向量：dense（sentence-transformers/all-MiniLM-L6-v2）+ sparse（Qdrant/bm25）
用途：search_for_review 快速论文级检索，按论文粒度返回最相关论文
写入时机：embed_paper() 解析后双写（title + abstract 拼接）
过滤维度：paper_id / project_id
```

### 数据流方向

```text
PostgreSQL (写入) ──embed_paper()──▶ Qdrant (写入)
     │                                    │
     │ 业务逻辑读写                        │ 仅检索读取
     ▼                                    ▼
 卡片/证据/图谱/报告               ScopeQA / search_for_review
```

Qdrant 的数据是 PostgreSQL 的子集的向量化投影。没有 PostgreSQL 就没有完整的论文库、卡片、证据、图谱和报告；没有 Qdrant 只是失去向量检索能力，退化为关键词搜索。

┌──────────────┐  ┌──────────────┐

│ paper_chunks │  │ paper_profiles│

### embed_paper() 双写逻辑

```text
① paper_chunks：每个 child chunk 一个向量点（跳过 parent 块）
② paper_profiles：每篇论文一个向量点（title + abstract 拼接）

云端推理（cloud_inference=true）：Qdrant 自动生成 dense + sparse 向量，传文本即可
本地模式：EmbeddingService 预计算 dense（bge-small-zh）+ TF-IDF sparse
```
