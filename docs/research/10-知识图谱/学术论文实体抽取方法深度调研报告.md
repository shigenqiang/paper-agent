## 1. 学术论文中的实体类型体系

### 1.1 SciERC标准实体类型（最权威基准）

SciERC (Luan et al., EMNLP 2018) 是最权威的科学信息抽取基准数据集，来自500篇AI领域论文摘要的人工标注。定义了6种实体类型：

| 实体类型 | 定义 | 示例 |
|---------|------|------|
| **Task** | 研究任务、问题、目标 | NER, machine translation, sentiment analysis |
| **Method** | 算法、模型、技术、系统 | BERT, LSTM, transformer, CRF |
| **Material** | 数据集、语料库、资源 | CoNLL-2003, ImageNet, Wikipedia |
| **Metric** | 评估指标、分数 | F1 score, BLEU, accuracy |
| **Other-ScientificTerm** | 不属于其他类别的科技术语 | features, embeddings, attention |
| **Generic** | 通用科学术语 | approach, model, system |

**来源**: https://nlp.cs.washington.edu/sciIE/

### 1.2 扩展实体类型体系（面向完整知识图谱）

在SciERC基础上，面向论文知识图谱的完整构建，需要扩展更多实体类型：

| 实体类型 | 定义 | 来源章节 | 示例 |
|---------|------|---------|------|
| **Paper** | 论文本身 | 元数据 | 标题、DOI |
| **Author** | 作者 | 元数据 | 人名 |
| **Affiliation** | 机构 | 元数据 | 清华大学、Google |
| **Venue** | 期刊/会议 | 元数据 | ACL, NeurIPS, Nature |
| **Theory** | 理论、定理 | Introduction/Discussion | No Free Lunch theorem |
| **Concept** | 概念、定义 | Introduction | attention mechanism |
| **Tool** | 工具、软件 | Methods | PyTorch, TensorFlow |
| **Framework** | 框架、平台 | Methods | HuggingFace, LangChain |
| **ResearchGap** | 研究空白 | Discussion | "缺乏对X的研究" |
| **Limitation** | 局限性 | Discussion | "样本量不足" |
| **Finding** | 发现、结论 | Results | "提升了3%的F1" |
| **Contribution** | 贡献声明 | Conclusion | "首次提出..." |

### 1.3 不同论文类型的实体分布

| 论文类型 | 核心实体 | 次要实体 | 典型密度 |
|---------|---------|---------|---------|
| 实验论文 | Method, Material, Metric, Finding | Task, Dataset | 高（每段3-5个） |
| 综述论文 | Task, Method, Finding, Gap | Limitation, InnovationPoint | 极高（每段5-10个） |
| 理论论文 | Method, Task, Finding, Theory | Concept | 中（每段2-3个） |
| 基准论文 | Dataset, Metric, Method, Task | Finding | 高（表格密集） |

### 1.4 实体类型统计（SciERC数据集）

在SciERC的标注数据中，各实体类型的分布：

| 实体类型 | 数量 | 占比 |
|---------|------|------|
| Method | ~3,200 | 28% |
| Task | ~2,800 | 24% |
| Material | ~1,900 | 16% |
| Other-ScientificTerm | ~2,100 | 18% |
| Metric | ~900 | 8% |

**核心发现**: Method和Task是最常见的实体类型，占总量的52%。这与学术论文的核心功能一致——描述"用什么方法解决什么问题"。

## 2. 传统NER方法

### 2.1 CRF序列标注

**原理**: 条件随机场（Conditional Random Field）是一种判别式概率图模型，通过定义条件概率 $P(Y|X)$ 来建模标签序列的联合概率。核心是利用特征函数捕捉标签之间的转移关系。

**关键特点**:
- 全局最优标签序列：考虑整个序列的标签转移概率
- 特征工程依赖：需要手工设计特征模板
- 训练高效：凸优化，全局最优解

**特征模板示例**:
```
# 当前词特征
U00:%x[-1,0]    # 前一个词
U01:%x[0,0]     # 当前词
U02:%x[1,0]     # 后一个词
U03:%x[-1,0]/%x[0,0]  # 前词+当前词

# 词性特征
U10:%x[-1,1]
U11:%x[0,1]

# 转移特征
B
```

**代码示例（伪代码）**:
```python
import sklearn_crfsuite

# 特征提取
def word2features(sent, i):
    word = sent[i][0]
    features = {
        'word.lower()': word.lower(),
        'word[-3:]': word[-3:],       # 后缀
        'word[-2:]': word[-2:],
        'word.isupper()': word.isupper(),
        'word.istitle()': word.istitle(),
        'word.isdigit()': word.isdigit(),
    }
    if i > 0:
        word1 = sent[i-1][0]
        features.update({
            '-1:word.lower()': word1.lower(),
            '-1:word.istitle()': word1.istitle(),
        })
    else:
        features['BOS'] = True  # 句首
    if i < len(sent)-1:
        word1 = sent[i+1][0]
        features.update({
            '+1:word.lower()': word1.lower(),
            '+1:word.istitle()': word1.istitle(),
        })
    else:
        features['EOS'] = True  # 句尾
    return features

# 训练CRF模型
crf = sklearn_crfsuite.CRF(
    algorithm='lbfgs',
    c1=0.1, c2=0.1,
    max_iterations=100,
    all_possible_transitions=True
)
crf.fit(X_train, y_train)

# 预测
y_pred = crf.predict(X_test)
```

**准确率**:

| 数据集 | F1 Score | 备注 |
|-------|----------|------|
| CoNLL-2003（通用） | ~84-87% | 依赖特征工程质量 |
| SciERC（学术） | ~55-62% | 学术术语复杂 |
| BC5CDR（生物医学） | ~80-84% | 领域术语密集 |

**适用场景**:
- 标注数据较少（<1000条）
- 需要快速部署、低计算资源
- 实体边界清晰、规则可枚举的场景
- 作为基线模型

### 2.2 BiLSTM-CRF

**原理**: 结合双向LSTM的上下文编码能力和CRF的全局序列解码能力。BiLSTM自动学习上下文特征表示，替代手工特征工程；CRF层确保输出的标签序列满足转移约束（如I-PER不能接在B-LOC之后）。

**模型架构**:
```
输入文本 → 词嵌入(Word2Vec/GloVe) → BiLSTM编码 → 线性层 → CRF解码 → 标签序列
```

**核心优势**:
- 自动特征学习：无需手工设计特征
- 双向上下文：捕获前后文信息
- 全局最优：CRF层保证标签序列合法性

**代码示例（伪代码）**:
```python
import torch
import torch.nn as nn

class BiLSTM_CRF(nn.Module):
    def __init__(self, vocab_size, tag_to_ix, embedding_dim, hidden_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim // 2,
                           num_layers=1, bidirectional=True)
        self.hidden2tag = nn.Linear(hidden_dim, len(tag_to_ix))
        # CRF转移矩阵
        self.transitions = nn.Parameter(
            torch.randn(len(tag_to_ix), len(tag_to_ix))
        )

    def _get_lstm_features(self, sentence):
        embeds = self.embedding(sentence)
        lstm_out, _ = self.lstm(embeds.view(len(sentence), 1, -1))
        lstm_out = lstm_out.view(len(sentence), -1)
        return self.hidden2tag(lstm_out)

    def forward(self, sentence):
        lstm_features = self._get_lstm_features(sentence)
        # CRF解码（Viterbi算法）
        score, tag_seq = self._viterbi_decode(lstm_features)
        return score, tag_seq

# 训练
model = BiLSTM_CRF(vocab_size, tag_to_ix, EMBEDDING_DIM, HIDDEN_DIM)
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, weight_decay=1e-4)

for epoch in range(num_epochs):
    for sentence, tags in training_data:
        model.zero_grad()
        loss = model.neg_log_likelihood(sentence, tags)
        loss.backward()
        optimizer.step()
```

**准确率**:

| 数据集 | F1 Score | 备注 |
|-------|----------|------|
| CoNLL-2003（通用） | ~91-92% | 经典SOTA |
| SciERC（学术） | ~67-72% | 学术术语挑战 |
| BC5CDR（生物医学） | ~85-91% | 领域适应后 |
| JNLPBA（生物医学） | ~72-76% | 嵌套实体挑战 |

**适用场景**:
- 标注数据中等规模（1000-10000条）
- 需要自动学习特征
- 序列标签之间有强依赖关系
- 计算资源有限但需要较好性能

### 2.3 BERT-NER / SciBERT-NER

**原理**: 利用预训练语言模型（BERT/SciBERT）的上下文表示能力，通过微调（fine-tuning）进行token分类。BERT通过Transformer架构捕获长距离依赖，SciBERT在1.14M科学论文上预训练，使用领域特定词表（SciVocab）。

**SciBERT关键特性**:
- 预训练数据：Semantic Scholar的1.14M篇论文（PubMed + arXiv）
- 词表：SciVocab（领域特定WordPiece词表）
- 模型架构：与BERT-base相同（12层，768维，12头）
- 参数量：~110M

**模型架构**:
```
输入文本 → BERT/SciBERT编码 → [CLS] + 各token表示 → 线性分类层 → 标签序列
```

**代码示例（伪代码）**:
```python
from transformers import AutoTokenizer, AutoModelForTokenClassification
from transformers import TrainingArguments, Trainer
import torch

# 加载SciBERT
model_name = "allenai/scibert_scivocab_uncased"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForTokenClassification.from_pretrained(
    model_name,
    num_labels=len(label_list),  # 实体标签数量
    id2label=id2label,
    label2id=label2id
)

# 数据预处理
def tokenize_and_align_labels(examples):
    tokenized_inputs = tokenizer(
        examples["tokens"],
        truncation=True,
        is_split_into_words=True,
        max_length=512
    )
    labels = []
    for i, label in enumerate(examples["ner_tags"]):
        word_ids = tokenized_inputs.word_ids(batch_index=i)
        label_ids = []
        previous_word_idx = None
        for word_idx in word_ids:
            if word_idx is None:
                label_ids.append(-100)  # 忽略特殊token
            elif word_idx != previous_word_idx:
                label_ids.append(label[word_idx])
            else:
                label_ids.append(-100)  # 忽略子词
            previous_word_idx = word_idx
        labels.append(label_ids)
    tokenized_inputs["labels"] = labels
    return tokenized_inputs

# 训练
training_args = TrainingArguments(
    output_dir="./scibert-ner",
    learning_rate=2e-5,
    per_device_train_batch_size=16,
    num_train_epochs=5,
    weight_decay=0.01,
    evaluation_strategy="epoch",
    save_strategy="epoch",
    load_best_model_at_end=True,
)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    tokenizer=tokenizer,
)
trainer.train()
```

**准确率对比**:

| 模型 | SciERC NER F1 | CoNLL-2003 F1 | BC5CDR F1 | 备注 |
|------|--------------|---------------|-----------|------|
| BERT-base | ~63-65% | ~92-93% | ~88-90% | 通用基线 |
| SciBERT | ~65-67% | ~91-92% | ~92-93% | 科学领域优化 |
| PubMedBERT | ~64-66% | ~90-91% | ~93-94% | 生物医学专精 |
| BioBERT | ~64-66% | ~91-92% | ~92-93% | 生物医学 |

- 标注数据充足（>5000条）

### 2.4 学术领域专用NER模型

#### 2.4.1 SciREX

**原理**: 面向科学论文的端到端信息抽取系统，同时进行实体识别、关系抽取和摘要生成。采用span-based方法，直接预测实体边界和类型。

**特点**:
- 全文级抽取（不仅限摘要）
- 支持嵌套实体
- 联合训练实体和关系

#### 2.4.2 DyREx

**原理**: 动态关系抽取方法，根据上下文动态调整关系分类策略。使用注意力机制加权不同上下文窗口的信息。

#### 2.4.3 多模态NER

**原理**: 结合论文中的图表信息增强实体识别。例如，从表格标题中识别数据集名称，从图表说明中识别方法名称。

**代码示例（伪代码）**:
```python
# 多模态学术NER示例
class MultimodalSciNER(nn.Module):
    def __init__(self, text_encoder, image_encoder, num_labels):
        super().__init__()
        self.text_encoder = text_encoder  # SciBERT
        self.image_encoder = image_encoder  # ResNet/ViT
        self.fusion = nn.MultiheadAttention(embed_dim=768, num_heads=8)
        self.classifier = nn.Linear(768, num_labels)

    def forward(self, input_ids, attention_mask, image_features):
        # 文本编码
        text_features = self.text_encoder(input_ids, attention_mask)
        # 图像编码
        img_features = self.image_encoder(image_features)
        # 跨模态注意力融合
        fused, _ = self.fusion(text_features, img_features, img_features)
        # 分类
        logits = self.classifier(fused)
        return logits
```

## 3. LLM驱动的实体抽取

### 3.1 用GPT-4/Claude做Few-Shot实体抽取

**原理**: 利用大语言模型的in-context learning能力，通过精心设计的prompt（包含少量示例），引导LLM从论文文本中抽取结构化实体。无需训练，无需标注数据。

**核心优势**:
- 零样本/少样本：无需大规模标注数据
- 灵活Schema：可随时调整实体类型定义
- 上下文理解：能处理复杂的学术表述
- 跨领域通用：同一prompt可适用于不同学科

**核心劣势**:
- 推理成本高：每次调用都有API费用
- 延迟较大：不适合实时批量处理
- 输出不稳定：同一输入可能产生不同结果
- 长文本限制：需要分块处理长论文

### 3.2 结构化Prompt设计

**Prompt设计原则**:

1. **角色设定**: 明确LLM扮演的专家角色
2. **Schema定义**: 清晰定义实体类型和边界
3. **Few-Shot示例**: 提供2-5个高质量示例
4. **输出格式**: 指定JSON输出格式
5. **约束条件**: 处理边界情况的规则

**完整Prompt模板**:

```python

### 3.5 LLM抽取的最佳实践

**1. 分块策略**:
```python
def chunk_for_extraction(text, max_tokens=2000):
    """按段落分块，保持上下文完整性"""
    paragraphs = text.split('\n\n')
    chunks = []
    current_chunk = []
    current_len = 0
    for para in paragraphs:
        para_len = count_tokens(para)
        if current_len + para_len > max_tokens:
            chunks.append('\n\n'.join(current_chunk))
            current_chunk = [para]
            current_len = para_len
        else:
            current_chunk.append(para)
            current_len += para_len
    if current_chunk:
        chunks.append('\n\n'.join(current_chunk))
    return chunks
```

**2. 结果聚合与去重**:
```python
def merge_extraction_results(results_list):
    """合并多个chunk的抽取结果，去重并统一实体ID"""
    all_entities = {}
    all_relations = []
    entity_id_map = {}  # text -> unified_id

    for result in results_list:
        for entity in result['entities']:
            key = (entity['text'].lower(), entity['type'])
            if key not in all_entities:
                unified_id = f"e{len(all_entities)}"
                entity_id_map[entity['id']] = unified_id
                all_entities[key] = {
                    **entity,
                    'id': unified_id,
                    'mentions': [entity]
                }
            else:
                all_entities[key]['mentions'].append(entity)

        for relation in result['relations']:
            head_id = entity_id_map.get(relation['head'])
            tail_id = entity_id_map.get(relation['tail'])
            if head_id and tail_id:
                all_relations.append({
                    **relation,
                    'head': head_id,
                    'tail': tail_id
                })

    return {
        'entities': list(all_entities.values()),
        'relations': all_relations
    }
```

**3. 置信度校准**:
```python
def calibrate_confidence(llm_output, calibration_set):
    """使用校准集调整LLM输出的置信度"""
    # LLM的置信度通常偏高，需要校准
    for entity in llm_output['entities']:
        # 基于实体类型和上下文调整置信度
        if entity['type'] in ['Method', 'Dataset']:
            entity['confidence'] *= 0.9  # 这些类型更容易误判
        if len(entity['text']) < 3:
            entity['confidence'] *= 0.8  # 短实体更容易误判
    return llm_output
```

## 4. 关系抽取方法

### 4.1 远程监督（Distant Supervision）

**原理**: 利用已有的知识库（如DBpedia、Wikidata）自动标注训练数据。核心假设：如果两个实体在知识库中存在某种关系，那么包含这两个实体的所有句子都可能表达这种关系。

**优势**:
- 无需人工标注
- 可大规模生成训练数据

**劣势**:
- 噪声标注：假设过于强烈，产生大量错误标注
- 关系类型受限于知识库

**代码示例（伪代码）**:
```python
class DistantSupervision:
    def __init__(self, knowledge_base):
        self.kb = knowledge_base  # 已有知识库

    def annotate(self, sentences, entity_pairs):
        """远程监督标注"""
        annotated = []
        for sent, (e1, e2) in zip(sentences, entity_pairs):
            # 查询知识库
            relation = self.kb.query(e1, e2)
            if relation:
                annotated.append({
                    'sentence': sent,
                    'entity1': e1,
                    'entity2': e2,
                    'relation': relation
                })
            else:
                annotated.append({
                    'sentence': sent,
                    'entity1': e1,
                    'entity2': e2,
                    'relation': 'NO_RELATION'
                })
        return annotated

    def bag_level_training(self, annotated_data):
        """包级别训练（减少噪声影响）"""
        # 将相同实体对的句子分组
        bags = defaultdict(list)
        for item in annotated_data:
            key = (item['entity1'], item['entity2'], item['relation'])
            bags[key].append(item['sentence'])
        # 对每个包进行训练
        return bags
```

**准确率**:

| 方法 | NYT数据集 F1 | 备注 |
|------|-------------|------|
| PCNN+ATT | ~72-76% | 包级别注意力 |
| BERT+Distant Supervision | ~78-82% | 预训练模型提升 |
| GPT-4远程监督 | ~75-80% | LLM过滤噪声 |

### 4.2 关系分类模型

**原理**: 给定一个句子和其中的两个实体，判断它们之间是否存在关系以及关系类型。典型方法是将实体位置信息注入到句子表示中，然后进行分类。

**主流架构**:

#### 4.2.1 CNN+Attention
```python
class CNN_ATT_Relation(nn.Module):
    def __init__(self, vocab_size, embed_dim, num_filters, num_relations):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.conv = nn.Conv1d(embed_dim, num_filters, kernel_size=3, padding=1)
        self.attention = nn.Linear(num_filters, 1)
        self.classifier = nn.Linear(num_filters, num_relations)

    def forward(self, input_ids, e1_pos, e2_pos):
        # 词嵌入
        embeds = self.embedding(input_ids)
        # CNN编码
        conv_out = self.conv(embeds.transpose(1, 2)).transpose(1, 2)
        # 注意力加权
        att_weights = torch.softmax(self.attention(conv_out), dim=1)
        sentence_repr = torch.sum(att_weights * conv_out, dim=1)
        # 关系分类
        logits = self.classifier(sentence_repr)
        return logits
```

#### 4.2.2 BERT+Entity Marker
```python
class BERT_Relation(nn.Module):
    def __init__(self, model_name, num_relations):
        super().__init__()
        self.bert = AutoModel.from_pretrained(model_name)
        self.classifier = nn.Linear(768 * 2, num_relations)  # 实体对表示拼接

    def forward(self, input_ids, attention_mask, e1_start, e2_start):
        # BERT编码
        outputs = self.bert(input_ids, attention_mask=attention_mask)
        sequence_output = outputs.last_hidden_state

        # 提取实体位置的表示
        e1_repr = sequence_output[torch.arange(len(e1_start)), e1_start]
        e2_repr = sequence_output[torch.arange(len(e2_start)), e2_start]

        # 拼接实体表示
        pair_repr = torch.cat([e1_repr, e2_repr], dim=-1)

        # 分类
        logits = self.classifier(pair_repr)
        return logits
```

| 方法 | SciERC RE F1 | SemEval F1 | 备注 |

### 4.4 学术论文中的特殊关系类型

#### 4.4.1 共现关系（Co-occurrence）
**原理**: 两个实体在同一段落/句子中共同出现，可能暗示某种关联。

```python
def extract_cooccurrence(entities, window_size=1):
    """基于共现窗口的关系抽取"""
    relations = []
    for i, e1 in enumerate(entities):
        for j, e2 in enumerate(entities):
            if i < j and abs(e1['position'] - e2['position']) <= window_size:
                relations.append({
                    'head': e1,
                    'tail': e2,
                    'type': 'CO_OCCURS',
                    'confidence': 1.0 / (abs(e1['position'] - e2['position']) + 1)
                })
    return relations
```

#### 4.4.2 引用关系（Citation）
**原理**: 论文之间的引用关系是最直接的学术关系。

#### 4.4.3 因果关系（Causal）
**原理**: 从论文的讨论和结论章节中抽取因果关系。

```python
CAUSAL_PATTERNS = [
    r"(.+?)导致了(.+)",
    r"(.+?)引起了(.+)",
    r"由于(.+?),?(.+)",
    r"因为(.+?),?(.+)",
    r"(.+?)的结果是(.+)",
    r"(.+?)因此(.+)",
]

def extract_causal_relations(text):
    """基于模式匹配的因果关系抽取"""
    relations = []
    for pattern in CAUSAL_PATTERNS:
        matches = re.finditer(pattern, text)
        for match in matches:
            relations.append({
                'cause': match.group(1).strip(),
                'effect': match.group(2).strip(),
                'type': 'CAUSES',
                'evidence': match.group(0)
            })
    return relations
```

## 7. 技术难点与解决方案

### 7.1 嵌套实体问题

**问题**: 学术文本中经常出现嵌套实体，如"BERT-based NER model"中，"BERT"是Method，"NER"是Task，"BERT-based NER model"整体也是Method。

**解决方案**:
```python
# Span-based方法：枚举所有可能的span
def enumerate_spans(text, max_span_length=10):
    spans = []
    tokens = text.split()
    for i in range(len(tokens)):
        for j in range(i, min(i + max_span_length, len(tokens))):
            span = ' '.join(tokens[i:j+1])
            spans.append((span, i, j))
    return spans

# 对每个span进行分类
class SpanClassifier(nn.Module):
    def __init__(self, encoder, num_types):
        super().__init__()
        self.encoder = encoder
        self.classifier = nn.Linear(encoder.hidden_size * 3, num_types)

    def forward(self, input_ids, span_starts, span_ends):
        # 编码
        representations = self.encoder(input_ids)
        # 提取span表示：[start; end; pooled]
        span_reprs = []
        for start, end in zip(span_starts, span_ends):
            start_repr = representations[start]
            end_repr = representations[end]
            pooled = torch.mean(representations[start:end+1], dim=0)
            span_reprs.append(torch.cat([start_repr, end_repr, pooled]))
        # 分类
        return self.classifier(torch.stack(span_reprs))
```

### 7.2 实体消歧

**问题**: 同一个实体可能有多种表述方式（如"BERT"、"Bidirectional Encoder Representations from Transformers"、"BERT-base"）。

**解决方案**:
```python
class EntityDisambiguator:
    def __init__(self, entity_dict):
        self.entity_dict = entity_dict  # 标准实体字典
        self.alias_map = self._build_alias_map()

    def _build_alias_map(self):
        """构建别名映射"""
        alias_map = {}
        for canonical, info in self.entity_dict.items():
            alias_map[canonical.lower()] = canonical
            for alias in info.get('aliases', []):
                alias_map[alias.lower()] = canonical
        return alias_map

    def disambiguate(self, entity_text):
        """实体消歧"""
        # 1. 精确匹配
        if entity_text.lower() in self.alias_map:
            return self.alias_map[entity_text.lower()]

        # 2. 模糊匹配
        candidates = []
        for alias, canonical in self.alias_map.items():
            similarity = self._compute_similarity(entity_text.lower(), alias)
            if similarity > 0.8:
                candidates.append((canonical, similarity))

        if candidates:
            return max(candidates, key=lambda x: x[1])[0]

        # 3. 创建新实体
        return entity_text

    def _compute_similarity(self, text1, text2):
        """计算文本相似度"""
        # 编辑距离、Jaccard相似度、语义相似度等
        from difflib import SequenceMatcher
        return SequenceMatcher(None, text1, text2).ratio()
```

### 7.4 长文档处理

**问题**: 学术论文通常很长（5-20页），超出LLM的上下文窗口。

**解决方案**:
```python
class LongDocumentProcessor:
    def __init__(self, chunk_size=2000, overlap=200):
        self.chunk_size = chunk_size
        self.overlap = overlap

    def process(self, document, extractor):
        """处理长文档"""
        # 1. 按章节分块
        sections = self._split_by_section(document)

        # 2. 对每个章节进行抽取
        all_results = []
        for section_name, section_text in sections:
            chunks = self._chunk_text(section_text)
            for chunk in chunks:
                result = extractor.extract(chunk, section_name)
                all_results.append(result)

        # 3. 合并结果
        merged = self._merge_results(all_results)

        # 4. 跨章节实体链接
        linked = self._cross_section_linking(merged)

        return linked

    def _split_by_section(self, document):
        """按IMRaD结构分块"""
        sections = {}
        current_section = "unknown"
        current_text = []

        for line in document.split('\n'):
            if self._is_section_header(line):
                if current_text:
                    sections[current_section] = '\n'.join(current_text)
                current_section = self._normalize_section(line)
                current_text = []
            else:
                current_text.append(line)

        if current_text:
            sections[current_section] = '\n'.join(current_text)

        return sections.items()
```

## 8. 未来发展趋势

### 8.1 LLM与传统方法的融合

**趋势**: 不是替代而是互补。LLM用于处理复杂、模糊的实体，传统模型用于处理高频、明确的实体。

**混合架构**:
```python
class HybridExtractor:
    def __init__(self, traditional_model, llm_extractor, confidence_threshold=0.8):
        self.traditional = traditional_model
        self.llm = llm_extractor
        self.threshold = confidence_threshold

    def extract(self, text):
        # 1. 传统模型快速抽取
        traditional_results = self.traditional.predict(text)

        # 2. 筛选低置信度结果
        low_confidence = [r for r in traditional_results
                         if r['confidence'] < self.threshold]

        # 3. LLM重新处理低置信度样本
        if low_confidence:
            llm_results = self.llm.extract(text, target_entities=low_confidence)
            # 合并结果
            return self._merge(traditional_results, llm_results)

        return traditional_results
```

### 8.2 多模态实体抽取

**趋势**: 结合论文中的图表、公式等非文本信息进行实体抽取。

### 8.3 增量学习

**趋势**: 支持模型在新数据上持续学习，而不需要从头训练。

### 8.4 可解释性增强

**趋势**: 不仅输出实体，还要解释为什么这个文本片段被识别为实体。
