## 1. 知识图谱数据模型设计

### 1.1 设计原则

学术论文知识图谱的Schema设计应遵循以下原则：

| 原则 | 说明 |
|------|------|
| **SciERC兼容** | 节点和边类型兼容SciERC/SciER/SciNLP标准，确保可与学术KG生态互操作 |
| **溯源优先** | 每个节点/边必须可追溯到来源论文、章节、chunk |
| **层次分离** | 元数据层（Paper/Author/Venue）、科学实体层（Method/Task/Dataset）、分析层（Gap/Innovation）分层设计 |
| **属性丰富** | 节点和边携带足够属性，支持筛选、排序、过滤 |
| **可扩展** | 支持未来新增节点/边类型而不破坏现有Schema |

### 1.3 边类型设计（19种）

| 边类型 | 方向 | 说明 | 关键属性 |
|--------|------|------|---------|
| `AUTHORED_BY` | Paper → Author | 作者关系 | `author_position` (first/last/corresponding) |

### 1.4 Neo4j Schema 定义

```cypher
-- 节点约束
CREATE CONSTRAINT paper_id IF NOT EXISTS FOR (p:Paper) REQUIRE p.paper_id IS UNIQUE;
CREATE CONSTRAINT author_id IF NOT EXISTS FOR (a:Author) REQUIRE a.author_id IS UNIQUE;
CREATE CONSTRAINT venue_id IF NOT EXISTS FOR (v:Venue) REQUIRE v.venue_id IS UNIQUE;
CREATE CONSTRAINT institution_id IF NOT EXISTS FOR (i:Institution) REQUIRE i.institution_id IS UNIQUE;
CREATE CONSTRAINT task_id IF NOT EXISTS FOR (t:Task) REQUIRE t.task_id IS UNIQUE;
CREATE CONSTRAINT method_id IF NOT EXISTS FOR (m:Method) REQUIRE m.method_id IS UNIQUE;
CREATE CONSTRAINT dataset_id IF NOT EXISTS FOR (d:Dataset) REQUIRE d.dataset_id IS UNIQUE;
CREATE CONSTRAINT metric_id IF NOT EXISTS FOR (m:Metric) REQUIRE m.metric_id IS UNIQUE;
CREATE CONSTRAINT finding_id IF NOT EXISTS FOR (f:Finding) REQUIRE f.finding_id IS UNIQUE;
CREATE CONSTRAINT limitation_id IF NOT EXISTS FOR (l:Limitation) REQUIRE l.limitation_id IS UNIQUE;
CREATE CONSTRAINT gap_id IF NOT EXISTS FOR (g:Gap) REQUIRE g.gap_id IS UNIQUE;
CREATE CONSTRAINT innovation_id IF NOT EXISTS FOR (i:InnovationPoint) REQUIRE i.innovation_id IS UNIQUE;

-- 索引
CREATE INDEX paper_project IF NOT EXISTS FOR (p:Paper) ON (p.project_id);
CREATE INDEX paper_year IF NOT EXISTS FOR (p:Paper) ON (p.year);
CREATE INDEX method_label IF NOT EXISTS FOR (m:Method) ON (m.normalized_label);
CREATE INDEX task_label IF NOT EXISTS FOR (t:Task) ON (t.normalized_label);
CREATE INDEX gap_confidence IF NOT EXISTS FOR (g:Gap) ON (g.confidence);
CREATE INDEX gap_status IF NOT EXISTS FOR (g:Gap) ON (g.status);

-- 全文索引（用于文本搜索）
CREATE FULLTEXT INDEX paper_fulltext IF NOT EXISTS FOR (p:Paper) ON EACH [p.title, p.abstract];
CREATE FULLTEXT INDEX finding_fulltext IF NOT EXISTS FOR (f:Finding) ON EACH [f.claim];

-- 向量索引（用于语义搜索）
CREATE VECTOR INDEX paper_embedding IF NOT EXISTS
FOR (p:Paper) ON (p.embedding)
OPTIONS {indexConfig: {`vector.dimensions`: 768, `vector.similarity_function`: 'cosine'}};
```

### 2.2 各阶段详解

#### 阶段1: 数据获取与元数据提取

**输入**: 论文PDF、DOI、arXiv ID、搜索结果

**处理流程**:
```
论文来源 ──> 元数据获取 ──> PDF下载 ──> 存储入库
    │              │              │           │
    v              v              v           v
  arXiv API    Semantic       本地存储     papers表
  OpenAlex     Scholar API    pdf_path
  CrossRef     作者/机构/年份
```

**技术选型**:
- 元数据获取: Semantic Scholar API + OpenAlex API（互补）
- PDF下载: arXiv直接下载 + Unpaywall API（OA链接）
- 元数据合并: 多源去重（DOI优先，标题模糊匹配备选）

**当前项目状态**: 已实现 `arxiv_client.py`, `openalex_client.py`, `semantic_scholar_client.py`

#### 阶段2: PDF解析与章节识别

**输入**: PDF文件

**处理流程**:
```
PDF ──> 版面分析 ──> 章节识别 ──> 文本分块 ──> 引文解析
         │              │              │              │
         v              v              v              v
    表格/图/公式    IMRaD结构     Chunks存储     参考文献
    双栏布局       Introduction   token_count    引用关系
    页眉页脚       Method/Result  quality_flags
```

**技术选型**:

| 方案 | 优点 | 缺点 | 推荐场景 |
|------|------|------|---------|
| **pdfplumber** | 轻量、Python原生 | 复杂布局效果差 | 快速原型 |
| **PyMuPDF (fitz)** | 速度快、功能全 | 需要C依赖 | 生产环境 |
| **GROBID** | 学术PDF专精、章节识别准确 | 需要Java服务 | 学术论文专用 |
| **Marker** | 深度学习版面分析 | GPU需求 | 高质量需求 |
| **Nougat (Meta)** | 学术PDF OCR | 模型大、速度慢 | 公式密集论文 |

**推荐**: GROBID（章节识别最准）+ pdfplumber（轻量备选）

**当前项目状态**: 已实现 `parser_service.py`，使用pdfplumber

#### 阶段3: 实体抽取（NER）

**输入**: 论文文本chunks

**处理流程**:
```
Text Chunks ──> 章节感知NER ──> 实体标准化 ──> 实体归并
                   │                │              │
                   v                v              v
              SciERC类型        同义词映射      去重合并
              6种实体类型       大小写归一       指纹哈希
              置信度评分        缩写展开
``

**技术方案对比**:

| 方案 | 方法 | F1 (SciERC) | 速度 | 适用场景 |
|------|------|-------------|------|---------|
| **LLM直接抽取** | GPT-4/Claude prompt | ~70-80% | 慢 | 小规模、高质量 |
| **BERT+CRF** | 微调预训练模型 | ~72% | 快 | 中等规模 |
| **SpERT** | 联合实体关系抽取 | ~75% | 中 | 实体+关系同时抽取 |
| **SciBERT+CRF** | 领域预训练 | ~78% | 快 | 学术论文专用 |
| **LLM+规则混合** | LLM抽取+规则验证 | ~80% | 中 | 推荐方案 |

**推荐方案**: LLM + 规则混合

```python
# 伪代码：LLM驱动的实体抽取
def extract_entities(chunk: PaperChunk) -> list[SectionEntity]:
    # 1. 章节感知的prompt选择
    prompt = get_section_aware_prompt(chunk.section_type)

    # 2. LLM抽取
    result = llm.extract(prompt=prompt, text=chunk.text,
                         schema=EntityExtractionSchema)

    # 3. 规则验证
    entities = validate_entities(result.entities, chunk.section_type)

    # 4. 标准化
    for entity in entities:
        entity.normalized_id = normalize_entity(entity)

    return entities
```

**当前项目状态**: 已实现LLM驱动的PaperCard抽取（`paper_card.py`），但未做独立的NER步骤

#### 阶段4: 关系抽取（RE）

**输入**: 已识别的实体对 + 原文上下文

**处理流程**:
```
实体对 ──> 候选关系生成 ──> 关系分类 ──> 置信度过滤 ──> 三元组输出
              │                │              │              │
              v                v              v              v
         共现窗口          LLM/规则       阈值过滤       (S,P,O)
         语法依存          SciERC类型     冲突检测       + 上下文
         位置特征          7种关系类型                  + 置信度
```

**关系抽取策略**:

| 策略 | 方法 | 精度 | 覆盖率 | 推荐场景 |
|------|------|------|--------|---------|
| **规则基** | 模式匹配、依存句法 | 高 | 低 | 结构化文本 |
| **LLM基** | Prompt-driven | 中高 | 高 | 通用场景 |
| **联合模型** | SpERT/DyGIE++ | 中 | 中 | 大规模批量 |
| **混合** | LLM+规则+验证 | 高 | 中高 | 推荐方案 |

### 3.1 问题分类

| 问题类型 | 说明 | 示例 |
|---------|------|------|
| **同一实体不同表述** | 同一事物的不同名称 | "BERT" / "Bidirectional Encoder Representations from Transformers" |

### 3.2 作者名消歧（Author Disambiguation）

作者名消歧是学术KG中最关键的实体消歧问题。

#### 3.2.1 挑战

| 挑战 | 说明 | 示例 |
|------|------|------|
| 姓名缩写 | 不同缩写形式 | "Y. LeCun" vs "Yann LeCun" |
| 拼写变体 | 不同拼写 | "Smythe" vs "Smyth" |

| 同名同姓 | 完全相同姓名 | 需要其他信息区分 |

#### 3.2.2 消歧方法对比

| 方法 | 原理 | 准确率 | 复杂度 | 推荐场景 |
|------|------|--------|--------|---------|
| **规则基** | 姓名格式匹配 + ORCID | 85-90% | 低 | 有ORCID的作者 |
| **聚类基** | 特征相似度聚类 | 90-95% | 中 | 批量消歧 |
| **图基** | 合著关系网络推理 | 92-97% | 高 | 大规模消歧 |
| **深度学习** | BERT嵌入 + 分类器 | 95-98% | 高 | 高精度需求 |
| **混合** | 规则 + 聚类 + 验证 | 93-97% | 中 | 推荐方案 |

**作者指纹生成算法**:

```python
def generate_author_fingerprint(
    name: str,
    affiliations: list[str],
    coauthors: list[str],
    topics: list[str],
) -> str:
    """生成作者指纹，用于消歧"""
    # 1. 姓名标准化
    normalized_name = normalize_name(name)  # "Y. LeCun" -> "le_cun_yann"

    # 2. 机构指纹（取最高频机构）
    inst_fp = hash(normalize_institution(affiliations[0])) if affiliations else ""

    # 3. 合作者指纹（取top-3合作者）
    coauthor_fps = sorted([normalize_name(c) for c in coauthors[:3]])

    # 4. 领域指纹
    topic_fp = hash("_".join(sorted(topics[:3])))

    # 5. 组合指纹
    return f"{normalized_name}_{inst_fp}_{hash('_'.join(coauthor_fps))}_{topic_fp}"
```

**聚类策略**:

```python
def cluster_authors(author_records: list[dict]) -> list[list[str]]:
    """对同一姓名的不同记录进行聚类"""
    clusters = []
    for record in author_records:
        merged = False
        for cluster in clusters:
            if should_merge(record, cluster):
                cluster.append(record)
                merged = True
                break
        if not merged:
            clusters.append([record])
    return clusters

def should_merge(record: dict, cluster: list[dict]) -> bool:
    """判断是否应合并到已有簇"""
    # 1. ORCID完全匹配
    if record.get("orcid") and any(r.get("orcid") == record["orcid"] for r in cluster):
        return True

    # 2. 机构匹配 + 合作者重叠
    inst_match = any_institution_overlap(record, cluster)
    coauthor_match = coauthor_overlap_score(record, cluster) > 0.3

    # 3. 领域匹配
    topic_match = topic_overlap_score(record, cluster) > 0.5

    return (inst_match and coauthor_match) or (coauthor_match and topic_match)
```

def normalize_entity(text: str, entity_type: str) -> str:
    """实体名称归一化"""
    # 1. 基础清理
    t = text.strip().lower()
    t = re.sub(r"[　]", " ", t)  # 全角空格
    t = re.sub(r"[_\-]+", " ", t)
    t = re.sub(r"\s+", " ", t)
    t = t.rstrip(".,;:;")

    # 2. 同义词检查
    if t in ENTITY_ALIASES:
        return ENTITY_ALIASES[t]

    # 3. 去复数（简单规则）
    if t.endswith("s") and not t.endswith("ss") and len(t) > 3:
        singular = t[:-1]
        if singular in ENTITY_ALIASES:
            return ENTITY_ALIASES[singular]

    # 4. 版本号标准化
    t = re.sub(r"(\d+)\.(\d+)\.(\d+)", r"\1.\2.\3", t)  # v1.2.3
    t = re.sub(r"v(\d+\.\d+)", r"\1", t)  # v2.0 -> 2.0

    return t
```

### 3.4 跨论文实体对齐

#### 3.4.1 嵌入相似度方法

```python
def align_entities_cross_paper(
    entities_a: list[dict],
    entities_b: list[dict],
    threshold: float = 0.85,
) -> list[tuple[str, str, float]]:
    """跨论文实体对齐"""
    alignments = []

    # 生成实体嵌入
    embeddings_a = embedding_service.encode([e["label"] for e in entities_a])
    embeddings_b = embedding_service.encode([e["label"] for e in entities_b])

    # 计算相似度矩阵
    sim_matrix = cosine_similarity(embeddings_a, embeddings_b)

    for i, ea in enumerate(entities_a):
        for j, eb in enumerate(entities_b):
            sim = sim_matrix[i][j]
            if sim >= threshold:
                # 额外验证：类型必须兼容
                if is_type_compatible(ea["type"], eb["type"]):
                    alignments.append((ea["id"], eb["id"], sim))

    return alignments
```

def deduplicate_paper(new_paper: dict, existing_papers: list[dict]) -> str | None:
    """论文去重，返回已有paper_id或None"""
    # 1. DOI精确匹配（最高优先级）
    if new_paper.get("doi"):
        for p in existing_papers:
            if p.get("doi") == new_paper["doi"]:
                return p["paper_id"]

    # 2. arXiv ID精确匹配
    if new_paper.get("arxiv_id"):
        for p in existing_papers:
            if p.get("arxiv_id") == new_paper["arxiv_id"]:
                return p["paper_id"]

    # 3. 标题模糊匹配
    new_title = normalize_title(new_paper.get("title", ""))
    for p in existing_papers:
        existing_title = normalize_title(p.get("title", ""))
        if new_title and existing_title:
            similarity = jaccard_similarity(new_title, existing_title)
            if similarity > 0.9:
                return p["paper_id"]

    return None

def normalize_title(title: str) -> set[str]:
    """标题归一化为词集合"""
    title = title.lower()
    title = re.sub(r"[^\w\s]", "", title)
    words = set(title.split())
    # 去停用词
    stop_words = {"a", "an", "the", "of", "in", "on", "for", "and", "or", "to", "with"}
    return words - stop_words

def jaccard_similarity(set_a: set, set_b: set) -> float:
    if not set_a or not set_b:
        return 0.0
    return len(set_a & set_b) / len(set_a | set_b)
```

#### 5.3.2 实体去重与合并

```python
def merge_entity_nodes(
    existing_node: dict,
    new_evidence: dict,
) -> dict:
    """合并实体节点的属性"""
    # 合并paper_ids
    existing_pids = set(existing_node["properties"].get("paper_ids", []))
    new_pid = new_evidence["paper_id"]
    existing_pids.add(new_pid)
    existing_node["properties"]["paper_ids"] = list(existing_pids)

    # 合并evidence_ids
    existing_eids = set(existing_node["properties"].get("evidence_ids", []))
    new_eid = new_evidence["evidence_id"]
    existing_eids.add(new_eid)
    existing_node["properties"]["evidence_ids"] = list(existing_eids)

    # 合并source_quotes（最多保留3条）
    existing_quotes = existing_node["properties"].get("source_quotes", [])
    if new_evidence.get("source_quote"):
        if len(existing_quotes) < 3:
            existing_quotes.append(new_evidence["source_quote"][:100])
    existing_node["properties"]["source_quotes"] = existing_quotes

    # 合并source_chunk_ids
    existing_chunks = existing_node["properties"].get("source_chunk_ids", [])
    if new_evidence.get("source_chunk_id"):
        if new_evidence["source_chunk_id"] not in existing_chunks:
            existing_chunks.append(new_evidence["source_chunk_id"])
    existing_node["properties"]["source_chunk_ids"] = existing_chunks

    return existing_node
```

ON MATCH SET m.paper_ids = m.paper_ids + $new_paper_id
WITH m
MATCH (p:Paper {paper_id: $paper_id})
MERGE (p)-[r:USED_FOR]->(m)
ON CREATE SET r.evidence_ids = [$evidence_id], r.created_at = datetime()
ON MATCH SET r.evidence_ids = CASE

    ELSE r.evidence_ids + $evidence_id

#### 5.5.1 图谱版本控制

```python
class GraphVersionManager:
    """图谱版本管理"""

    def __init__(self, storage):
        self.storage = storage

    def create_snapshot(self, project_id: str, reason: str) -> str:
        """创建图谱快照"""
        graph = self.storage.query("graphs", {"project_id": project_id})
        if not graph:
            return ""

        version_id = f"v_{datetime.now().strftime('%Y%m%d_%H%M%S')}"
        snapshot = {
            "version_id": version_id,
            "project_id": project_id,
            "reason": reason,
            "graph_data": graph[0],
            "node_count": len(graph[0].get("nodes", [])),
            "edge_count": len(graph[0].get("edges", [])),
            "created_at": datetime.now().isoformat(),
        }
        self.storage.save_collection(f"graph_versions_{project_id}", [snapshot])
        return version_id

    def list_versions(self, project_id: str) -> list[dict]:
        """列出所有版本"""
        versions = self.storage.load_collection(f"graph_versions_{project_id}")
        return sorted(versions, key=lambda v: v["created_at"], reverse=True)

    def restore_version(self, project_id: str, version_id: str) -> bool:
        """恢复到指定版本"""
        versions = self.storage.load_collection(f"graph_versions_{project_id}")
        target = next((v for v in versions if v["version_id"] == version_id), None)
        if not target:
            return False
        self.storage.upsert_item("graphs", f"kg_{project_id}", target["graph_data"])
        return True
```

### 5.6 Gap节点的增量聚合

Gap节点是通过聚合多个Limitation节点产生的，增量更新时需要特殊处理：

```python
def incrementally_update_gaps(
    nodes: dict,
    edges: dict,
    new_limitations: list[dict],
):
    """增量更新Gap节点"""
    # 1. 收集现有Gap的normalized_label
    existing_gap_norms = {
        n["properties"]["normalized_label"]: nid
        for nid, n in nodes.items()
        if n.get("node_type") == "Gap"
    }

    # 2. 对新Limitation进行聚类
    for lim in new_limitations:
        norm = normalize_label(lim["claim"])[:80]

        # 检查是否已有匹配的Gap
        matched_gap_id = None
        for gap_norm, gap_id in existing_gap_norms.items():
            if text_similarity(norm, gap_norm) > 0.8:
                matched_gap_id = gap_id
                break

        if matched_gap_id:
            # 更新已有Gap
            gap_node = nodes[matched_gap_id]
            gap_node["properties"]["supporting_paper_ids"].append(lim["paper_id"])
            gap_node["properties"]["supporting_limitation_ids"].append(lim["limitation_id"])
            # 重算置信度
            gap_node["properties"]["confidence"] = compute_gap_confidence(
                gap_node["properties"]["source_types"],
                "medium",
                len(gap_node["properties"]["supporting_paper_ids"]),
                True,
            )
        else:
            # 创建新Gap候选
            gap_id = f"gap:{stable_hash(norm)}"
            nodes[gap_id] = create_gap_node(norm, lim)

        # 创建SUGGESTS_GAP边
        edge_id = f"edge:SUGGESTS_GAP:{stable_hash(lim['limitation_id'])}:{stable_hash(matched_gap_id or gap_id)}"
        if edge_id not in edges:
            edges[edge_id] = create_suggests_gap_edge(lim, matched_gap_id or gap_id)
```
