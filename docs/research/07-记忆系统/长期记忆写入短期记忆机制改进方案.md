### 2.2 智能触发判断

**文件**: `src/agents_v2/core/context_injector.py`

新增 `_should_recall_memories()` 方法，只有当用户问题涉及历史关键词时才触发记忆召回：

```python
class IntelligentContextInjector:
    HISTORY_KEYWORDS = [
        "之前", "上次", "之前那个", "上次那个",
        "以前", "曾经", "之前你", "上次我",
        "还记得", "之前提到", "上次说的"
    ]

    def _should_recall_memories(self, task: str, memory_state: Any) -> bool:
        """判断是否需要召回记忆"""
        for keyword in self.HISTORY_KEYWORDS:
            if keyword in task:
                return True
        return False
```

**触发逻辑**：

```
用户问题 → 包含历史关键词? → 是 → 触发记忆召回
                              → 否 → 不触发（默认行为）
```

### 2.3 遗忘曲线时间衰减

**文件**: `src/agents_v2/core/context_injector.py`

新增 `_calculate_retention_score()` 方法，基于 Ebbinghaus 公式计算保留分数：

```python
def _calculate_retention_score(self, mem: Any, current_time: float) -> float:
    """
    公式: retention = importance * e^(-t/S)

    其中:
    - t: 距离上次访问的时间
    - S: 记忆强度参数（基于重要性）
      - 高重要性(>=0.8): S = 7天
      - 中等重要性(>=0.6): S = 1天
      - 低重要性(>=0.4): S = 12小时
      - 其他: S = 1小时
    """
    importance = self._get_memory_importance(mem)

    if not hasattr(mem, 'last_accessed') or mem.last_accessed == 0:
        return importance

    t = current_time - mem.last_accessed

    if importance >= 0.8:
        S = 86400 * 7   # 7天
    elif importance >= 0.6:
        S = 86400        # 1天
    elif importance >= 0.4:
        S = 3600 * 12    # 12小时
    else:
        S = 3600         # 1小时

    retention = importance * math.exp(-t / S) if S > 0 else importance
    return min(1.0, max(0.0, retention))
```

### 2.4 重要性阈值过滤

**文件**: `src/agents_v2/core/context_injector.py`

在 `_prioritize_memories()` 中集成时间衰减和阈值过滤：

```python
def _prioritize_memories(self, task_memories, preference_memories) -> List[Any]:
    """优先级排序 - 集成时间衰减和重要性阈值过滤"""
    scored = []
    current_time = time.time()

    for mem in task_memories:
        importance = self._get_memory_importance(mem)

        # 重要性阈值过滤
        if importance < self.importance_threshold:
            continue

        # 计算时间衰减后的保留分数
        retention = self._calculate_retention_score(mem, current_time)

        # 最终分数 = 基础分数 * 保留分数
        base_score = importance * 0.7 + 0.3
        final_score = base_score * retention

        scored.append((final_score, mem))

    # 同样的处理应用于 preference_memories
    # ...

    # 按最终分数排序
    scored.sort(key=lambda x: x[0], reverse=True)
    return [mem for _, mem in scored]
```

**阈值配置**：

```python
IMPORTANCE_THRESHOLD = 0.3  # 低于此值的记忆被过滤
```

```
┌─────────────────────────────────────────────────────────────┐
│                      用户问题输入                             │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│              _should_recall_memories()                       │
│                                                              │
│  检查历史关键词: ["之前", "上次", "曾经", ...]               │
│                              ↓                               │
│              包含关键词? → 是 → 触发召回                     │
│                         → 否 → 不触发（跳过）                │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│           _retrieve_relevant_memories()                     │
│                                                              │
│  1. 从 memory_state 检索记忆                                │
│  2. 调用 _prioritize_memories() 排序                        │
│     - 重要性阈值过滤 (< 0.3 丢弃)                           │
│     - 时间衰减计算 (retention = importance * e^(-t/S))       │
│  3. 结合基础分数和保留分数计算最终优先级                      │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│           Context Window (短期记忆)                         │
│                                                              │
│  高优先级记忆被加载进来，低重要性记忆被过滤                  │
└─────────────────────────────────────────────────────────────┘
```

## 5. 使用示例

### 5.1 自动触发（推荐）

```python
injector = IntelligentContextInjector(
    importance_threshold=0.3,
    enable_time_decay=True
)

# 用户问题包含"之前"关键词，自动触发记忆召回
context = injector.build_context(
    task="帮我改进之前那个登录功能",  # 会触发召回
    memory_state=memory_manager,
    ...
)

# 用户问题不包含历史关键词，不触发
context = injector.build_context(
    task="帮我写一篇关于深度学习的论文",  # 不会触发
    memory_state=memory_manager,
    ...
)
```

### 5.2 手动控制

```python
# 在 MemoryNode 中使用
node = create_memory_node()

# 只有包含历史关键词的问题才会触发召回
state = node.recall_before_search(state)
```
