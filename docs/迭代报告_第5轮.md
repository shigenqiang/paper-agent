## 二、发现的重大问题

### 2.1 MiniMax-M2.7 中文编码问题

**问题描述**: MiniMax-M2.7模型在生成中文内容时存在编码问题，输出的中文字符显示为乱码（如"���"）。

**影响范围**: 所有依赖LLM生成中文内容的Agent，包括：
- TopicAgent（选题生成）
- LiteratureAgent（文献综述）
- 所有问题导向Agent
- 所有Writing Agent

**临时解决方案**: 使用英文提示可以正常工作

**根本原因**: MiniMax-M2.7模型对中文的生成存在bug

**建议**:
1. 等待MiniMax修复该问题
2. 或使用支持中文的模型（如GPT-4、Claude等）
3. 或在提示词中使用英文，输出时再翻译
