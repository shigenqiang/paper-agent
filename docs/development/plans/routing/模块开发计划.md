# 模块3：意图路由三级级联升级开发计划

> 规划日期：2026-05-02 | 版本：v1.0 | 优先级：P1 | 状态：待开始 | 周期：2-3周

---

## 3.1 背景与目标

**现状**：
- IntentRouter 已实现 11 种意图类型
- 采用关键词匹配 + LLM 辅助的两步路由

**目标**：
- 实现三级级联混合路由（关键词→语义向量→LLM）
- 降低 85% 路由成本
- P50 延迟从 800ms 降至 15ms

---

## 3.2 三级级联架构

```
用户输入
  → Layer 1: 关键词快速匹配（<1ms, acc 60-75%）
    → 置信度不足 ↓
  → Layer 2: 语义向量路由（10-50ms, acc 80-92%）[新增]
    → 置信度不足 ↓
  → Layer 3: LLM深度分类（500ms-2s, acc 90-96%）
    → Layer 4: 降级兜底（默认意图）
```

---

## 3.3 实施计划

### Phase 1：语义向量路由层（1周）

| 任务 | 说明 | 文件 |

### Phase 3：性能优化（1周）
