## 模块概述

Search模块封装多源学术搜索能力。

### 数据源

| 源 | 说明 | API |
|------|------|-----|
| **arXiv** | 预印本论文 | arXiv API |
| **PubMed** | 生物医学文献 | PubMed API |
| **Semantic Scholar** | 学术图谱 | S2 API |
| **OpenAlex** | 开放学术知识 | OpenAlex API |

### 搜索能力

| 能力 | 说明 |
|------|------|
| **多源检索** | 同时搜索多个数据库 |
| **去重合并** | 跨源结果去重 |
| **元数据提取** | 论文信息结构化 |
| **引用追踪** | 向前向后引用 |
