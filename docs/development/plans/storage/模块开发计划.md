## 模块概述

Storage模块管理数据持久化，采用多存储融合架构。

### 存储选型

| 存储 | 用途 | 技术 |
|------|------|------|
| **PostgreSQL** | 结构化数据 | 会话、用户数据 |
| **Qdrant** | 向量存储 | 论文向量检索 |
| **Neo4j** | 图数据库 | 知识图谱 |
| **Redis** | 缓存 | Token缓存、会话缓存 |
| **文件存储** | 文件PDF | 本地/OSS |

### 数据流转

```
数据输入 → 分类 → PostgreSQL(结构化)
                → Qdrant(向量)
                → Neo4j(图)
                → 文件存储(PDF)
```
