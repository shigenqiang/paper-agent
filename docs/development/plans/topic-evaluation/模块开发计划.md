## 模块概述

Topic Evaluation模块负责选题阶段的评估和可行性分析。

### 评估维度

| 维度 | 指标 |
|------|------|
| **创新性** | 研究空白分析 |
| **可行性** | 资源可行性评估 |
| **重要性** | 领域重要性 |
| **新颖性** | 与现有研究差异化 |
| **可操作性** | 执行难度评估 |

### 评估流程

```
用户输入 → 关键词分析 → 相关领域检索 → 空白分析 → 创新性评估 → 可行性评估 → 输出报告
```
