## 模块概述

Retrieval模块负责论文和知识的检索增强。

### 检索类型

| 类型 | 技术 | 用途 |
|------|------|------|
| **向量检索** | Qdrant/ChromaDB | 语义相似搜索 |
| **全文检索** | Elasticsearch | 关键词搜索 |
| **混合检索** | 向量+关键词 | 混合搜索策略 |
| **知识图谱检索** | Neo4j Cypher | 关系查询 |

### EnhancedRetrievalEngine

| 功能 | 说明 |
|------|------|
| **多路召回** | 同时召回多个来源 |
| **重排序** | Cross-encoder重排 |
| **上下文增强** | 检索结果加工 |
