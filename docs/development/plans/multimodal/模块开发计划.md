# Multimodal 模块开发计划

> 规划日期：2026-05-02 | 版本：v1.0

---

## 模块概述

多模态模块支持论文中的图表理解、公式识别等能力。

### 核心能力

| 能力 | 说明 | 适用场景 |
|------|------|---------|
| **图表理解** | 图表内容提取和描述 | Figure/Table解析 |
| **公式识别** | LaTeX/MathML提取 | 数学公式 |
| **图像理解** | 多模态模型理解 | 流程图、架构图 |
| **PDF转图像** | PDF页面转图片 | 可视化分析 |

### 技术选型

| 任务 | 推荐模型 |
|------|----------|
| 图表/图像理解 | Gemini 3.1 Pro / Claude Opus |
| 公式识别 | Marker / PDF-Extract-Kit |
