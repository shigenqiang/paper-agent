### 2.2 写作工作流完整链路 (核心路径)

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                        写作工作流 (Writing Workflow)                             │
└─────────────────────────────────────────────────────────────────────────────────┘

[1] memory_recall ──────────────────────────────────────────────────────────────┐
    功能: 检索前召回历史记忆                                                      │
    输入: user_id, query                                                         │
    处理: EnhancedMemorySystem.recall(top_k=3)                                  │
    输出: 增强查询 (原始query + 历史记忆上下文)                                    │
    │                                                                            │
    ▼                                                                            │
[2] crawler ───────────────────────────────────────────────────────────────────┐
    功能: 多源论文检索                                                            │
    数据源: arXiv, PubMed, Semantic Scholar, OpenAlex                           │
    处理: 并行搜索, 结果合并                                                     │
    输出: 原始论文列表 (papers[])                                                │
    │                                                                            │
    ▼                                                                            │
[3] selector ──────────────────────────────────────────────────────────────────┐
    功能: 论文质量筛选                                                           │
    处理: LLM评分 (相关性 + 质量 + 新颖性)                                       │
    输出: 高质量论文列表 (selected_papers[], top_k=20)                          │
    │                                                                            │
    ▼                                                                            │
[4] multimodal (可选) ─────────────────────────────────────────────────────────┐
    功能: 多模态分析 (论文图表理解)                                               │
    处理: 图表提取, 内容分析                                                     │
    输出: 多模态特征                                                             │
    │                                                                            │
    ▼                                                                            │
[5] kg (可选) ─────────────────────────────────────────────────────────────────┐
    功能: 知识图谱构建                                                           │
    处理: 实体关系提取, 图谱构建                                                 │
    输出: 知识图谱数据                                                           │
    │                                                                            │
    ▼                                                                            │
[6] outline ───────────────────────────────────────────────────────────────────┐
    功能: 大纲生成 (LLM调用)                                                     │
    处理: 基于 selected_papers 生成论文大纲                                      │
    输出: outline (章节结构, 每节要点)                                            │
    │                                                                            │
    ▼                                                                            │
[7] writing ───────────────────────────────────────────────────────────────────┐
    功能: 内容写作 (LLM调用)                                                     │
    处理: 逐节生成, 引用标注                                                     │
    输出: draft (完整初稿)                                                       │
    │                                                                            │
    ▼                                                                            │
[8] review ────────────────────────────────────────────────────────────────────┐
    功能: 论文评审 (LLM调用)                                                     │
    处理: 质量评估, 问题反馈                                                     │
    输出: feedback (问题列表, 改进建议)                                           │
    │                                                                            │
    ▼                                                                            │
[9] evaluator ─────────────────────────────────────────────────────────────────┐
    功能: 自动评估                                                               │
    处理: 多维度评分 (逻辑性/完整性/创新性/格式)                                  │
    决策: 通过 → END, 不通过 → 返回 [7] writing 重写                             │
    │                                                                            │
    ▼                                                                            │
[10] memory_remember ──────────────────────────────────────────────────────────┐
    功能: 存储本次任务结果                                                        │
    处理: 记住 selected_papers, 任务类型, 用户偏好                                │
    输出: 持久化到记忆系统                                                        │
    │                                                                            │
    ▼                                                                            │
[END] 返回最终状态                                                                │
    包含: draft, selected_papers, trace_id, 性能统计                              │
    └────────────────────────────────────────────────────────────────────────────┘
```

```
│    短期记忆           │  │    会话记忆           │  │    长期记忆           │
│  (ShortTermMemory)    │  │  (SessionMemory)      │  │  (LongTermMemory)     │
│                       │  │                       │  │                       │
│ 范围: 当前任务         │  │ 范围: 任务内跨Agent    │  │ 范围: 跨任务持久化     │
│ 存储: 内存             │  │ 存储: Redis            │  │ 存储: PostgreSQL      │
│ 容量: 500条目          │  │ 容量: 500条目          │  │ 容量: 无限制          │
│ 特性: 任务结束清除     │  │ 特性: 自动摘要生成     │  │ 特性: 向量检索        │
└───────────────────────┘  └───────────────────────┘  └───────────────────────┘
         │                          │                          │
         └──────────────────────────┼──────────────────────────┘
                                    ▼
                    ┌───────────────────────────────┐
                    │    情景记忆 (EpisodicMemory)   │
                    │                               │
                    │ 范围: 执行轨迹记录             │
                    │ 存储: PostgreSQL + Neo4j       │
                    │ 特性: 时间线, 因果关系         │
                    └───────────────────────────────┘
                                    │
                                    ▼
                    ┌───────────────────────────────┐
                    │    统一记忆管理器              │
                    │  (UnifiedMemoryManager)        │
                    │                               │
                    │ 核心服务:                      │
                    │ - MemoryExtractor (LLM驱动)    │
                    │ - SummaryGenerator (自动摘要)  │
                    │ - EnhancedRetrievalEngine      │
                    │ - ForgettingController         │
                    └───────────────────────────────┘

记忆节点在 Workflow 中的集成点:

写作意图路由:
  router → memory_recall → crawler → selector → ... → memory_remember → END
                    │                                    │
                    ▼                                    ▼
            召回历史记忆 (Top 3)                  存储 Top 5 论文
            增强用户查询                        记录任务结果
            提供上下文                          积累用户知识
```
