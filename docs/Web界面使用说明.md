# 论文Agent Web界面使用说明

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动后端API服务

**方式一：直接启动**
```bash
python api.py
```

**方式二：使用uvicorn**
```bash
uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```

API服务将在 `http://localhost:8000` 启动

### 3. 启动Web界面

**Windows用户：**
```bash
run_web.bat
```

**Linux/Mac用户：**
```bash
chmod +x run_web.sh
./run_web.sh
```

**或直接运行：**
```bash
streamlit run app.py
```

Web界面将在浏览器中自动打开，默认地址：`http://localhost:8501`

## 功能说明

### 主界面

#### 查询输入
- 在主输入框中输入您想了解的研究主题
- 支持自然语言查询，例如：
  - "函数型数据分析的最新进展"
  - "Transformer模型在NLP中的应用"
  - "2023年深度学习领域的突破性研究"

#### 参数设置
- **API地址**：配置后端API服务地址
- **最大结果数**：控制返回的论文数量（5-50篇）
- **年份范围**：限定搜索的论文发表年份

#### 查询历史
- 自动保存最近10条查询记录
- 点击历史记录可快速重新执行查询

### 查询结果

查询成功后，界面将展示：

1. **查询概览**
   - 查询主题
   - 找到的论文数量
   - 执行状态

2. **研究报告**
   - 研究背景与意义
   - 主要研究发现
   - 方法论对比
   - 未来研究方向
   - 参考文献列表

### 状态提示

- ✅ **API服务连接正常**：后端服务运行正常
- ⚠️ **API服务未连接**：请检查后端是否启动

## 使用技巧

### 1. 优化查询质量

**好的查询示例：**
```
请搜索2022-2024年关于大模型可解释性的研究论文，重点关注LIME和SHAP方法的改进
```

**不好的查询示例：**
```
AI
```

### 2. 合理设置参数

- **快速预览**：设置最大结果数为5-10篇
- **深入研究**：设置最大结果数为20-50篇
- **最新研究**：将起始年份设为最近年份

### 3. 利用历史记录

- 常用查询会被自动保存
- 点击历史记录可快速复用

## 常见问题

### Q: 查询一直显示"正在搜索和分析论文..."
**A:** 请检查后端API服务是否正常运行，查看侧边栏的状态提示。

### Q: 找到的论文数量为0
**A:** 尝试：
1. 扩大年份范围
2. 简化查询关键词
3. 检查查询主题是否过于冷门

### Q: 报告内容不够详细
**A:** 增加最大结果数，系统将分析更多论文。

### Q: 如何导出查询结果？
**A:** 报告将以Markdown格式展示，您可以直接复制，或使用浏览器的"另存为"功能保存页面。

## API接口文档

### 健康检查
```bash
GET /health
```

响应：
```json
{
  "status": "healthy"
}
```

### 执行查询
```bash
POST /query
```

请求体：
```json
{
  "query": "查询内容",
  "max_results": 20,
  "year_range": [2020, 2025]
}
```

响应：
```json
{
  "status": "success",
  "message": "Query completed successfully",
  "report_markdown": "...",
  "papers_count": 15
}
```
