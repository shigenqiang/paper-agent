### 2.2 GPT-Researcher架构分析

```
用户请求 → 规划代理(Planner)
              ↓
         并行执行多个搜索任务
              ↓
         搜索代理(Searcher) × N
              ↓
         评估代理(Reviewer)
              ↓
         结果聚合 → 报告生成
```

**核心特点**:
- 多Agent自主决策搜索策略
- 并行搜索多数据源
- 结果去重和排序
- 支持 Tavily, SerpAPI, Google Scholar

## 三、论文Agent核心架构

### 3.2 论文写作Pipeline

```
选题 ──▶ 文献调研 ──▶ Thesis凝练 ──▶ 大纲制定 ──▶ 初稿撰写 ──▶ 修订编辑 ──▶ 审核
  │          │            │            │           │           │          │
  ▼          ▼            ▼            ▼           ▼           ▼          ▼
Topic    Literature   Thesis       Outline     Draft      Editor    Reviewer
Agent     Agent       Agent        Agent      Writer      Agent      Agent
```

| Agent | 职责 | 核心能力 |
|-------|------|----------|
| TopicAgent | 选题方向评估 | 研究空白分析 |
| LiteratureAgent | 文献搜索与筛选 | 多源搜索、去重排序 |
| ThesisAgent | 核心论点凝练 | 创新性判断 |
| OutlineAgent | 逻辑结构设计 | 章节规划 |
| DraftWriterAgent | 初稿撰写 | 内容生成 |
| EditorAgent | 修订润色 | 语言优化 |
| ReviewerAgent | 最终审核 | 质量把控 |

## 六、引用准确性保障

### 6.1 幻觉检测技术

```
分层防护策略:
├── Layer 1: 输入过滤 - 检测明显错误
├── Layer 2: 检索增强 - RAG提供真实上下文
├── Layer 3: 生成约束 - Prompt限制输出范围
├── Layer 4: 输出验证 - 事后核查和置信度
└── Layer 5: 人工审核 - 关键内容复核
```

### 6.2 RAG引用验证

| 技术 | 描述 |
|------|------|
| **Context-Reference Alignment** | 每个生成内容附带原始文档引用 |
| **Chunk-Level Citation** | 引用精度细化到文档块级别 |
| **Chain-of-Verification** | 模型逐一验证每个声明 |
| **Citation Graph Validation** | 检测虚假或断开的引用链 |

## 九、核心结论

### 9.1 论文Agent最重要的5个部分

1. **多源学术搜索** - 决定文献质量和覆盖面
2. **引用准确性** - 学术可信度的生命线
3. **深度论文理解** - PDF解析+多模态理解
4. **RAG检索增强** - 生成内容的事实依据
5. **多层记忆系统** - 个性化和上下文连贯

### 9.2 技术选型总结

| 层级 | 推荐方案 |
|------|----------|
| Agent框架 | LangGraph / CrewAI |
| LLM | Claude 3.5 (英文) / DeepSeek V3 (中文) |
| 向量存储 | Qdrant / pgvector |
| 图数据库 | Neo4j |
| PDF解析 | Marker + pdfplumber |
| 搜索API | OpenAlex + Semantic Scholar |
| 记忆服务 | Mem0 / Zep |

### 9.3 未来趋势

1. **多Agent协作**成为主流架构
2. **长上下文窗口**(100K+)简化多文档处理
3. **领域微调**模型在学术写作质量上显著优于通用模型
4. **引用准确性**成为区分AI写作工具的关键指标
5. **幻觉检测**成为学术AI的必备能力
