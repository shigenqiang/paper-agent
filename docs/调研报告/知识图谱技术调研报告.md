## 二、查询技术对比

### 2.1 主流查询语言

| 语言 | 数据库 | 特点 | 性能 |
|------|--------|------|------|
| **Cypher** | Neo4j, RedisGraph | 类SQL语法，声明式 | 中等 |
| **Gremlin** | JanusGraph, HugeGraph, Amazon Neptune | 图遍历语言，命令式 | 较高 |
| **SPARQL** | Apache Jena, Virtuoso, GraphDB | RDF标准查询语言 | 中等 |
| **GSQL** | TigerGraph | 编译型，预编译为C++ | 最高 |

### 2.2 Cypher (Neo4j)

```cypher
-- 查询示例：查找论文的作者及其机构
MATCH (a:Author)-[:WRITES]->(p:Paper)-[:PUBLISHED_IN]->(j:Journal)
WHERE p.title CONTAINS 'machine learning'
RETURN a.name, j.name, count(p) AS paper_count
ORDER BY paper_count DESC
LIMIT 10

-- 路径查询：查找两篇论文之间的关联
MATCH path = (p1:Paper {title: 'Paper A'})-[:CITES*1..3]-(p2:Paper {title: 'Paper B'})
RETURN path
```

**优点**:
- 语法直观，接近自然语言
- 生态丰富，工具链完善
- 学习曲线平缓

**缺点**:
- Neo4j单机版性能有限
- 分布式支持需要企业版

### 2.3 Gremlin (JanusGraph/HugeGraph)

```groovy
// HugeGraph查询示例
g.V().has('paper', 'title', 'machine learning')
  .outE('writes')
  .inV()
  .out('affiliated_with')
  .values('name')
```

**优点**:
- 支持大规模分布式图
- 兼容多种后端存储（ Cassandra, HBase, ScyllaDB）
- 开源生态活跃（HugeGraph是Apache顶级项目）

**缺点**:
- 语法相对复杂
- 不同实现略有差异

### 2.4 GSQL (TigerGraph)

```gsql
-- TigerGraph查询示例
CREATE QUERY find_paper_authors(STRING paper_title) FOR GRAPH paper_graph {
  PRINT "Finding authors for:", paper_title;
  start = {Paper.*}.SELECT生FROM Paper p
    WHERE p.title == paper_title;
  authors = SELECT a FROM start-(WRITES:e)-:a;
  PRINT authors;
}
```

**优点**:
- 编译型语言，性能最高（比Neo4j快100-300倍）
- 原生支持并行计算
- 内置丰富图算法

**缺点**:
- 闭源（社区版有限制）
- 学习曲线陡峭

### 2.5 选型建议

| 场景 | 推荐 |
|------|------|
| 中小规模（<1亿边） | Neo4j + Cypher |
| 大规模生产环境 | HugeGraph + Gremlin 或 TigerGraph |
| 学术/RDF标准 | Virtuoso + SPARQL |
| 最高性能需求 | TigerGraph GSQL |

**Paper Agent推荐**: 采用 **Neo4j + Cypher** 作为主要方案，原因：
1. 社区版免费，部署简单
2. 生态成熟，工具链完善
3. Cypher语法易学易用
4. 满足论文知识图谱规模需求（估计<1000万节点）

## 三、更新与删除技术

### 3.1 Neo4j更新机制

```cypher
-- 批量更新：使用APOC插件
CALL apoc.periodic.iterate(
  "UNWIND $batch AS row RETURN row",
  "MATCH (p:Paper {id: row.id})
   SET p.citations = row.citations,
       p.updated_at = datetime()",
  {batch: [...]}
)

-- 事务性更新
BEGIN
MATCH (a:Author {id: 'author_1'})
MATCH (p:Paper {id: 'paper_1'})
MERGE (a)-[:WRITES {role: 'corresponding'}]->(p)
SET p.revision_count = p.revision_count + 1
COMMIT
```

### 3.2 大规模删除优化

```cypher
-- 批量删除：使用APOC插件避免内存溢出
CALL apoc.periodic.commit(
  "MATCH (n:DeprecatedNode) WHERE n.delete_me = true
   WITH n LIMIT 1000
   DETACH DELETE n
   RETURN count(n)",
  {}
)

-- 删除孤立节点
MATCH (n) WHERE NOT (n)--()
WITH collect(n) AS orphans
CALL apoc.agdc.async.delete(orphans) YIELD deleted
RETURN deleted
```

## 四、社区检测技术

### 4.1 主流算法对比

| 算法 | 时间复杂度 | 适用规模 | 特点 |
|------|------------|----------|------|
| **Louvain** | O(n log n) | 中大规模 | 模块度优化，精度高 |
| **Label Propagation** | O(m) | 大规模 | 速度快，近线性 |
| **Infomap** | O(m) | 中大规模 | 基于随机游走 |
| **GNN-based** | O(m×k) | 中等规模 | 精度最高，需训练 |
| **Leiden** | O(n log n) | 大规模 | Louvain改进，更快更稳定 |

### 4.2 Louvain算法

```
算法原理：
1. 初始化：每个节点独立为一个社区
2. 迭代优化：
   a. 对每个节点，计算将其移动到邻居社区带来的模块度增益
   b. 选择增益最大的邻居社区（如果增益>0）
   c. 重复直到收敛
3. 压缩：合并同一社区内的节点
4. 重复直到全局模块度不再提升
```

```python
# NetworkX实现
import networkx as nx
from community import community_louvain

G = nx.read_gexf('paper_network.gexf')
partition = community_louvain.best_partition(G, resolution=1.0)

# 获取社区
communities = {}
for node, comm_id in partition.items():
    if comm_id not in communities:
        communities[comm_id] = []
    communities[comm_id].append(node)
```

class CommunityGNN(torch.nn.Module):
    def __init__(self, num_features, num_classes):
        super().__init__()
        self.conv1 = GCNConv(num_features, 128)
        self.conv2 = GCNConv(128, 64)

    def forward(self, data):
        x, edge_index = data.x, data.edge_index
        x = F.relu(self.conv1(x, edge_index))
        x = F.relu(self.conv2(x, edge_index))
        x, edge_index, _, _, _, _ = self.pool(x, edge_index)

def detect_communities(graph):
    """使用Leiden算法检测社区"""
    # 构建NetworkX图
    G = nx.Graph()
    for entity in graph.entities:

## 六、检索技术

### 6.1 知识图谱嵌入 (Knowledge Graph Embedding)

| 模型 | 原理 | 适用任务 | 复杂度 |
|------|------|----------|--------|
| **TransE** | h + r ≈ t | 一对一关系 | O(n) |
| **TransH** | 超平面投影 | 一对多关系 | O(n) |
| **TransR** | 关系空间投影 | 多关系 | O(nr) |
| **ComplEx** | 复数向量 | 非对称关系 | O(n) |
| **RotatE** | 旋转建模 | 全类型关系 | O(n) |

### 6.2 TransE详解

```python
# TransE实现
class TransE(torch.nn.Module):
    def __init__(self, num_entities, num_relations, embedding_dim):
        super().__init__()
        self.entity_embedding = nn.Embedding(num_entities, embedding_dim)
        self.relation_embedding = nn.Embedding(num_relations, embedding_dim)

    def forward(self, head, relation, tail):
        head_emb = self.entity_embedding(head)
        rel_emb = self.relation_embedding(relation)
        tail_emb = self.entity_embedding(tail)

        # h + r ≈ t
        score = head_emb + rel_emb - tail_emb
        return torch.norm(score, p=2, dim=1)

    def get_score(self, head, relation, tail):
        return -self.forward(head, relation, tail)  # 分数越高越好
```

### 6.4 微软GraphRAG检索流程

```python
# GraphRAG检索实现
class GraphRAGRetriever:
    def __init__(self, graph, vector_store):
        self.graph = graph
        self.vector_store = vector_store
        self.community_detector = LeidenCommunityDetector()

    def retrieve(self, query, top_k=10):
        # 1. 从查询中提取实体
        entities = self.extract_entities(query)

        # 2. 社区检测确定搜索范围
        relevant_communities = self.community_detector.find_relevant(
            entities, query
        )

        # 3. 收集社区内所有相关子图
        subgraphs = []
        for comm in relevant_communities:
            subgraph = self.graph.get_subgraph(comm.nodes)
            subgraphs.append(subgraph)

        # 4. 生成社区摘要
        summaries = [
            self.generate_summary(sg) for sg in subgraphs
        ]

        # 5. 上下文组装
        context = self.assemble_context(query, entities, summaries)

        return context

    def extract_entities(self, query):
        """使用LLM从查询中提取实体"""
        prompt = f"""
        从以下查询中提取实体和关系：
        {query}

        返回格式：
        entities: [entity1, entity2, ...]
        relations: [(entity1, relation, entity2), ...]
        """
        response = self.llm.complete(prompt)
        return parse_response(response)

    def find_relevant_communities(self, entities):
        """找到包含查询实体的社区"""
        communities = self.graph.get_all_communities()
        scored = []

        for comm in communities:
            # 计算社区与查询的相关度
            comm_entities = set(comm.entities)
            overlap = len(entities & comm_entities)
            score = overlap / len(entities | comm_entities)
            scored.append((comm, score))

        # 返回top-k社区
        return [c for c, s in sorted(scored, key=lambda x: -x[1])[:self.top_k]]
```

### 6.5 向量+图混合检索实现

```python
# 使用Neo4j + Qdrant混合检索
from neo4j import GraphDatabase
from qdrant_client import QdrantClient

class HybridRetriever:
    def __init__(self, neo4j_uri, qdrant_host):
        self.neo4j = GraphDatabase.driver(neo4j_uri)
        self.qdrant = QdrantClient(host=qdrant_host)

    def retrieve_papers(self, query, top_k=5):
        # 1. 向量检索获取候选论文
        query_embedding = self.get_embedding(query)
        vector_results = self.qdrant.search(
            collection_name="paper_embeddings",
            query_vector=query_embedding,
            limit=top_k * 2
        )

        # 2. 提取相关实体
        paper_ids = [r.id for r in vector_results]

        # 3. 图遍历扩展
        with self.neo4j.session() as session:
            cypher = """
            MATCH (p:Paper)-[:CITES]->(cited:Paper)
            WHERE p.id IN $paper_ids
            WITH p, count(cited) AS citation_count
            WHERE citation_count > 0
            RETURN p.id, p.title, citation_count
            ORDER BY citation_count DESC
            LIMIT $top_k
            """
            graph_results = session.run(cypher, paper_ids=paper_ids, top_k=top_k)

        # 4. 结果融合 (MMR)
        final_results = self.merge_results(
            vector_results, graph_results, query, top_k
        )

        return final_results

    def merge_results(self, vector_results, graph_results, query, top_k):
        """使用MMR融合结果"""
        seen = set()
        merged = []

        # 按分数排序合并
        all_results = []
        for r in vector_results:
            all_results.append((r, 'vector', r.score))
        for r in graph_results:
            all_results.append((r, 'graph', r['score']))

        all_results.sort(key=lambda x: -x[2])

        for item, source, score in all_results:
            if len(merged) >= top_k:
                break
            # MMR去重
            if item.id not in seen:
                seen.add(item.id)
                merged.append(item)

        return merged
```

### 7.2 GraphRAG架构分析

```python
# GraphRAG核心流程
class GraphRAG:
    def __init__(self):
        self.graph_store = Neo4jGraphStore()
        self.vector_store = LanceDBVectorStore()
        self.community_hierarchy = None

    def build_index(self, documents):
        # 1. 文档分块
        chunks = self.chunk_documents(documents)

        # 2. 实体关系抽取
        for chunk in chunks:
            entities, relations = self.extract_entities_relations(chunk)
            self.graph_store.upsert_entities(entities)
            self.graph_store.upsert_relations(relations)

        # 3. 社区检测
        self.community_hierarchy = self.detect_communities()

        # 4. 生成社区摘要
        for level in self.community_hierarchy.levels:
            for community in level.communities:
                summary = self.generate_community_summary(community)
                community.summary = summary

        # 5. 向量化
        embeddings = self.embed_documents(chunks)
        self.vector_store.index(embeddings)

    def query(self, user_query):
        # 1. 实体链接
        entities = self.extract_and_link_entities(user_query)

        # 2. 社区定位
        relevant_communities = self.locate_communities(entities)

        # 3. 收集社区上下文
        context = []
        for comm in relevant_communities:
            context.append(comm.summary)
            context.append(self.get_subgraph_snippet(comm, entities))

        # 4. 生成答案
        prompt = self.build_prompt(user_query, context)
        return self.llm.complete(prompt)
```

### 8.4 关键API设计

```python
class KnowledgeGraphService:
    def __init__(self, neo4j_uri, qdrant_url):
        self.graph = Neo4jGraph(neo4j_uri)
        self.vectors = QdrantClient(qdrant_url)

    # 查询接口
    def query_papers(self, query: str, filters: dict, top_k: int = 10):
        """混合检索：向量 + 图遍历"""
        # 1. 实体识别
        entities = self.extract_entities(query)

        # 2. 向量检索候选
        candidates = self.vector_search(query, top_k * 2)

        # 3. 图扩展
        expanded = self.graph_expand(candidates, entities)

        # 4. MMR融合
        results = self.mrr_merge(expanded, query, top_k)

        return results

    def find_related_papers(self, paper_id: str, depth: int = 2):
        """路径发现：查找相关论文"""
        return self.graph.find_paths(
            paper_id,
            max_depth=depth,
            relationship_types=['CITES', 'AUTHORED_BY']
        )

    def detect_communities(self, algorithm: str = 'leiden'):
        """社区检测"""
        if algorithm == 'leiden':
            return self.graph.leiden_communities()
        elif algorithm == 'louvain':
            return self.graph.louvain_communities()

    # 更新接口
    def update_paper(self, paper_data: dict):
        """增量更新论文"""
        self.graph.upsert_node('Paper', paper_data)

        # 更新向量
        embedding = self.compute_embedding(paper_data['abstract'])
        self.vectors.upsert(paper_data['id'], embedding)

    def batch_import(self, papers: list):
        """批量导入"""
        self.graph.execute_batch([
            f"MERGE (p:Paper {{id: '{p['id']}'}}) SET p = $props"
            for p in papers
        ])
```
