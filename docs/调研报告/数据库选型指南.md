## 一、存储需求分析

### 1.1 数据类型

| 数据类型 | 存储需求 | 特点 |
|----------|----------|------|
| 短期记忆 | 内存存储 | LRU+TTL,快速访问 |
| 会话记忆 | 内存/SSD | 高并发,跨Agent共享 |
| 长期记忆 | SSD/HDD | 持久化,向量嵌入 |
| 情景记忆 | SSD/HDD | 时序数据,轨迹记录 |
| 关系数据 | SSD | 结构化,关联查询 |
| 向量数据 | SSD | 语义搜索,高维 |

### 1.2 性能要求

| 需求 | 推荐方案 |
|------|----------|
| 向量相似度搜索 | < 100ms |
| 关键词搜索 | < 50ms |
| 图关系遍历 | < 200ms |
| 数据持久化 | 异步,不影响主流程 |

## 二、数据库推荐

### 2.1 PostgreSQL (主推荐)

**用途**: 关系数据 + 向量存储

**优势**:
- 单一数据库满足多种需求
- pgvector扩展支持向量搜索
- 成熟稳定,生态丰富
- JSON支持,灵活扩展

**配置示例**:
```sql
-- 启用pgvector扩展
CREATE EXTENSION IF NOT EXISTS vector;

-- 创建向量表
CREATE TABLE embeddings (
    id SERIAL PRIMARY KEY,
    memory_id VARCHAR(255),
    content TEXT,
    embedding vector(1536),
    created_at TIMESTAMP DEFAULT NOW()
);

-- 创建HNSW索引(快速近似最近邻)
CREATE INDEX ON embeddings USING HNSW (embedding vector_cosine_ops);
```

**Python集成**:
```python
import psycopg2
from pgvector.psycopg2 import register_vector

conn = psycopg2.connect(os.getenv("DATABASE_URL"))
register_vector(conn.cursor())
cursor = conn.cursor()
cursor.execute("SELECT * FROM embeddings ORDER BY embedding <=> %s LIMIT 5", [query_vector])
```

### 2.2 Redis

**用途**: 缓存 + 短期记忆

**优势**:
- 内存存储,超高性能
- 支持多种数据结构
- 丰富的数据淘汰策略

**配置示例**:
```python
import redis

r = redis.Redis(host='localhost', port=6379, db=0)

# LRU缓存
r.setex("memory:key", ttl_seconds=3600, value=data)

# 批量操作
pipe = r.pipeline()
for key, value in memories:
    pipe.setex(key, 3600, value)
pipe.execute()
```

### 2.3 Neo4j

**用途**: 图数据 + 实体关系

**优势**:
- 原生图数据库
- 强大的图遍历查询
- 可视化工具

**配置示例**:
```python
from neo4j import GraphDatabase

driver = GraphDatabase.driver("bolt://localhost:7687", auth=(user, pass))

def find_related_entities(entity_id):
    with driver.session() as session:
        result = session.run("""
            MATCH (e1:Entity {id: $id})-[:RELATES_TO*1..3]-(e2:Entity)
            RETURN e2.id, e2.name, COUNT(*) as relation_count
            ORDER BY relation_count DESC
            LIMIT 10
        """, id=entity_id)
        return [dict(record) for record in result]
```

### 2.4 Milvus/Qdrant (备选向量数据库)

**适用场景**: 大规模向量数据(>100万条)

**优势**:
- 专用向量引擎
- 更强的向量搜索性能
- 分布式支持

**配置示例**:
```python
from pymilvus import connections, Collection

connections.connect("default", host="localhost", port="19530")
collection = Collection("memory_embeddings")
collection.load()

# 向量搜索
search_params = {"metric_type": "IP", "params": {"nprobe": 10}}
results = collection.search(
    data=[query_vector],
    anns_field="embedding",
    param=search_params,
    limit=10
)
```

### 6.4 MCP 集成方案

```python
# 通过 MCP 协议标准化向量数据库访问
# MCP Server: mcp-server-milvus / mcp-server-qdrant

from mcp.server import Server
import mcp.types as types

class VectorDBMCPServer:
    """向量数据库 MCP Server - 标准化Paper Agent的向量检索"""

    def __init__(self, db_type: str = "qdrant"):
        self.server = Server(f"{db_type}-mcp-server")

    @self.server.list_tools()
    async def handle_list_tools() -> list[types.Tool]:
        return [
            types.Tool(
                name="semantic_search",
                description="语义相似论文检索",
                inputSchema={
                    "type": "object",
                    "properties": {
                        "query": {"type": "string"},
                        "collection": {"type": "string", "default": "papers"},
                        "top_k": {"type": "integer", "default": 10},
                        "filter": {"type": "object"}  # 按年份/领域过滤
                    },
                    "required": ["query"]
                }
            ),
            types.Tool(
                name="hybrid_search",
                description="混合检索：向量相似度 + 关键词BM25 + 图遍历",
                inputSchema={...}
            )
        ]
```

### 6.5 GraphRAG 存储架构

```
┌──────────────────────────────────────────────────────┐
│              GraphRAG 存储层                           │
├──────────────────────────────────────────────────────┤
│  文档 → 分块 → 实体/关系提取 → 知识图谱 (Neo4j)       │
│         ↓                                            │
│    向量嵌入 → 向量存储 (Qdrant/Milvus)               │
│         ↓                                            │
│    社区检测 → 社区摘要 → 社区嵌入 (Qdrant)           │
│         ↓                                            │
│    全文索引 → Elasticsearch / PostgreSQL             │
└──────────────────────────────────────────────────────┘
```

**推荐组合**: Neo4j (图) + Qdrant (向量) + PostgreSQL (全文+元数据)
