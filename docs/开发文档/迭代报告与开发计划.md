## 一、项目概述

### 核心能力

| 模块 | 功能 |
|------|------|
| 智能路由 | IntentRouter - 自动判断问题类型 |
| 论文搜索 | PaperSearchAgent - arXiv/PubMed等学术平台 |
| 文献综述 | LiteratureAgent - 基于真实论文的专业回答 |
| 选题辅助 | TopicAgent - 智能选题建议 |
| 论文写作 | DraftWriterAgent - 全流程辅助 |

## 二、全链路架构

```
用户输入
    ↓
┌─────────────────────────────────────────────┐
│ 1. 输入处理层 (api_server.py / demo.py)     │
└─────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────┐
│ 2. 意图路由层 (IntentRouter)                │
│    - 关键词匹配 + LLM fallback              │
│    - 11种IntentType                        │
└─────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────┐
│ 3. MasterSupervisor (全局协调器)            │
│    - 状态管理 (PaperState)                  │
│    - 6阶段流转: diagnostic→topic→...       │
└─────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────┐
│ 4. PhaseSupervisor (阶段协调器)             │
│    - diagnostic/topic/literature/methodology │
│    - writing/polish                         │
└─────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────┐
│ 5. 执行层 (Agent)                           │
│    - PaperSearch/Thesis/Outline/Draft Agent │
└─────────────────────────────────────────────┘
    ↓
用户输出
```

### 核心入口文件

| 文件路径 | 功能 |
|---------|------|
| `src/agents_v2/api_server.py` | HTTP API服务入口 |
| `src/agents_v2/demo.py` | 演示脚本入口 |
| `src/agents_v2/unified/master_supervisor.py` | 核心协调器 |
