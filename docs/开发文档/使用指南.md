## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

```bash
# 创建 .env 文件
OPENAI_API_KEY=your_api_key_here
LLM_PROVIDER=openai
LLM_MODEL=gpt-4
```

### 3. 启动服务

```bash
# 后端 (localhost:8000)
python -m src.agents_v2.api_server

# 前端 (可选, localhost:3000)
cd frontend && npm install && npm run dev
```

### 4. 验证服务

```bash
curl http://localhost:8000/health
curl -H "X-API-Key: dev-api-key" http://localhost:8000/api/papers
```

## 运行方式

### 演示脚本

```bash
python -m src.agents_v2.demo
```

### Python API

```python
import asyncio
from src.agents_v2.paper_agents import TopicAgent

async def main():
    agent = TopicAgent()
    result = await agent.execute({"user_request": "机器学习在医疗诊断中的应用"})
    print(f"成功: {result.success}, 质量: {result.quality_score}")

asyncio.run(main())
```

### HTTP API

```bash
# 启动服务
python -m src.agents_v2.api_server

# 健康检查
curl http://localhost:8000/health

# 选题
curl -X POST http://localhost:8000/api/topic \
  -H "X-API-Key: dev-api-key" \
  -d '{"user_request": "深度学习优化"}'

# 论文搜索
curl -X POST http://localhost:8000/api/search \
  -H "X-API-Key: dev-api-key" \
  -d '{"query": "transformer", "max_results": 5}'
```

## Docker部署

### 快速部署

```bash
git clone <repository_url>
cd paper-agent
cp .env.example .env  # 编辑填入API密钥
docker-compose up -d
docker-compose ps
```

### Docker Compose 配置

```yaml
services:
  paper-agent:
    build: .
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY}
    ports:
      - "8000:8000"
```

### 常用命令

```bash
docker-compose up -d      # 启动
docker-compose down       # 停止
docker-compose logs -f    # 查看日志
```

## API端点

### 论文管理

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/papers` | GET | 论文列表 |
| `/api/papers` | POST | 创建论文 |
| `/api/papers/{id}` | GET/PUT/DELETE | 论文CRUD |
| `/api/papers/{id}/outline/generate` | POST | 生成大纲 |
| `/api/papers/{id}/sections/{sectionId}/generate` | POST | 生成分段 |

### 文献管理

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/literature/search` | POST | 搜索文献 |
| `/api/papers/{paperId}/literature` | POST | 添加文献到论文 |
| `/api/literature/{id}/citation` | GET | 获取引用格式 |

### 其他

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/papers/{paperId}/chat` | POST | AI对话 |
| `/api/settings` | GET/PUT | 设置管理 |
| `/api/topic` | POST | 选题 |
| `/api/search` | POST | 论文搜索 |

### 认证

所有认证端点需要 header: `X-API-Key: dev-api-key`

## 常见问题

**Q: 前端无法连接后端？**
- 确认后端运行在 `http://localhost:8000`
- 检查 vite.config.js 代理配置

**Q: API返回401？**
- 确认请求头包含 `X-API-Key`

**Q: 前端修改需要重启吗？**
- 不需要，Vite支持热更新

**Q: API调用失败？**
- 检查 `.env` 配置和 `OPENAI_API_KEY` 是否有效

**Q: 中文显示乱码？**
- 使用GPT-4/Claude，或使用TranslationWrapper
