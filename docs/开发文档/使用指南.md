## 系统概述

Paper Agent 是一个基于多Agent协作的学术论文自动调研与综述生成系统。

### 核心能力

| 模块 | 功能 | 说明 |
|------|------|------|
| 智能路由 | IntentRouter | 自动判断问题类型，决定处理策略 |
| 论文搜索 | PaperSearchAgent | 从arXiv/PubMed等学术平台搜索论文 |
| 文献综述 | LiteratureAgent | 基于真实论文给出专业回答 |
| 选题辅助 | TopicAgent | 智能选题建议 |
| 论文写作 | DraftWriterAgent | 从选题到完稿的全流程辅助 |

### 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                    Paper Agent System                      │
├─────────────────────────────────────────────────────────┤
│  Frontend (React + Ant Design) │ Backend (Python aiohttp) │
│  - localhost:3000             │ - localhost:8000          │
└─────────────────────────────────────────────────────────┘
```

## 快速开始

### 1. 环境要求

- Python 3.10+
- Node.js 18+ (仅前端开发)
- npm 或 yarn

### 2. 安装后端依赖

```bash
cd /d/pycharmprojects/pythonProject1
pip install -r requirements.txt
```

### 3. 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑 .env 文件
OPENAI_API_KEY=your_api_key_here
LLM_PROVIDER=openai
LLM_MODEL=gpt-4
```

### 4. 启动后端服务

```bash
python -m src.agents_v2.api_server
```

后端服务将在 `http://localhost:8000` 启动。

### 5. 启动前端服务

```bash
cd frontend
npm install
npm run dev
```

前端服务将在 `http://localhost:3000` 启动。

### 6. 验证服务

```bash
# 健康检查
curl http://localhost:8000/health

# 获取论文列表 (需要认证)
curl -H "X-API-Key: dev-api-key" http://localhost:8000/api/papers
```

## 认证方式

### API密钥认证

所有需要认证的端点都需要在请求头中添加 `X-API-Key`。

**默认开发密钥**: `dev-api-key`

```bash
# 带认证的请求示例
curl -H "X-API-Key: dev-api-key" http://localhost:8000/api/papers
```

```javascript
// 前端会自动添加X-API-Key header
const apiKey = localStorage.getItem('api_key') || 'dev-api-key'
config.headers['X-API-Key'] = apiKey
```

### 生产环境建议

1. 在 `.env` 中设置强密码的 `API_KEY`
2. 定期轮换API密钥
3. 使用HTTPS传输
4. 考虑添加IP白名单

## 核心功能

### 1. 创建新论文

```bash
curl -X POST http://localhost:8000/api/papers \
  -H "X-API-Key: dev-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "深度学习在医学影像诊断中的应用",
    "topic": "医学影像诊断"
  }'
```

### 2. 生成论文大纲

```bash
curl -X POST http://localhost:8000/api/papers/{paper_id}/outline/generate \
  -H "X-API-Key: dev-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "深度学习在医学影像诊断中的应用"
  }'
```

### 3. 搜索文献

```bash
curl -X POST http://localhost:8000/api/literature/search \
  -H "X-API-Key: dev-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "deep learning medical imaging",
    "max_results": 10
  }'
```

### 4. AI对话

```bash
curl -X POST http://localhost:8000/api/papers/{paper_id}/chat \
  -H "X-API-Key: dev-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "如何提高深度学习模型的泛化能力？"
  }'
```

### 5. 获取/更新设置

```bash
# 获取设置
curl http://localhost:8000/api/settings \
  -H "X-API-Key: dev-api-key"

# 更新设置
curl -X PUT http://localhost:8000/api/settings \
  -H "X-API-Key: dev-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "theme": "dark",
    "defaultCitationStyle": "apa"
  }'
```

## 常见问题

### Q: 前端无法连接后端？

1. 确认后端服务运行在 `http://localhost:8000`
2. 检查前端 vite.config.js 代理配置
3. 检查浏览器控制台网络请求

### Q: API返回401未授权？

1. 确认请求头中包含 `X-API-Key`
2. 检查API密钥是否正确
3. 确认 .env 文件中的 API_KEY 配置

### Q: 如何添加新的API端点？

1. 在 `src/agents_v2/api/paper_api.py` 中添加处理函数
2. 在 `setup_paper_routes()` 中注册路由
3. 重启后端服务

### Q: 前端修改后需要重启吗？

不需要。Vite 开发服务器支持热模块替换（HMR），修改代码会自动更新。
