## 🎯 使用示例

### 增强检索

```python
from src.agents_v2.retrieval.enhanced_retrieval_pipeline import enhanced_retrieve

result = await enhanced_retrieve(
    query="deep learning in medical imaging",
    retriever=your_retriever,
    llm=your_llm,
    top_k=20,
    enable_all_optimizations=True
)

print(f"找到 {len(result.documents)} 个文档")
print(f"召回率提升: {result.metadata}")
```

### 增强记忆

```python
from src.agents_v2.personalization.enhanced_memory_system import (
    EnhancedMemorySystem
)

memory = EnhancedMemorySystem(
    storage_path=".memory",
    enable_forgetting_curve=True,
    enable_preference_learning=True
)

# 记住内容
await memory.remember(
    user_id="user123",
    content="深度学习在医学影像中的应用",
    importance=8.0
)

# 回忆内容
recalled = await memory.recall(
    user_id="user123",
    query="医学影像AI",
    top_k=5
)

# 个性化响应
personalized = await memory.get_personalized_response(
    user_id="user123",
    query="医学影像诊断",
    base_response="基础回答..."
)
```
