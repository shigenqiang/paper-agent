## 二、链路深化研究提示词

### 2.1 输入处理层研究

```
深度研究论文Agent的输入处理层：

### 意图识别

   - LLM-based意图分类的最佳实践？

### 多语言处理
1. 中英文混合输入如何处理？
2. 跨语言检索如何实现？
3. 多语言输出的质量保证？

## 现有方案分析
请对比分析3-5个主流系统的输入处理方案，指出各自优缺点。
```

## 三、综合研究提示词

```
## 论文Agent全链路深度研究

你是一家AI研究机构的高级研究员。请对论文Agent进行全面的技术研究。

### 研究范围

1. **输入处理**
   - 意图识别：准确率>90%的实现方案
   - 输入验证：安全性和有效性保障
   - 多语言支持：中英文混合处理

2. **检索增强**
   - 多源检索：ArXiv / PubMed / SS 的最优组合
   - 查询优化：改写 / 扩展 / 去重
   - 结果融合：排序算法与置信度计算

3. **文档解析**
   - PDF解析：文本 / 表格 / 图表 / 公式
   - 结构化：章节分类 / 引用链接 / 知识抽取
   - 质量评估：解析准确率的衡量标准

4. **内容生成**
   - 论文写作：各章节的生成策略
   - 质量控制：Self-RAG / 反思机制 / 修订流程
   - 引用生成：自动插入与格式规范

5. **系统架构**
   - 多Agent协作：通信协议 / 状态管理 / 错误处理
   - Pipeline编排：串行 / 并行 / 条件分支
   - 可扩展性：模块化 / 插件机制

### 研究要求

1. **技术深度**：每个环节需要深入到具体算法和实现细节
2. **实践验证**：通过代码实验验证方案的可行性
3. **对比分析**：对比多个方案的优劣
4. **改进建议**：指出现有系统的不足，提出具体的改进方向

### 输出结构

1. 每个链路的现状分析
2. 关键技术点详解
3. 最佳实践建议
4. 遗漏点清单
5. 优先级排序的改进计划

### 发现遗漏点时的要求

当你发现现有系统中没有注意到的重要技术点时：
1. 详细说明该技术点的价值
2. 提供具体的实现思路
3. 给出预期的效果提升
4. 评估实现的复杂度
```
