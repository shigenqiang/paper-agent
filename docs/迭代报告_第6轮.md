## 二、发现的根本问题

### MiniMax-M2.7 中文编码问题

**问题描述**: MiniMax-M2.7模型在处理中文时存在编码问题。

**表现**:
- 发送中文到API → 模型收到的中文是乱码
- 模型生成的中文 → 返回的中文是乱码
- 英文内容处理正常

**影响范围**: 所有依赖LLM生成中文内容的Agent

**根本原因**: 模型在处理UTF-8中文字符时存在bug

**测试验证**:
```python
# 英文输入输出 - 正常
Input: '{"name": "test"}' → Output: '{"name":"test"}' ✓

# 中文输入输出 - 失败
Input: '{"name": "测试"}' → 中文变乱码 ✗
```
