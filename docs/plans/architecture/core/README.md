# core 模块开发计划

> 状态：已规划
> 与未来框架设计 v2.1 对齐

## 模块定位

core 模块是整个 Agent 系统的基础层，提供：
- BaseAgent 基类 + LLMConfig
- MCP Client 协议集成
- 意图路由三级级联
- 上下文智能压缩
- 流式输出增强

## 与未来框架设计对应

| 未来框架设计 | 本模块任务 |
|-------------|-----------|
| 三级级联意图路由 | Layer 1/2/3 + 置信度校准 |
| MCP 协议集成 | MCP Client + 工具调用封装 |
| 智能上下文 | 重要性评估 + 摘要生成 + 窗口管理 |
