# Topic Evaluation - 选题阶段评估标准

**模块状态：规划中**

---

## 概述

选题阶段评估标准模块负责对生成的候选主题进行系统化质量评估，基于国际标准（NSF/NIH/Horizon Europe）建立四维度评估框架，并对评分制式进行统一。

## 核心功能

1. **四维度评估**：创新性、重要性、可行性、清晰性
2. **评分制式统一**：统一使用0-1分制
3. **研究空白识别**：自动识别领域研究空白点
4. **综合质量评分**：加权计算最终综合分

## 评估维度

| 维度 | 权重 | 描述 |
|------|------|------|
| 创新性 (Novelty) | 30% | 理论/方法/应用创新 |
| 重要性 (Significance) | 25% | 研究空白、学术/实践价值 |
| 可行性 (Feasibility) | 25% | TR/L、资源、时间 |
| 清晰性 (Clarity) | 20% | 问题、范围、目标 |
