# 选题阶段评估标准细化方案

**创建日期：2026-05-03**

---

## 一、背景与问题

根据调研结果和国际标准对比，发现当前选题阶段存在以下问题：

### 1.1 现有评估维度不足

| 现有维度 | 问题 |
|---------|------|
| literature_adequacy | 仅文献充足性，缺研究空白评估 |
| method_feasibility | 仅方法可行性，缺技术成熟度(TRL) |
| novelty | 未区分理论/方法/应用创新 |
| time_reasonableness | 仅时间维度 |
| resource_accessibility | 仅资源维度 |

### 1.2 评分制式不一致

| 模块 | 当前制式 | 问题 |
|------|---------|------|
| MasterSupervisor | 0-1阈值 | 统一标准 |
| TopicScores | 1-10分 | 与阈值不匹配 |
| TopicRefinerAgent | 0-10分 | 与阈值不匹配 |

### 1.3 缺少国际标准对齐

NSF/NIH/Horizon Europe等权威框架的核心维度未体现在评估中：
- NSF: Intellectual Merit + Broader Impacts
- NIH: Significance, Innovation, Approach, Environment, Investigator
- Horizon Europe: Excellence, Impact, Implementation

## 二、评估标准体系设计

### 2.1 四维度评估框架（对齐国际标准）

| 维度 | 权重 | 子指标 | 描述 |
|------|------|--------|------|
| **创新性 (Novelty)** | 30% | 理论创新 | 突破现有理论框架 |
| | | 方法创新 | 采用新方法或改进现有方法 |
| | | 应用创新 | 将理论应用于新领域 |
| **重要性 (Significance)** | 25% | 研究空白明确性 | 识别并填补研究空白 |
| | | 学术价值 | 对学科发展的贡献 |
| | | 实践价值 | 对实际应用的贡献 |
| **可行性 (Feasibility)** | 25% | 技术成熟度(TRL) | 基于1-9级TRL框架 |
| | | 资源可获得性 | 数据、设备、人力 |
| | | 时间合理性 | 周期内可完成 |
| **清晰性 (Clarity)** | 20% | 问题清晰度 | 研究问题明确 |
| | | 范围定义 | 研究边界清晰 |
| | | 目标具体性 | 目标可量化评估 |

### 2.2 评分等级

| 等级 | 分数范围 | 说明 |
|------|---------|------|
| EXCELLENT | ≥0.8 | 全面满足评估标准 |
| GOOD | ≥0.65 | 大部分满足，少量优化空间 |
| ACCEPTABLE | ≥0.5 | 满足基本要求，需改进 |
| POOR | <0.5 | 存在重大问题 |

### 2.3 综合评分计算公式

```
创新性综合分 = (理论创新×0.4 + 方法创新×0.35 + 应用创新×0.25)
重要性综合分 = (研究空白×0.4 + 学术价值×0.3 + 实践价值×0.3)
可行性综合分 = (TRL×0.4 + 资源×0.3 + 时间×0.3)
清晰性综合分 = (问题清晰×0.35 + 范围定义×0.35 + 目标具体×0.3)

最终分 = 创新性×0.30 + 重要性×0.25 + 可行性×0.25 + 清晰性×0.20
```

## 三、评分制式统一方案

### 3.1 统一使用0-1分制

| 模块 | 修改前 | 修改后 |
|------|--------|--------|
| MasterSupervisor阈值 | 0-1 | 保持0-1 |
| TopicScores | 1-10 | 0-1 |
| TopicRefinerAgent | 0-10 | 0-1 |
| QualityScore | 0-1 | 保持0-1 |

### 3.2 阈值对应关系

| 等级 | 阈值范围 | 说明 |
|------|---------|------|
| 选题阶段通过 | ≥0.7 | MasterSupervisor当前设置 |
| 良好 | ≥0.65 | 优化建议 |
| 优秀 | ≥0.8 | 可选更高标准 |
