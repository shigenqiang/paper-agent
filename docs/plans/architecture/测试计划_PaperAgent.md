# Paper Agent 测试计划

**测试日期**: 2026-05-01
**测试模型**: MiniMax-M2.7
**测试目标**: 评估各功能模块的性能和质量

---

## 1. 功能优先级分析

### 核心功能（必须测试）

| 优先级 | 功能 | Agent | 重要性说明 |
|--------|------|-------|-----------|
| P0 | 选题推荐 | TopicAgent | 论文起点，决定研究方向 |
| P0 | 文献搜索 | PaperSearchAgent | 获取参考资料的基础能力 |
| P0 | 大纲生成 | OutlineAgent | 论文结构框架，影响整体质量 |
| P1 | 文献综述 | LiteratureReviewAgent | 背景研究，学术规范性 |
| P1 | 开题报告 | ProposalGeneratorAgent | 研究计划制定 |
| P1 | 意图路由 | IntentRouter | 智能调度入口 |

### 扩展功能（可选测试）

| 优先级 | 功能 | Agent | 重要性说明 |
|--------|------|-------|-----------|
| P2 | 初稿生成 | DraftGeneratorAgent | 长文本生成能力 |
| P2 | 智能改稿 | SmartReviserAgent | 内容优化能力 |
| P2 | 引用生成 | CitationGenerator | 学术规范工具 |
| P3 | 反思引擎 | ReflectionEngine | 质量改进机制 |
| P3 | 流式生成 | StreamingGenerator | 用户体验优化 |

---

## 2. 测试维度

每个功能测试以下维度：

| 维度 | 指标 | 说明 |
|------|------|------|
| **响应时间** | 秒(s) | 从请求到返回的耗时 |
| **成功率** | % | 请求成功完成的比例 |
| **输出质量** | 1-5分 | 人工评估输出质量 |
| **格式正确性** | 是/否 | 输出格式是否符合预期 |
| **内容相关性** | 1-5分 | 输出与输入的相关程度 |

---

## 3. 测试用例设计

### 3.1 选题推荐 (TopicAgent)

**测试输入**:
```
用户请求: "我想研究人工智能在医疗领域的应用"
```

**预期输出**:
- 返回3-5个选题建议
- 每个选题包含：标题、研究方向、可行性分析
- 响应时间 < 30秒

**质量标准**:
- 选题具有学术价值
- 选题之间有差异性
- 包含创新性建议

---

### 3.2 文献搜索 (PaperSearchAgent)

**测试输入**:
```
查询: "transformer attention mechanism"
来源: arxiv
最大结果: 5
```

**预期输出**:
- 返回相关论文列表
- 每篇论文包含：标题、作者、摘要、链接
- 响应时间 < 20秒

**质量标准**:
- 论文与查询高度相关
- 包含近年高质量论文
- 信息完整准确

---

### 3.3 大纲生成 (OutlineAgent)

**测试输入**:
```
主题: "深度学习模型压缩技术研究"
要求: "包含模型剪枝、量化、知识蒸馏三个方面"
```

**预期输出**:
- 层次化的大纲结构
- 包含章节标题和简要说明
- 响应时间 < 30秒

**质量标准**:
- 结构清晰合理
- 覆盖主要研究方向
- 符合学术论文规范

---

### 3.4 文献综述 (LiteratureReviewAgent)

**测试输入**:
```
主题: "大语言模型的发展历程"
```

**预期输出**:
- 综述性文本
- 包含关键论文引用
- 响应时间 < 45秒

**质量标准**:
- 时间线清晰
- 重要工作有覆盖
- 语言学术规范

---

### 3.5 开题报告 (ProposalGeneratorAgent)

**测试输入**:
```
题目: "基于深度学习的图像超分辨率算法研究"
背景: "图像超分辨率在医学影像、卫星遥感等领域有重要应用"
意义: "提高图像质量对下游任务有显著帮助"
```

**预期输出**:
- 完整开题报告结构
- 包含研究背景、意义、方法、计划
- 响应时间 < 60秒

**质量标准**:
- 逻辑连贯
- 研究问题明确
- 方法可行

---

### 3.6 意图路由 (IntentRouter)

**测试输入**:
```
测试请求列表:
1. "我想写一篇关于深度学习的论文"
2. "帮我搜索Transformer相关论文"
3. "生成一个开题报告"
4. "润色我的论文摘要"
```

**预期输出**:
- 正确识别意图
- 推荐合适的Agent
- 响应时间 < 5秒

**质量标准**:
- 意图识别准确
- Agent推荐合理
- 处理模式正确


## 6. 风险与注意事项

1. **API限流**: MiniMax可能有调用频率限制，测试间隔建议3-5秒
2. **网络延迟**: 不同时间段网络状况可能不同
3. **模型随机性**: 相同输入可能得到不同输出，关注质量趋势
4. **成本控制**: 每次调用消耗token，控制测试次数
