# storage 模块开发计划

> 状态：已规划
> 与未来框架设计 v2.1 对齐

## 模块定位

storage 模块是数据持久化核心，提供：
- PostgreSQL 论文存储
- Qdrant 向量存储
- Neo4j 图谱存储
- Redis 分布式缓存
- 统一存储接口

## 与未来框架设计对应

| 未来框架设计 | 本模块任务 |
|-------------|-----------|
| PostgreSQL + Qdrant | 论文 + 向量存储 |
| Neo4j | 图谱实体关系 |
| Redis | 分布式缓存 |
| 存储抽象 | StorageAdapter + 事务 |
