# 论文写作系统性能优化与QA系统测试

## 任务目标

1. **性能优化**：缩减论文写作流程的运行时间，同时保持论文质量不下降
2. **QA系统测试**：完善QA系统功能，使用Neo4j知识图谱

## 具体要求

### 1. 性能优化
- 测试当前 `paper_pipeline.py` 的运行时间
- 分析可并行的环节（目前是串行执行）
- 实现并行化优化
- 如果当前方法效果不佳，**去网上调研方案**并实现
- 记录优化前后的时间对比

### 2. QA系统测试
- 使用Docker/容器方式运行Neo4j
- 测试知识图谱问答功能
- 完善QA系统直到功能完整可用

### 3. 性能记录
- 记录每个阶段的时间消耗
- 记录并发数、吞吐量等指标
- 对比优化前后的效果

## 执行步骤

### 阶段1：性能基线测试
1. 运行 `paper_pipeline.py`，记录总时间和各阶段时间
2. 分析瓶颈环节

### 阶段2：并行化优化
1. 识别可并行的模块（如文献搜索、大纲生成、章节撰写等）
2. 实现 asyncio 并行化
3. 测试优化效果

### 阶段3：QA系统测试
1. 启动 Neo4j 容器
2. 运行 QA 测试
3. 修复发现的问题

## 预期成果
- 论文生成时间显著缩短（目标：减少50%以上）
- 论文质量保持稳定
- QA系统功能完善可运行
