## 模块概述

Scheduler模块负责任务调度和资源管理。

### 核心功能

| 功能 | 说明 |
|------|------|
| **任务队列** | 异步任务队列管理 |
| **优先级调度** | 任务优先级排序 |
| **资源分配** | GPU/Token资源分配 |
| **限流控制** | Rate Limit管理 |

### 技术选型

| 组件 | 技术 |
|------|------|
| **队列** | Celery + Redis |
| **调度** | APScheduler |
| **限流** | Token Bucket |
