> 规划日期：2026-05-02 | 版本：v1.0

## 模块概述

Diagnostic模块负责论文质量诊断和问题检测。

### 诊断维度

| 诊断项 | 说明 |
|--------|------|
| **清晰度** | 论文表达清晰度评估 |
| **逻辑性** | 论点逻辑严密性 |
| **贡献度** | 研究贡献度评估 |
| **原创性** | 原创性检测 |
| **规范性** | 学术格式规范 |
