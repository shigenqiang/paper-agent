## 模块概述

知识图谱模块负责实体关系存储和检索。

### 技术选型

| 组件 | 技术 | 用途 |
|------|------|------|
| **KG Service** | Neo4j + Qdrant | 实体关系 + 向量检索 |

### 核心功能

| 功能 | 说明 |
|------|------|
| **实体管理** | 论文、作者、概念等实体 |
| **关系抽取** | 实体间关系自动抽取 |
| **图谱查询** | Cypher查询 + 向量相似 |
| **推理能力** | CARA自适应推理 |

### Hindsight 图谱整合

| 技术 | 原理 | 适用场景 |
|------|------|---------|
| **TEMPR** | 时序检索 | 时间敏感查询 |
| **CARA** | 自适应推理 | 复杂推理 |
