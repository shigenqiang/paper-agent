## 模块概述

Paper Agents是专注于学术论文处理的Agent集合。

### Agent职责矩阵

| Agent | 核心技能 | 输入 | 输出 |
|-------|---------|------|------|
| **LiteratureSearcher** | 多源检索 | 查询词 | 论文列表 |
| **LiteratureReviewer** | 综述生成 | 论文列表 | 综述文本 |
| **OutlineDesigner** | 大纲设计 | 主题 | 结构化大纲 |
| **SectionWriter** | 章节写作 | 大纲+文献 | 章节草稿 |
| **CitationManager** | 引用管理 | 参考文献 | 格式化引用 |

### 工作流集成

```
Searcher → Reviewer → Planner → Writer → Polisher
   ↓          ↓          ↓         ↓        ↓
 选题      综述      大纲      写作     润色
```
