## 模块概述

Core模块包含Agent核心组件和上下文注入器。

### 核心组件

| 组件 | 说明 |
|------|------|
| **UnifiedAgent** | 统一Agent基类 |
| **ContextInjector** | 上下文注入器，含智能触发和遗忘曲线 |
| **PromptCache** | Prompt缓存，优化路由成本 |
| **LLMConfig** | LLM统一配置 |

### ContextInjector 智能触发机制

```
_should_recall_memories() - 历史关键词检测
  检查: ["之前", "上次", "曾经", "还记得", ...]

_prioritize_memories() + 遗忘曲线
  retention = importance × e^(-t/S)
  重要性阈值过滤 (< 0.3 丢弃)
```

---

## 核心公式

```
遗忘曲线: retention = importance × e^(-t/S)

重要性等级与S参数：
- CRITICAL (1.0): S = ∞
- HIGH (0.8): S = 604,800秒 (7天)
- MEDIUM (0.5): S = 86,400秒 (1天)
- LOW (0.3): S = 3,600秒 (1小时)
```
