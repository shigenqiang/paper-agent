## 模块概述

LangGraph Workflow模块实现六阶段写作流水线统一编排。

### 六阶段工作流

```
阶段1: 选题诊断
阶段2: 文献综述
阶段3: 大纲规划
阶段4: 逐章写作 (Generator-Critic循环)
阶段5: 综合润色
阶段6: 格式输出
```

### 核心节点

| 节点 | 说明 |
|------|------|
| **RouteNode** | 三级级联路由入口 |
| **SearcherNode** | 搜索节点 |
| **PlannerNode** | 规划节点 |
| **WriterNode** | 写作节点 |
| **ReviewerNode** | 评审节点 |
| **PolisherNode** | 润色节点 |
| **CheckpointNode** | 检查点 |

### 状态管理

- LangGraph SqliteSaver/PostgresSaver持久化
- 支持暂停/恢复/时间旅行调试
- 状态快照包含完整上下文
