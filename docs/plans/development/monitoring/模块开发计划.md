## 6.4 日志系统标准

| 要求 | 说明 |
|------|------|
| **多级别** | TRACE/DEBUG/INFO/WARN/ERROR/CRITICAL |
| **多目标** | 控制台、文件、远程服务器 |
| **滚动** | 按大小/时间自动滚动 |
| **异步** | 异步写入，不阻塞业务 |
| **结构化** | JSON格式，便于分析 |
| **可关联** | TraceId串联全链路日志 |
| **可告警** | 日志异常实时告警 |
