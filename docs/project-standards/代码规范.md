# 代码规范

本文档定义代码编写标准，基于以下官方规范：
- [Google Style Guides](https://github.com/google/styleguide)
- [PEP 8](https://pep8.org/) — Python 官方编码规范
- [PEP 561](https://peps.python.org/pep-0561/) — 类型信息分发
- [Conventional Commits](https://www.conventionalcommits.org/) — Git 提交规范
- [OWASP Top 10 for LLMs](https://owasp.org/www-project-top-10-for-large-language-model-applications/) — LLM 安全

## 1. 命名规范

### 1.1 命名基本原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **清晰性** | 名称应清晰表达意图 | `get_user_by_id` 而非 `get_user` |
| **一致性** | 同一概念全程使用相同名称 | 统一用 `id` 而非混用 `id`/`ID`/`Id` |
| **简洁性** | 在保证清晰的前提下简短 | `calc_total` 而非 `calculate_total_amount` |
| **可读性** | 使用完整单词或常见缩写 | `config` 而非 `cfg` |

### 1.2 变量命名

| 类型 | 命名规范 | 示例 |
|------|----------|------|
| 普通变量 | `snake_case` | `user_name`, `total_count` |
| 常量 | `UPPER_SNAKE_CASE` | `MAX_RETRY_COUNT`, `API_BASE_URL` |
| 布尔变量 | `is/has/can/should` 前缀 | `is_active`, `has_permission` |
| 私有变量 | `_` 前缀 | `_private_method` |
| 类型变量 | `PascalCase` | `T`, `UserT` |

**避免的无意义命名：**
```python
# 禁止
x, temp, data, info, val, obj

# 推荐
user_index, temporary_file, user_data, file_size
```

### 1.3 函数/方法命名

| 场景 | 规范 | 示例 |
|------|------|------|
| 普通方法 | `snake_case` | `get_user`, `process_data` |
| 私有方法 | `_snake_case` | `_validate_input` |
| 异步方法 | `snake_case`（用 async/await） | `async def fetch_data()` |
| Getter | `get_xxx` 或属性 | `@property def name()` |
| 工厂方法 | `from_xxx`, `create_xxx` | `User.from_dict()` |

**动词参考：**

| 动作 | 方法名示例 |
|------|------------|
| 获取 | `get_user`, `fetch_orders`, `retrieve_data` |
| 创建 | `create_user`, `generate_report` |
| 更新 | `update_user`, `modify_settings` |
| 删除 | `delete_user`, `remove_item` |
| 检查 | `check_permission`, `validate_input`, `is_valid` |
| 处理 | `process_payment`, `handle_request` |

### 1.4 类命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 普通类 | `PascalCase` | `UserService`, `OrderProcessor` |
| 异常类 | `PascalCase` + `Error` 后缀 | `UserNotFoundError` |
| 抽象类 | `PascalCase` | `BaseAgent` |
| 枚举类 | `PascalCase` | `NodeType`, `RelationType` |
| Protocol | `PascalCase` | `Renderable`, `Serializable` |
| TypedDict | `PascalCase` + `Dict` 可选 | `UserData` |

### 1.5 文件命名

| 文件类型 | 规范 | 示例 |
|----------|------|------|
| 普通模块 | `snake_case.py` | `user_service.py` |
| 测试文件 | `test_xxx.py` | `test_user_service.py` |
| 配置文件 | `snake_case.py` | `config.py` |
| 类型存根 | `xxx.pyi` | `user_service.pyi` |

## 2. 类型注解规范（2025 标准）

### 2.1 基本规则

```python
from __future__ import annotations  # 启用前向引用（PEP 563）

# 所有公开函数必须有类型注解
def get_user(user_id: int) -> User | None:
    ...

# 使用现代联合语法（Python 3.10+）
def process(value: str | int | None) -> str: ...

# 使用 TypeVar 泛型
from typing import TypeVar
T = TypeVar("T", bound=BaseModel)

def first(items: list[T]) -> T | None:
    return items[0] if items else None
```

### 2.2 高级类型模式

```python
from typing import (
    TYPE_CHECKING, Protocol, TypeVar, Generic,
    TypedDict, Literal, ParamSpec, Concatenate,
    reveal_type,
)

# TYPE_CHECKING 守卫（仅类型检查时导入）
if TYPE_CHECKING:
    from my_package.models import User  # 避免运行时导入开销

# TypedDict（结构化字典）
class UserData(TypedDict):
    name: str
    email: str
    age: int

# Protocol（结构化子类型，鸭子类型的类型化版本）
class Renderable(Protocol):
    def render(self) -> str: ...

# Literal（约束值）
def set_mode(mode: Literal["read", "write", "append"]) -> None: ...

# StrEnum（替代字符串常量）
from enum import StrEnum

class FileMode(StrEnum):
    READ = "read"
    WRITE = "write"
    APPEND = "append"

# ParamSpec（保留可调用对象签名）
P = ParamSpec("P")

def with_logging(func: Callable[P, T]) -> Callable[P, T]:
    def wrapper(*args: P.args, **kwargs: P.kwargs) -> T:
        logger.info(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
```

### 2.3 py.typed 标记

在包根目录放置 `py.typed` 空文件，声明包提供类型信息（PEP 561）：

```
src/my_package/
├── __init__.py
├── py.typed          # <-- 这个文件
└── ...
```

## 3. 代码格式规范

### 3.1 缩进与空格

| 规范项 | Python |
|--------|--------|
| 缩进 | 4 空格 |
| 行宽 | ≤88 字符（Ruff 默认） |
| 赋值周围 | 加空格：`name = "value"` |
| 参数周围 | 加空格：`func(param1, param2)` |
| 运算符周围 | 加空格：`a + b` |

### 3.2 换行规范

```python
# 参数对齐换行
def long_function_name(
    param_one,
    param_two,
    param_three,
) -> ReturnType:
    pass

# 链式调用换行
result = (
    some_object
    .method_one()
    .method_two()
    .method_three()
)
```

### 3.3 空行规范

```python
# 顶级定义之间：2 空行
class ClassA:
    pass


class ClassB:
    pass


def function_a():
    pass


def function_b():
    pass


# 方法之间：1 空行
class MyClass:
    def method_a(self):
        pass

    def method_b(self):
        pass
```

### 3.4 导入规范


## 4. 注释规范

### 4.1 注释原则

| 原则 | 说明 |
|------|------|
| **必要性** | 只在需要时写注释，不要为明显的代码加注释 |
| **准确性** | 注释必须与代码一致，过时注释比无注释更危险 |
| **简洁性** | 清晰简洁，避免冗长 |

### 4.2 方法注释（Google 风格）

```python
def get_user_by_id(user_id: int) -> User | None:
    """根据 ID 获取用户。

    Args:
        user_id: 用户 ID

    Returns:
        User 对象或 None（不存在时）

    Raises:
        ValueError: user_id 无效
        DatabaseError: 数据库连接失败
    """
```

### 4.3 行内注释

```python
# 优先使用正则表达式（性能更优）
pattern = r'^[a-zA-Z0-9]+$'

# 在复杂代码后添加解释：
result = sorted(items, key=lambda x: x['score'] * random.random())  # 添加随机性打破平局
```

### 4.4 TODO 注释

```python
# TODO(username): 说明要做什么
# FIXME(username): 说明已知问题
# HACK(username): 说明临时解决方案
# NOTE(username): 说明重要信息
```

## 5. 函数/方法规范

### 5.1 设计原则

| 原则 | 说明 |
|------|------|
| **单一职责** | 一个函数只做一件事 |
| **参数控制** | 参数 ≤3 个最佳，最多 5 个 |
| **返回值明确** | 返回类型一致，避免混合 |
| **避免副作用** | 无不可预期的状态修改 |

### 5.2 参数校验

```python
def divide(a: float, b: float) -> float:
    """除法运算。"""
    if b == 0:
        raise ValueError("除数不能为零")
    return a / b
```

### 5.3 返回值规范

```python
# 始终返回一致的类型
def find_user(user_id: int) -> User | None:
    if not user_id:
        return None
    return db.get(user_id)  # User 或 None
```

## 6. 异步代码规范

### 6.1 异步函数

```python
import asyncio

# 异步函数使用 async/await
async def fetch_data(url: str) -> dict:
    async with httpx.AsyncClient() as client:
        response = await client.get(url)
        return response.json()

# 并发执行
async def fetch_all(urls: list[str]) -> list[dict]:
    tasks = [fetch_data(url) for url in urls]
    return await asyncio.gather(*tasks)

# 带超时
async def fetch_with_timeout(url: str, timeout: float = 30.0) -> dict:
    return await asyncio.wait_for(fetch_data(url), timeout=timeout)
```

### 6.2 异步上下文管理器

```python
class AsyncDatabase:
    async def __aenter__(self):
        self.conn = await create_connection()
        return self

    async def __aexit__(self, exc_type, exc_val, exc_tb):
        await self.conn.close()

# 使用
async with AsyncDatabase() as db:
    result = await db.query("SELECT ...")
```

### 6.3 异步迭代器

```python
class AsyncPaperStream:
    def __init__(self, query: str):
        self.query = query
        self.offset = 0

    def __aiter__(self):
        return self

    async def __anext__(self) -> Paper:
        papers = await fetch_papers(self.query, self.offset, limit=10)
        if not papers:
            raise StopAsyncIteration
        self.offset += len(papers)
        return papers
```

### 6.4 异步生成器

```python
async def stream_papers(query: str) -> AsyncGenerator[Paper, None]:
    """流式获取论文。"""
    offset = 0
    while True:
        papers = await fetch_papers(query, offset, limit=10)
        if not papers:
            break
        for paper in papers:
            yield paper
        offset += len(papers)
```

## 7. 错误处理规范

### 7.1 异常层次

```python
class AgentV3Error(Exception):
    """Base exception."""

class ConfigError(AgentV3Error):
    """Configuration error."""

class LLMError(AgentV3Error):
    """LLM call error."""

class ParseError(AgentV3Error):
    """Paper parsing error."""
```

### 7.2 异常处理原则

| 原则 | 说明 |
|------|------|
| **具体异常** | 抛出具体异常类型，而非通用 Exception |
| **包含上下文** | 异常信息应包含有用的调试信息 |
| **不压制异常** | 不要用空的 except 块 |
| **记录日志** | 捕获异常后记录日志 |

```python
# 好：具体异常 + 上下文
try:
    user = User.objects.get(id=user_id)
except User.DoesNotExist:
    logger.warning(f"User not found: {user_id}")
    raise UserNotFoundError(f"User {user_id} not found")

# 好：使用 with 自动管理资源
with open("data.txt", "r") as file:
    content = file.read()

# 禁止：空的 except
try:
    risky_operation()
except:
    pass  # 会隐藏所有错误
```

### 7.3 重试机制

```python
import asyncio

async def retry_with_backoff(
    func,
    max_retries: int = 3,
    base_delay: float = 1.0,
) -> Any:
    """指数退避重试。"""
    last_error = None
    for attempt in range(max_retries):
        try:
            return await func()
        except Exception as e:
            last_error = e
            if attempt < max_retries - 1:
                delay = base_delay * (2 ** attempt)
                logger.warning(f"Attempt {attempt+1} failed: {e}, retry in {delay}s")
                await asyncio.sleep(delay)
    raise last_error
```

## 9. LLM/Agent 代码规范

### 9.1 LLM 调用封装

```python
class LLMClient:
    """统一 LLM 客户端。"""

    async def ainvoke(
        self,
        prompt: str,
        system_prompt: str = "",
        max_retries: int = 3,
    ) -> str:
        """带重试的异步 LLM 调用。"""
        ...

    async def ainvoke_json(
        self,
        prompt: str,
        system_prompt: str = "",
    ) -> dict:
        """返回解析后的 JSON。"""
        raw = await self.ainvoke(prompt, system_prompt)
        try:
            return json.loads(raw)
        except json.JSONDecodeError:
            # 从 markdown 代码块中提取
            match = re.search(r"```json\s*\n(.*?)\n```", raw, re.DOTALL)
            if match:
                return json.loads(match.group(1))
            raise
```

### 9.2 Agent 基类模式

```python
class BaseAgent:
    """Agent 基类。"""

    def __init__(self, config: AppConfig, name: str = "base"):
        self.config = config
        self.name = name
        self.llm = LLMClient(config.llm)
        self.logger = logging.getLogger(f"agent.{name}")

    async def call_llm(
        self,
        prompt: str,
        system_prompt: str = "",
        json_mode: bool = False,
    ) -> Any:
        """调用 LLM。"""
        if json_mode:
            return await self.llm.ainvoke_json(prompt, system_prompt)
        return await self.llm.ainvoke(prompt, system_prompt)
```

## 附录：常见错误速查

| 错误类型 | 错误示例 | 正确示例 |
|----------|----------|----------|
| 变量命名过短 | `x = get_data()` | `user_data = get_user_data()` |
| 函数名不清晰 | `process()` | `process_payment()` |
| 魔法数字 | `if score > 60` | `if score >= PASSING_SCORE` |
| 硬编码路径 | `/home/user/file` | `get_config_path("file")` |
| 空 except 块 | `try: ... except: pass` | `try: ... except SpecificError: ...` |
| 过深嵌套 | 5 层以上 if 嵌套 | 提取函数 + 卫语句 |
| 重复代码 | 复制粘贴 3 次以上 | 提取为公共函数 |
| 缺少类型注解 | `def get_user(id):` | `def get_user(id: int) -> User \| None:` |
| 同步阻塞调用 | `time.sleep(10)` | `await asyncio.sleep(10)` |
| 无重试的 LLM 调用 | `llm.invoke(prompt)` | `await llm.ainvoke(prompt, max_retries=3)` |
