## 3. 工具链规范

### 3.1 Ruff：统一 Linter + Formatter（2025 标准）

Ruff 替代了 black、isort、flake8、pylint、pyupgrade、autoflake、bandit：

| 旧工具 | Ruff 替代 | 配置节 |
|--------|-----------|--------|
| black | `ruff format` | `[tool.ruff.format]` |
| isort | `ruff check --select I` | `[tool.ruff.lint.isort]` |
| flake8 | `ruff check` | `[tool.ruff.lint]` |
| pylint | `ruff check --select PLE,PLW` | `[tool.ruff.lint]` |
| pyupgrade | `ruff check --select UP` | `[tool.ruff.lint]` |
| bandit | `ruff check --select S` | `[tool.ruff.lint]` |

**配置：**

```toml
[tool.ruff]
target-version = "py311"
line-length = 88

[tool.ruff.lint]
select = [
    "E",    # pycodestyle errors
    "W",    # pycodestyle warnings
    "F",    # pyflakes
    "I",    # isort
    "N",    # pep8-naming
    "UP",   # pyupgrade
    "B",    # flake8-bugbear
    "SIM",  # flake8-simplify
    "C4",   # flake8-comprehensions
    "S",    # flake8-bandit (安全)
    "A",    # flake8-builtins
    "PIE",  # flake8-pie
    "PT",   # flake8-pytest-style
    "RUF",  # Ruff 特有规则
    "TCH",  # TYPE_CHECKING 导入优化
    "T20",  # 检测 print 语句
    "LOG",  # flake8-logging
]
ignore = ["E501", "S101"]

[tool.ruff.lint.per-file-ignores]
"tests/**/*.py" = ["S101", "T20"]
"scripts/**/*.py" = ["T20"]
"demos/**/*.py" = ["T20"]

[tool.ruff.lint.isort]
known-first-party = ["src"]

[tool.ruff.format]
quote-style = "double"
indent-style = "space"
docstring-code-format = true

[tool.ruff.lint.pydocstyle]
convention = "google"
```

**CLI 命令：**

```bash
ruff check --fix .       # 检查并自动修复
ruff format .            # 格式化
ruff check . && ruff format --check .  # CI 检查（不修改）
```

### 3.2 uv：包管理器（替代 pip）

uv 替代了 pip、pip-tools、virtualenv、pyenv：

| 旧工具 | uv 替代 |
|--------|---------|
| `pip install` | `uv add` / `uv pip install` |
| `pip-compile` | `uv lock` |
| `python -m venv` | `uv venv` |
| `pyenv` | `uv python install` |
| `pipx` | `uv tool install` |

**推荐工作流：**

```bash
uv init my-project       # 初始化项目
uv add httpx pydantic    # 添加依赖
uv add --dev pytest ruff # 添加开发依赖
uv sync                  # 同步环境
uv lock                  # 锁定依赖
uv run python main.py    # 在项目环境中运行
uv run pytest            # 运行测试
uv tool run ruff check . # 运行工具（无需全局安装）
```

## 6. AI Agent 开发规范

### 6.1 Agent 架构原则

| 原则 | 说明 |
|------|------|
| **工具设计** | 工具应有清晰的名称和 Schema，验证所有输入 |
| **错误处理** | 优雅处理工具失败，指数退避重试 |
| **上下文管理** | 精确控制传给 LLM 的上下文，过多会降低性能 |
| **幂等性** | Agent 操作应尽可能幂等，支持安全重试 |
| **人机协作** | 关键决策需人工确认 |
| **可观测性** | 记录所有 LLM 调用、工具调用、Agent 决策 |

### 6.2 MCP（Model Context Protocol）

MCP 是 Anthropic 开发的开放协议，标准化 AI 应用连接外部数据源和工具的方式：

**三个核心原语：**
- **Resources：** 暴露给 LLM 的上下文数据
- **Tools：** LLM 可调用的函数
- **Prompts：** 可复用的提示词模板

**传输机制：**
- **stdio：** 本地进程（最常用）
- **SSE：** 远程服务器（HTTP）

### 6.3 Agent Protocol

Agent-to-Agent 通信标准：
- REST API 定义 Agent 生命周期（创建、运行、状态、取消）
- 标准化任务输入/输出格式
- 支持流式响应
- 支持长时间运行的任务轮询

### 6.4 可观测性

| 维度 | 实践 | 工具 |
|------|------|------|
| 日志 | 结构化日志，关联 ID | structlog, loguru |
| 追踪 | 分布式追踪 | OpenTelemetry |
| 指标 | Token 用量、延迟、成本、错误率 | Prometheus, Grafana |
| 评估 | 自动化质量评估 | LangSmith, LangFuse |

## 7. 安全规范

### 7.1 OWASP LLM Top 10（2025）

| ID | 漏洞 | 缓解措施 |
|----|------|----------|
| LLM01 | 提示注入 | 输入验证、系统提示加固、多轮确认 |
| LLM02 | 敏感信息泄露 | 不在提示中包含密钥/PII、输出过滤 |
| LLM03 | 供应链漏洞 | 固定模型版本、审计第三方工具 |
| LLM04 | 数据/模型投毒 | 训练数据验证、模型校验和 |
| LLM05 | 输出处理不当 | LLM 输出验证后再使用 |
| LLM06 | 过度授权 | 最小权限原则、人工确认危险操作 |
| LLM07 | 系统提示泄露 | 不在提示中存储密钥、监控输出 |
| LLM08 | 向量/嵌入漏洞 | RAG 管道安全审计 |
| LLM09 | 错误信息 | 事实验证、引用溯源 |
| LLM10 | 无限制消耗 | 速率限制、Token 预算 |

### 7.2 输入验证

```python
import re
from pydantic import BaseModel, field_validator

class UserQuery(BaseModel):
    query: str

    @field_validator("query")
    @classmethod
    def validate_query(cls, v: str) -> str:
        if len(v) > 10_000:
            raise ValueError("Query too long")
        injection_patterns = [
            r"ignore\s+(previous|above|all)\s+instructions",
            r"system\s*prompt",
        ]
        for pattern in injection_patterns:
            if re.search(pattern, v, re.IGNORECASE):
                raise ValueError("Potentially malicious input detected")
        return v
```

### 7.3 速率限制

```python
from collections import defaultdict
import time

class RateLimiter:
    def __init__(self, max_calls: int, window_seconds: int):
        self.max_calls = max_calls
        self.window = window_seconds
        self.calls: dict[str, list[float]] = defaultdict(list)

    def check(self, user_id: str) -> bool:
        now = time.time()
        self.calls[user_id] = [t for t in self.calls[user_id] if now - t < self.window]
        if len(self.calls[user_id]) >= self.max_calls:
            return False
        self.calls[user_id].append(now)
        return True
```

### 7.4 输出过滤

```python
import re

def filter_sensitive_output(text: str) -> str:
    """从 LLM 输出中脱敏 PII。"""
    text = re.sub(r"\b\d{3}-\d{2}-\d{4}\b", "[REDACTED-SSN]", text)
    text = re.sub(r"\b[\w.+-]+@[\w-]+\.[\w.-]+\b", "[REDACTED-EMAIL]", text)
    text = re.sub(r"\b\d{3}[-.]?\d{3}[-.]?\d{4}\b", "[REDACTED-PHONE]", text)
    return text
```

## 8. 学术研究可复现性规范

### 8.1 FAIR 原则

| 原则 | 要求 |
|------|------|
| **Findable** | 分配 DOI（Zenodo）、提供元数据（CITATION.cff） |
| **Accessible** | 标准协议（HTTPS/git）、持久存档 |
| **Interoperable** | 标准格式（CSV/JSON/HDF5） |
| **Reusable** | 清晰许可证、完整文档、语义版本控制 |

### 8.2 ACM Artifact 认证

| 徽章 | 含义 | 要求 |
|------|------|------|
| Artifacts Available | 公开可访问 | 上传到持久存档并分配 DOI |
| Artifacts Evaluated - Functional | 文档完整可运行 | 审查者能运行代码得到结果 |
| Artifacts Evaluated - Reusable | 高质量代码 | 清晰代码、文档、测试、易用 |
| Results Reproduced | 结果可独立验证 | 第三方能复现主要结论 |

### 8.3 环境规范

| 环境 | 用途 | 数据特点 |
|------|------|----------|
| local/dev | 本地开发 | 测试数据 |
| staging | 预发布测试 | 脱敏生产数据 |
| production | 正式环境 | 真实数据 |

### 8.4 敏感信息管理

- 禁止硬编码敏感信息
- 使用 `.env` 文件管理（不提交到 git）
- 提供 `.env.example` 模板

## 10. CI/CD 规范

### 10.1 GitHub Actions

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v4
      - run: uv sync --frozen
      - run: uv run ruff check .
      - run: uv run ruff format --check .

  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.11", "3.12", "3.13"]
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v4
      - run: uv python install ${{ matrix.python-version }}
      - run: uv sync --frozen
      - run: uv run pytest --cov

  type-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v4
      - run: uv sync --frozen
      - run: uv run mypy src/
```
