### 2.3 Phase阶段定义

`chain_tracer` 定义了8个标准链路阶段：

```
INPUT → ROUTING → PLANNING → EXECUTION → RETRIEVAL → GENERATION → VALIDATION → OUTPUT
```

原有组件无阶段概念，所有操作混在一起无法区分执行节点。

## 五、监听器架构

### 5.1 ChainListener接口

```
ChainListener (抽象基类)
├── on_trace_start()     # 追踪开始
├── on_span_start()       # Span开始
├── on_span_end()         # Span结束
├── on_trace_end()        # 追踪结束
└── on_error()            # 错误发生
```

### 5.2 预置监听器

| 监听器 | 功能 | 输出 |
|--------|------|------|
| `LoggingChainListener` | 结构化日志 | 控制台/文件 |
| `MetricsChainListener` | 指标收集 | 性能数据 |

### 5.3 扩展能力

可自定义监听器实现：
- **告警监听器**: 错误超过阈值时告警
- **存储监听器**: 将链路数据写入数据库
- **上报监听器**: 上报到APM系统

## 八、集成到现有Agent

### 8.1 集成方式对比

| 方式 | 代码改动 | 复杂度 | 推荐度 |
|------|----------|--------|--------|
| **Mixin继承** | 1行 | ⭐ | ✅✅✅ |
| **手动包装** | 多处 | ⭐⭐⭐ | ✅ |
| **装饰器** | 1行/方法 | ⭐ | ✅✅ |

### 8.2 集成示例

```python
# 之前 (无追踪)
class PaperSearchAgent(BaseAgent):
    async def execute(self, query):
        results = await self.search(query)
        return results

# 之后 (Mixin集成)
class PaperSearchAgent(BaseAgent, ChainTracerMixin):
    def __init__(self, ...):
        super().__init__(...)
        self.init_chain_tracer()

    async def execute(self, query):
        with self.trace_chain(ChainPhase.RETRIEVAL, "search") as span:
            span.add_tag("query_type", "paper_search")
            results = await self.search(query)
            span.add_attribute("results_count", len(results))
            return results
```
