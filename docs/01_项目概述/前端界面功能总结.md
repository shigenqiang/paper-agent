## 2. 论文写作 (WritingPage)

**页面布局**：
```
┌─────────────────────────────────────────────────────────────────────────────┐
│ [选择论文▼] [论文标题___________] [保存] [上传]  [AI续写]  [编辑|预览|双栏|全文] │
├────────────┬────────────────────────────────────────────┬────────────────┤
│ 📄 大纲   │           ✏️ 1.1 研究背景 [234字]           │ 📚 引用管理     │
│            │  ─────────────────────────────────────────  │                │
│ [+ 添加]   │                                            │ [APA ▼]        │
│            │  开始写作...或点击上方「AI续写」            │ ────────────   │
│ 📄 第1章  │  让AI帮您生成内容                          │                │
│   ├ 1.1 ←│                                            │ 暂无引用       │
│   ├ 1.2  │                                            │                │
│   └ 1.3  │                                            │ [添加引用]     │
│ 📄 第2章  │  ─────────────────────────────────────────  │                │
│   ├ 2.1  │  总字数: 1234  |  当前: 234 字  |  14:32   │                │
│   └ 2.2  │  [已保存 ✓]                               │                │
│ 📄 第3章  │                                            │                │
│ [删除][下一章]                                        │                │
└────────────┴────────────────────────────────────────────┴────────────────┘
```

**功能列表**：
- **论文管理**：下拉选择论文、创建新论文、上传论文文件
- **四栏编辑模式**：
  - **编辑模式**：纯文本编辑
  - **预览模式**：纯Markdown渲染
  - **双栏模式**：左编辑右预览，同步滚动
  - **全文模式**：编辑全部章节内容
- **三栏布局**：
  - 左侧：论文大纲树形结构（支持添加/删除/跳转下一章）
  - 中间：富文本编辑区，支持 AI 续写（Ctrl+Enter）
  - 底部：引用管理面板（支持 APA、MLA、IEEE、GB/T 7714 格式）
- **快捷键支持**：Ctrl+S 保存、Ctrl+Z 撤销、Ctrl+Enter AI续写
- **自动保存**：30 秒间隔自动保存，状态指示图标
- **字数统计**：实时显示当前章节和总字数
- **保存状态**：图标指示保存状态（保存中/已保存/未保存）
- **全屏模式**：支持全屏写作
- **文件上传**：支持 PDF、Markdown(.md)、TXT、DOCX 格式（拖拽上传）
- **Markdown支持**：支持数学公式（KaTeX）、代码高亮
- **全局编辑**：弹窗模式同时编辑所有章节，带实时预览

- **节点交互**：悬停预览、点击详情、Prior/Derivative 论文分类
- **GraphRAG 问答**：基于图谱的智能问答
- **文献库面板**：底部可折叠面板，支持上传/添加/筛选文献
- **社区检测**：Leiden 算法检测论文聚类
- **中心性分析**：Degree/PageRank/Betweenness 中心性
- **路径查找**：两篇论文间的最短路径
- **邻居分析**：指定节点的直接关联节点

**视图模式**：

| 视图 | 颜色依据 | 说明 |
|------|---------|------|
| 社区 | 社区颜色 | 同一社区节点颜色相同 |
| 类型 | 节点类型 | 论文蓝/方法紫/数据集绿等 |
| 年份 | 发表年份 | 越新颜色越深（2015-2026渐变） |
| 引用 | 连接度 | 高连接度红色/中黄色/低绿色 |

**交互功能**：
- 拖拽画布移动视图
- 滚轮缩放
- 拖拽节点重新布局
- 点击节点显示详情
- 悬停节点显示预览

## 整体架构

这是一个完整的 **Paper Agent** 学术论文写作辅助系统，涵盖以下核心功能：

| 模块 | 功能 |
|------|------|
| 文献搜索 | 多源学术数据库并行搜索 |
| 论文管理 | 创建、编辑、上传、版本管理 |
| 大纲生成 | AI 智能分析生成结构 |
| 论文写作 | 富文本编辑 + AI 续写（支持Markdown/KaTeX） |
| 引用管理 | 多格式引用、文献库 |
| 学术资讯 | 日/周/月报自动生成 |
| 知识图谱 | 可视化论文关系图 + GraphRAG + 社区检测 |
| AI 助手 | 对话式写作辅助 |

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | React 18 + Vite |
| UI 组件库 | Ant Design 5.x |

| Markdown 渲染 | react-markdown + remark-math + rehype-katex |
| 图谱可视化 | AntV G6 |
| HTTP 客户端 | axios |
| 后端框架 | Python aiohttp |
| 数据库 | Neo4j (知识图谱) |
| 认证方式 | API Key (x-api-key header) |
