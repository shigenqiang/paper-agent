# Paper-Agent 简历项目描述（可验证版）

> 更新日期：2026-05-23 | 版本：v4.0

---

项目名称：Paper-Agent — 学术论文智能写作与定期报告生成系统

技术栈：Python · LangGraph · LangChain · aiohttp · PostgreSQL · Redis · Neo4j · Qwen3-Embedding

项目背景：学术研究人员完成文献综述需要在多个平台检索、手工筛选、撰写，周期长、效率低

核心职责：独立负责系统架构设计、核心算法实现、前后端开发、性能优化和测试部署

---

**项目功能描述**：

用户输入一个研究主题（如"深度学习医学图像诊断"），系统自动完成：

1. **主题分析**：分析研究领域，生成3-5个候选主题，评估可行性（5维评分：文献充足性/方法可行性/创新性/时间合理性/资源可获取性），选择最佳主题

2. **文献检索**：并发搜索5个学术数据库（arXiv/PubMed/Semantic Scholar/OpenAlex/CrossRef），top_k=20候选→rerank_top_k=5精排，三维筛选（相关性/质量/新颖性），3-5秒返回结果

3. **论文生成**：基于文献生成结构化大纲，逐章节生成内容，自动插入引用标注，多轮评审迭代优化

4. **学术问答**：基于检索文献回答学术问题，QA评估Faithfulness≥0.8/Answer Relevance≥0.8/Context Precision≥0.75，幻觉检测，置信度校准，多跳推理

5. **定期报告**：自动生成日报/周报/月报，支持数据监控和趋势分析

---

技术实现：

1. 多源学术检索系统：集成5个学术API（arXiv/PubMed/Semantic Scholar/OpenAlex/CrossRef），aiohttp+asyncio异步并行调度（MAIN_SEARCH_CONCURRENCY=4），top_k=20候选检索→rerank_top_k=5精排，搜索响应时间3-5秒

2. 基于LangGraph的多Agent工作流引擎：StateGraph设计20个功能节点，PaperAgentState状态类管理上下文传递，条件边函数控制流程分支，支持Diagnostic→Topic→Literature→Outline→Draft→Polish完整流水线

3. 学术引用生成系统：支持APA/MLA/GB/TURABIAN四种引用格式，引用解析器提取DOI/URL/标题信息，CrossRef API作者年份校验，批量引用生成和参考文献自动编号

4. 论文写作流水线：三维论文筛选（相关性/质量/新颖性），主题可行性5维评分（10分制：文献充足性/方法可行性/创新性/时间合理性/资源可获取性），多轮评审迭代（Reviewer反馈→Writer修订→Evaluator评分）

5. 学术QA系统（RAG架构）：top_k=20检索+rerank_top_k=5重排，Faithfulness≥0.8/Answer Relevance≥0.8/Context Precision≥0.75，幻觉检测overall_score 0.12（low risk），置信度校准±0.15，多跳推理子问题分解+推理链

6. 分层记忆系统：短期记忆（会话级）+长期记忆（持久化），Qwen3-Embedding向量检索语义搜索，遗忘曲线算法自动衰减低重要性记忆，支持跨会话上下文恢复

7. 系统架构：aiohttp异步API服务支持SSE流式输出，PostgreSQL+Redis+Neo4j存储，LLM调用超时TIME_LIMIT=120s，P95响应延迟<5000ms（20次测试），Docker容器化水平扩展
