# Demos

示例代码和演示脚本。

## 快速开始

```bash
# 运行完整论文生成
python demos/run_full_paper.py "你的论文主题"

# 运行论文搜索演示
python demos/run_demo.py

# 检查前端服务
python demos/check_frontend.py
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `run_full_paper.py` | 完整论文生成流程演示 |
| `run_demo.py` | 论文搜索和主题选择演示 |
| `demo_stage1.py` | 第一阶段演示 |
| `demo_langgraph_workflow.py` | LangGraph 工作流演示 |
| `test_unified_workflow.py` | 统一工作流测试 |
| `check_frontend.py` | 前端服务检查工具 |
